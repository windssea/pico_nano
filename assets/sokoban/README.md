# PicoNano 原创推箱子题库

本目录由项目自有生成器生成，许可证 Apache-2.0，不复制第三方关卡或位图。`levels.pnsk` 是唯一嵌入固件的数据，`levels.json` 保存可审查的题面、完整推箱解法和分级依据，不链接到固件。墙、箱、目标、角色与按钮都由同源像素绘制。

共90关，每档30关。低档前10关为单箱教学，最优2–6推；随后双箱3–10推、不要求把已就位的箱子移出目标、换箱不超过3次。中档双箱8–22推，至少一次换箱。高档三箱16–40推，至少4次换箱且精确搜索展开至少50个状态。档内按箱数、推数等确定排序。以上是生成筛选指标，不能替代人类试玩的难度评价。

先从完成局反向合法拉箱，再由独立正向A*寻找最少推数解。玩家可达区域规范化后作为状态，采用墙约束的反向目标距离/箱子目标匹配启发式；达到节点预算但未解出的候选直接丢弃，不把超时当作高难。完整解法另外由C游戏核心逐关走路、推箱、撤销和重做回放。

## 重建与核验

```sh
python assets/sokoban/generate.py --seed 20261026 --out build-dev/sokoban/rebuilt
python assets/sokoban/test_bank.py
```

只用Python标准库。默认从头生成，不读取本机历史缓存。可显式增加 `--checkpoint build-dev/sokoban/generator-checkpoint.json`，保存完整随机数状态、版本、种子与已筛选关卡；同一参数再次执行续建。更换种子或算法版本不能混用旧检查点。Windows CPython3.12与Linux CPython3.12从头重建已得到相同14432B题包。

## 二进制格式 v1

全部多字节整数为小端。32B头：magic `PNSK`、u16版本1、u16记录长度160、u32关卡数90、u32全部记录CRC32，余16B为零。文件必须精确为14432B。

每个160B记录：0–7为宽、高、难度、箱数、玩家、证明推数、最优推数、保留零；8–9为u16全局题号；10–11为换箱/移出目标次数；12/28/44分别为16B墙/目标/初始箱子位图；60–155为最多48组“箱位置、方向”证明，未用部分为零；156–159保留零。方向0上1右2下3左。外边界封墙，棋盘外位必须为墙且不能有箱/目标。运行时上限10×12/128格、5箱；当前内置关卡6×6至9×9、1–3箱。

产品只支持内置题包，暂未开放TF扩展题库或运行时随机出关。无需在设备运行A*。每次取关先完整验证题包CRC、头/尺寸/保留位，再验证当前关卡全部解法；内部续局载荷自带当前关卡及证明，不依赖TF文件。版本或题库改变不会替换玩家已保存的当前局。
