# PicoNano 中国象棋残局题库

本目录由项目自有脚本构建与穷举证明，许可证 Apache-2.0，不复制受版权保护的第三方棋书软件数据。`endgames.pnxq` 是唯一嵌入固件的只读数据，`endgames.json` 保存可审查的棋子排布、标题与主变证明序列，不链接到固件。棋盘、九宫、楚河汉界、炮兵花标与棋子均由同源像素图元和共享字库绘制。

共 60 关，每档 20 关，均为**红先必胜**：
- **初级（0–19）**：1–2 回合基础杀法（对面笑、铁门栓、重炮杀、闷宫杀、卧槽马、挂角马、马后炮、双车错等经典杀型）。
- **中级（20–39）**：2–3 回合战术组合，含弃子引离、借炮使马及黑方反杀威胁下的紧迫连杀。
- **高级（40–59）**：3–4 回合深度杀局，黑方均具备一步反杀威胁，红方须步步精确催杀方可破局。

全部 60 关均由独立极大极小穷举求解器验证：对黑方一切合法应着，红方均在标定回合内强制绝杀或困毙，且不存在更短漏解；关卡名称字符全部在内置正文字库覆盖范围内。

## 二进制格式 v1

全部多字节整数为小端。32B 头：magic `PNXQ`、u16 版本 1、u16 记录长度 96、u32 关卡数 60、u32 全部记录 CRC32，余 16B 为零。文件精确为 5792B。

每条 96B 记录：0–5 为题号、难度、棋子数（3–16）、证明半回合数（奇数 1–15）、最大步数上限、最短绝杀回合数；6–7 保留零；8–31 为零结尾 UTF-8 局名；32–63 为至多 16 组 `(坐标 0..89, 棋子码)`，升序排列，未用槽为 `(0xFF, 0)`；64–95 为至多 16 半回合 `(起点, 终点)` 绝杀主变证明，未用槽为零。C 核心在加载时再次校验整包 CRC、棋子合法坐标与主变完整绝杀回放。
