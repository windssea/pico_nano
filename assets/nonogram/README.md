# PicoNano 原创数织题库

本目录由项目自有脚本生成，许可证 Apache-2.0，不复制第三方谜题或位图。`puzzles.pnng` 是唯一嵌入固件的只读数据，`puzzles.json` 保存可审查的题面、标题与推理轮数，不链接到固件。棋盘、行列提示数字、填涂块、排除叉号与按钮均由同源像素图元绘制。

共 90 关，每档 30 关：
- **简单（0–29）**：前 15 关为 5×5 入门图案，后 15 关为 8×8 图案；每行每列至多 5 段提示。
- **中等（30–59）**：10×10 图案，纯行列逻辑传播至少 4 轮，每行每列至多 5 段提示。
- **困难（60–89）**：15×15 图案，纯行列逻辑传播至少 6 轮，每行每列至多 6 段提示。

全部 90 关均经精确单行动态规划与行列传播验证**无需猜测唯一可解**，标题字符全部落在内置正文字库覆盖范围内，通关前隐藏标题避免剧透。

## 重建与核验

```sh
python assets/nonogram/generate.py --seed 20261118
python assets/nonogram/test_bank.py
```

## 二进制格式 v1

全部多字节整数为小端。32B 头：magic `PNNG`、u16 版本 1、u16 记录长度 64、u32 关卡数 90、u32 全部记录 CRC32，余 16B 为零。文件精确为 5792B。

每条 64B 记录：0–3 为宽、高、难度、目标涂黑格数；4–5 为 u16 题号；6 为行传播轮数；7 保留零；8–31 为以零结尾的 UTF-8 标题（未用字节全零）；32–63 为 256 位小端解位图（棋盘外高位必须为零）。C 核心在取题时再次验证整包 CRC、头部、位边界与完整唯一性。
