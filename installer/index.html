PicoNano 网页安装

用电脑上的 Chrome 或 Edge 通过 USB 连接阅读器，一次完成安装或升级。只写需要的区域，不整片擦除。

当前浏览器不支持 Web Serial。请在电脑上用 Chrome 或 Edge 打开本页（手机和 Safari、Firefox 不支持）。

1 · 连接设备

  1. 用能传数据的 USB 线把阅读器接到电脑。
  2. 点“连接设备”，在弹窗里选择出现的串口（通常名为 USB JTAG/serial debug unit）。
  3. 如果一直连不上，让设备进入下载模式后再试（ESP32-S3 通常是按住 BOOT 再接 USB；本机具体按键以原厂说明为准）。

    安装器会写哪些内容

    安装器先读取设备上的分区表，再决定要写什么：

    • 升级（设备已是本固件布局）：只写应用固件和 OTA 选择；引导程序与设备相同时跳过；设置、阅读进度、书签和壁纸都保留。
    • 首次安装（原厂或其他系统）：写引导程序、应用、OTA 选择，最后写分区表。旧分区表里本就是设置区（NVS）的扇区保留，新设置区里原先不是 NVS 的扇区清空；内部数据和壁纸分区若还不是有效文件系统，写入空镜像。
    • 任何情况都不整片擦除，不碰存储卡，不写屏幕电源芯片（VCOM 只从 PMU 读取）。每段写完都做 MD5 校验。
    开机后没有画面

    固件读不到有效的屏幕电压（VCOM）时会故意不刷屏，屏幕保持原样，这是保护行为。设置区无法初始化时固件也会停下。可用串口查看日志（115200）：看到 “NVS unavailable” 时，重新连接并勾选“清除设置区”再装一次。

    如何恢复原来的系统

    用安装前保存的整片备份写回 0x0：esptool --chip esp32s3 -p COM? write-flash 0x0 read-pico-backup-….bin。中途断开时设备会停在下载模式，可直接重新安装或写回备份。

    命令行安装

    也可以下载各版本文件夹里的分段文件用 esptool 写入，说明见仓库 releases/ 中的 README。

    页面在浏览器中直接与设备通信，固件文件从本站下载并经 SHA-256 校验。串口通信使用 esptool-js 0.5.7（Apache-2.0）。
