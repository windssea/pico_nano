# 设备热点传输入口

0.0.47已在主设备入口装配上传文件适配、独立文件worker、AP WiFi、HTTP和中文页面。书架“传书”进入；阅读页点左上“小纸 Pico”打开“阅读与传输”菜单，再点“热点传书”。这是设备代码接通，尚未烧写或进行真实无线/墨水屏验证。

## 用户流程

进入前记录当前书内容身份、执行阅读保存屏障并关闭所有TF阅读/字体消费者。失败时保留原会话，不开启上传。进入后显示热点名称、本次口令、浏览器地址和六位配对码；手机连接热点后访问地址，使用既有中文网页发送TXT/EPUB、TTF或PNG/JPEG。

“停止传输并返回”立即请求关闭，页面保持“正在关闭传输”，等待已接收处理结束。资源归还后重新打开原书，在持久位置恢复。若同名书被上传替换，原内容身份校验阻止把旧阅读记录交给新书，并提示从书架重新选择。进入时没有活动书籍则退出回书架。

传输期间短按电源键先关闭传输，归还存储后才显示锁屏。锁屏后按 [锁屏浅睡](POWER.md) 进入浅睡，电源键唤醒回原书。拔卡或失去网络地址会关闭当前传输；关闭未完成时保留对象，页面可重试关闭，不强杀任务或卸载卡。

设备入口有热点模式，以及已保存网络时的“局域网传书”（见 [家庭网络与局域网传书](LAN_TRANSFER.md)）；网络扫描仍待实现；热点二维码已加入，见 [扫码传书](TRANSFER_QR.md)，文字连接方式保留。不能将本阶段称为完整LocalSend或完整第一版。

## 所有权与界面

后台监督任务调用 [WiFi生命周期](DEVICE_WIFI.md)、[HTTP适配](DEVICE_TRANSFER_HTTP.md) 和 [文件工作任务](TRANSFER_WORKER.md)。主UI在移交期间只读锁保护快照，不扫描TF、检查租约、detach或remount共享media。监督任务查询BSP卡状态；失效先关闭消费者，再将media归还主UI处理。

退出顺序为HTTP关闭认证/接收并drain → worker关闭文件/释放租约 → WiFi停止/注销/deinit → 确认无租约 → released → 主UI join/释放监督上下文 → 原书恢复。后台清理失败不发布released，保留资源供显式重试。耗时校验或HTTP停止不占用主界面任务。

页面由同源 `pn_transfer_view` 纯绘制，使用常驻UI字体，不从TF加载字体；未知数据字形画边框，固定文本的字体子集由工具生成。状态重绘最多每秒一次，使用已有GL16，首次未知面板状态仍GC16。刷新时序、残影和功耗需真机检查。

书架的传输按钮需平台显式启用；PC阅读模拟器的旧入口继续隐藏，不显示未接通的点击项。PC HTTP独立入口仍可实际传书，见 [网页服务](TRANSFER_WEB.md)。

## 可复跑检查与边界

host的transfer_view用真实常驻字体检查菜单/页面绘制、有效命中、停止中不可误点及平台隐藏控件。device_transfer用真实pthread监督任务、阅读会话、持久位置、上传worker及SDK-stub无线/HTTP，检查已有READ租约拒绝进入、关书后接通配对、停止归还存储、非零阅读位置重开一致、HTTP关闭失败保留资源并重试、拔卡关闭。SDK网络、时钟和无线行为明确stub，不构成真实连接或面板证据。

两套ESP-IDF配置现在真实链接设备入口及传输模块。下一步需完成配网/二维码、续传丢失新建回复的找回、字体管理与图片应用等软件项，再做实际手机连接、上传、关闭、拔卡、阅读恢复、任务栈/内存、吞吐和功耗验证。原格式/PDF/FB2/CBZ及第一版功能目标保持不变。
