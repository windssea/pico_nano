# 逐书排版设置与草稿

TXT与原生EPUB共用逐书排版设置（EPUB入口自0.0.30接入）：字号、行间距、段落间距、首行缩进、字间距、左右边距，以及阅读线和上下位置。字体文件管理、字重、对齐/高级排版、全局默认、其他未实现格式仍在原第一版范围内，不能把当前字段当成全部排版需求已完成。

正文顶部“排版”打开设置页，修改值只改变草稿。点预览显示原文锚点处的正文，点正文返回设置，再选择应用或取消。正文预览期间不派发翻页动作；取消回原设置及原锚点。显示失败回滚当前排版值，不写配置；界面未成功呈现时不能应用。保存失败保留草稿和会话供重试。

PC两种窗口均可按S打开，上下选择字段、左右修改，P预览，预览中Enter/Esc/S回表单，表单Enter应用、Esc取消。鼠标与设备触摸共用命中；预览中点击任何位置回表单。正文按钮“缩小/放大”与PC键盘+/-改为同一套持久设置，重启后仍生效。

## 范围与布局

| 项目 | 范围 | 默认与含义 |
| --- | --- | --- |
| 字号 | 28..72px，界面步进2 | 调用方初始值，设备44px |
| 行间距 | 100..220%，步进5 | 145%，实际不低于字体ascent+descent |
| 段落间距 | 0..100%，步进5 | 字号的25%，整数像素 |
| 首行缩进 | 0..2字 | 0，按字体em像素宽度缩进 |
| 字间距 | 字号的0..50%，步进5 | 默认0，26.6精度额外字距；换行不加字距 |
| 边距 | 16..80偶数px，步进2 | 左右32，正文宽度684-2*margin |
| 阅读线 | 关闭／虚线／点线 | 默认关闭；1px灰线跟随实际文字行 |
| 上下位置 | -8..8px，步进2 | 默认0；负值上移，正值下移 |

正文区域以当前共享阅读布局为准，工具栏位于底部320px。原生字体度量和光栅尺寸随配置变化，不缩放整页；首行、段距、行距和字距传给同源分页器。字距加在相邻字形位置之间，字形本身不拉伸；行末自然字宽仍用于对齐，下一行从原源位置重新排版。EPUB使用同一layout字距字段及设置界面，恢复原资源路径和语义锚点；TXT使用source_offset。两者不保存永久页码；字号/边距重排不会跳到章首。固定左对齐、基础断词/标点等原限制仍在。

表单每个按钮命中至少80px，字段编辑和表单使用GL16，更多页调整字间距、阅读线与上下位置；清残影统一在系统设置。不将表单编辑计入阅读周期，未实现250ms预览合并。预览期间正文上方显示“排版预览”，底部显示“设置尚未保存”和“点击返回设置”；应用/取消回正常阅读控件。行间距显示倍数，字号/边距显示“像素”，段距/字距说明按字号比例计算。实际响应和纸屏观感尚未上板验收。

阅读线只绘制实际有文字的行，依据基线、字体下降部和行间空隙定位，不改变分页、语义锚点或持久分页key，不增加帧或常驻缓存。EPUB混合字号取该行实际下降部；带插图的行跳过，正文视口裁切防止越过边距/页脚。关闭恢复原始像素，逐书记录独立，段落及整页预览、应用、取消沿用原事务。当前仅横排，尚无竖排支持。

## 持久格式和提交

使用逐书`<SHA>.style.a`/`.style.b`，PC位于state-dir，设备/data/progress。借用内部存储租约，不改NVS、VCOM或TF字体文件。未知配置、损坏或错内容身份拒绝猜默认；只有双槽不存在才用open初始字号和默认值，已有配置优先于该初始字号。

PNTS payload schema3固定64bytes：magic4/版本号2bytes（值3）/reserved2=0、内容SHA32、pixels/line_percent/gap_percent/indent_em/margin/gl_before_clear各2bytes（40..51），字距tracking_percent位于52..53，阅读线reading_line位于54..55，上下位置reading_line_offset为56..57的有符号16bit值，余6bytes必须0。读schema1时52..63须0，字距补0；读schema2时54..63须0，保留字距。两种旧版阅读线默认关闭、位置为0，不自动重写旧文件；未知schema拒绝。外层PNJR序号/CRC/A-B同步读回保持原样。配置不改进度或书签。gl_before_clear保留0..30校验及原二进制位置，仅用于旧记录兼容，不参与显示或周期判断。

应用先验证范围、重排/呈现，再写配置。写错误可能已提交，立即重新load并比对完整候选来确认；确认候选已落盘可报告成功。尚未确认提交的应用意图由会话保留，关闭时重试，不释放会话丢请求。EPUB将该候选与后续预览草稿分别保存，关闭重试提交原应用候选。取消失败应用时先解析实际记录：若已改变，则尝试恢复原配置；未知/损坏不擦除或强行覆盖。首次部分写且无旧有效槽的配置损坏，仍需要以后明确修复引导。

未申请应用的预览，离书/锁屏时只丢草稿，原配置不变；位置仍按正常保存屏障处理。apply失败但预览已确认时，屏幕可以已经显示候选排版，不能把保存失败误当作旧画面还在。每次导航尝试先清last_confirmed，参数错误也不能复用此前成功标志。

## 验证

`python tools/dev.py host`覆盖配置范围/非零字距/阅读线及有符号位置/旧schema1和2兼容/未知版本/内容身份/真实文件重读；真实阅读器覆盖失败预览回滚、原锚点、取消、应用跨重启、无效参数确认标志和写失败阻拦关闭/修复后重试。style_ui测试覆盖未呈现禁止应用、排版与阅读线按钮命中及取值、预览/返回和草稿取消，资源回收为零。

`python tools/dev.py sdl`的style_window通过实际SDL事件验证书架窗口与独立阅读窗口，跨进程恢复已应用字号，并核对实际保存载荷中的字距。同一测试另比较TXT/EPUB阅读线的虚线、点线、关闭与页脚像素不变，并检查取消、重开和实际schema3载荷；还覆盖EPUB独立与书架窗口的触屏入口、历史七字段兼容载荷、取消及关闭未应用预览不改变配置。两套SDK构建只证明交叉编译，不证明硬件性能。可设PN_STYLE_CAPTURE为文件路径运行host/test_style_ui捕获同源PGM；PN_STYLE_PREVIEW_CAPTURE另存正文预览；图像是绘制快照，不是纸屏照片。

字体管理/完整回退、全局与逐书继承、高级对齐、翻页手势设置、PDF及硬件验收继续开发，第一版目标保持完整。

EPUB实际小说与用户字体可用host的epub_app_capture复跑；设PN_EPUB_STYLE_FORM=1导出设置页，PN_EPUB_STYLE_PREVIEW=1导出两字缩进、1.60倍行距、40%段距、5%字距的原文预览。样本与输出保存在本机忽略目录，不随产品分发。
