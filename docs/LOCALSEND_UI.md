# 附近传书确认与状态界面

当前已提供固件/PC共用的 C 界面组件 `pn_localsend_view`，以及可点击的独立 SDL 演练窗口。确认、拒绝和取消演练调用真实会话核心；进度、安装结果与恢复页面使用明确标注的状态样例。窗口不开网络、不写文件，尚未与 PC HTTP 服务、设备页面和停止屏障接线，不能把演练结果作为真实 LocalSend 传书验收。

## 操作与状态

- 标题“附近传书”，发送方名称、文件数、总大小和当前已选数量清晰展示。发送方是申报名称，不能视为认证。
- 每页最多 3 个文件，全部最多 8 个；上一组/下一组保留本次选择。新确认代次会清空选择并回第一页。
- 默认所有文件“不接收”。书籍/字体可选“接收”；图片明确选“封面”或“锁屏”。至少选择一个有效文件才能确认，拒绝全部随时可用。
- 选择仍是本机草稿，点击确认后控制层才能调用会话授权。确认必须携带原 `snapshot.generation`；旧弹窗或延迟事件不能确认新请求。
- 已确认等待发送、正在接收、校验与保存、安装结果分别展示。接收百分比是内存输入量，100%不代表安装成功；文件类别与安装目录继续由共享安装层控制。
- 显示已安装/未安装计数。部分成功与全部未安装分别提示；取消明确保留已安装文件。恢复状态提示关闭后恢复，不伪造撤销成功。
- 活动会话提供“取消接收”，请求取消后禁用重复点击；其他终态提供“停止传输并返回”。实际停止、恢复和返回原书由控制层负责，界面不直接关闭 owner。

界面沿用 684×1216 逻辑坐标和常驻中文字体；选择/翻组按钮至少 88 像素，底部确认与拒绝各 96 像素高。文件名过长截断，陌生字形沿用公共字体回退。books/fonts 等实际目录名、格式和容量单位保留必要英文，其余交互文案为中文。

## 开发窗口

```powershell
$env:DOCKER_CONTEXT='desktop-linux'
python tools/dev.py sdl-run
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_localsend_preview.ps1
```

书架模拟器与预览是两个独立窗口。预览标明“不传输文件”；可点击选择、翻组、确认、拒绝和取消。空格循环显示接收、校验、部分完成、恢复及新请求样例；Esc关闭。关闭预览不会关闭书架或操作私人文件。

重建后需关闭旧预览，再运行脚本加载新程序。SDL dummy 测试专用 `PN_LS_PREVIEW_SCRIPT` 支持 `tap:X:Y`、`space`、`quit`，坐标为逻辑像素；不是固件或网络自动确认策略。

## 接线契约与验证

`pn_ls_view_bind` 校验复制快照、页码/活动文件和接收量，错误保留原对象；同代次保留选择，新代次重置。绘制与命中无网络、文件、电源或设置副作用；绘制恢复字号，不修改会话。传输 owner 与 UI owner 不跨线程共享活动会话或字体对象，接线时必须复制快照并串行提交动作。

传输期间不得借用仍依赖存储卡读租约的全局回退字体；控制层先停止阅读/字体消费者，再使用常驻UI字体呈现。设备进度重绘需节流并沿用已有刷新策略，不能随每个网络块整屏刷新；刷新性能仍须上板实测。

选择动作按文件索引及选项编码；书籍/字体选项为拒绝/接收，图片为拒绝/封面/锁屏。控制层在处理 `CONFIRM` 时将当前选择和代次一起交给 `pn_ls_decide`，拒绝时提交全拒绝；收到 `CANCEL` 后调用取消流程并继续查询真实快照，不能自己把页面改成“已取消”。`STOP` 必须经过既有关闭入口、join调用方和关闭worker屏障；恢复未收口不能启动新接收。

`python tools/dev.py host` 的 localsend_view 验证代次、图片分类、分页边界、非法状态、接收量、命中及常驻字体绘制；SDL 的 localsend_preview 验证实际点击与真实会话确认/拒绝/取消，以及示例状态切换。图片捕获位于忽略的 build-dev，不提交。

尚待实现：与真实 PC HTTP 会话联动、设备页面装配、三键焦点、超时快照轮询、离页/锁屏/拔卡停止，以及官方桌面/Android/iOS完整互通。组件编译、演练截图均不能替代这些交付门。
