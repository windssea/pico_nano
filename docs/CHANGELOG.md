# PicoNano 变更记录

这里只记简短结果；当前机制见[架构](ARCHITECTURE.md)，剩余门见[开发指南](DEVELOPMENT_PLAN.md)。2026-10-14归档前完整记录见[历史CHANGELOG](archive/2026-10-14/CHANGELOG.md)，早期版本细节不重复维护。

## 2026-10-14：0.6.1 调频、去除已显示帧副本与阅读/锁屏改进

- 动态调频：产品/显示/无线会话按需持最高频锁，空闲约1秒降到80MHz；自动浅睡未开。功耗与翻页时延需真机测。
- 阅读触摸只分左右半屏翻页，移除点中间打开工具栏（KEY2不变）；设置页移除局域网传书入口。
- 阅读线增加浅/中/深/黑深浅（PNTS schema4，旧记录为浅）。
- 透明遮罩锁屏把预处理平面缓存到TF `.readpico/masks`，后续锁屏只读平面并按字节合成（主机样本86.9→4.3ms）。
- EPUB打开在整书SHA顺序读取中顺带校验ZIP本地头（400章样本ZIP打开88.8→2.9ms，冷开p50 435→354ms，主机）。
- 局部刷新改为比较epdiy前/后缓冲（板级方向）求逻辑外接框，操作面板底图由后缓冲逆变换；池内省去406KiB `shown_px`。
- 新增旋转逆变换往返和200轮随机外接框oracle，设备管理/开机测试改用后缓冲；局部刷新与面板底图需真机复验。
- HARDWARE补充厂商规格、BSP核对的GPIO/I²C连线及硬件能力使用核查（电源管理/触控中断/向量指令等未用项）。

## 2026-10-14：发布0.6（a0a9a97）

- 语义模型文本按1/2/4字节存码点、连续位置省略差值；超384KiB长章保留阅读起点附近的已验证窗口并以序号/段落状态接续，越界或尾部不足回冷解析重建。
- 原创约30万中文标量单章：120次下一页+40次上一页XML解析976→16次，三种上限逐帧一致；短段章计费318000→250000字节。
- 设备整书SHA在内部余量足够时临时借32KiB DMA块（替身验证读取17→3次）；真机TF/翻页时延未测。
- 产品版本改为0.6，唯一来源 `PN_PRODUCT_VERSION`（CMake/打包/状态接口共用）；开机画面右下角显示“v0.6”，设置“存储与关于”显示版本，默认锁屏不带版本号。

- 主入口收拢为硬件、当前架构、后续开发指南、构建、安装发布、TF目录和本记录，详细区分实现/软件验证/构建/真机验收。

- 更新开发入口及升级打包文档来源；本批不生成固件或发布网页安装器。

## 2026-10-14：阅读优化（随0.6发布）

- 邻页精确字形预热、BMP512槽四路缓存、短段紧凑语义模型与已验证EPUB热页窗口复放；保持完整冷校验、384KiB模型/共享缓存上限、低预算流式退路和显示/位置屏障。
- 完整143CTest、10Python、5Node及31SDL通过，最后准入守卫后补5项相关回归。主机同原创9.94MiB EPUB热下一页准备p50约3.915→0.197ms，会话峰值增加约160KiB，冷开/整体光栅无明确收益。
- 已随0.6发布；真机效果待验证。
