# PicoNano 存储卡目录与安装契约

更新：2026-10-14。本页是所有上传通道的长期路径规范，目录常量以 [pn_sd_layout.h](../components/pn_storage/include/pn_sd_layout.h) 为准，安装映射由 [pn_upload_directory](../components/pn_transfer/pn_upload.c) 共用。界面类别中文，跨平台路径名固定，不自动移动/删除旧文件。

## TF 公开和内部目录

设备内部挂载点 `/sdcard`，下列路径相对卡根：

| 路径 | 内容 | 行为 |
| --- | --- | --- |
| `/piconano/books/` | 已校验TXT/EPUB | 书架固定扫描根，未实现格式不因扩展名通过而安装成功 |
| `/piconano/fonts/` | 已校验TTF，最多32MiB/文件 | 字体管理/选择；上传不自动替换当前字体 |
| `/piconano/covers/` | 封面JPEG/PNG资源（网页上传为184×256、16灰阶PNG） | 通过书名主体关联 |
| `/piconano/wallpapers/` | 锁屏JPEG/PNG资源（网页上传均为原生边界内16灰阶PNG，保留16级透明度） | 用户预览/裁切/旋转并应用 |
| `/piconano/backgrounds/` | 阅读背景JPEG/PNG资源（网页上传为684×1216、16灰阶4位PNG，最多159B UTF8文件名） | 等比居中裁切铺满，在排版设置选择，上传不自动应用 |
| `/piconano/.readpico/backgrounds/` | 可重建阅读背景缩略图和原生缓存 | 缩略图144×256，完整底图核对源SHA及缓存CRC，翻页只读内存 |
| `/piconano/.readpico/covers/` | 可重建缩略图 | 不与封面原图混放 |
| `/piconano/.readpico/indexes/library.pni` | 可重建书库索引 | 介质/目录变动失效，打开书仍完整核对SHA |
| `/piconano/.readpico/reading/pages/` | 开发中的TF增量分页表 | 按完整书籍/实际字体布局键保存，最多65536项/表，全局32MiB；缺失/损坏回原书，不是已完成整书分页 |
| `/piconano/.readpico/masks/` | 可重建透明锁屏灰度/透明平面 | 原图路径/大小/mtime/变换为键，CRC 损坏即重建，可整目录删除 |
| `/piconano/.readpico/wallpapers/` | 可重建壁纸缩略图及原生预览 | 缩略图144×256/16灰阶；原生预览核对完整源SHA及CRC，可整目录删除 |
| `/piconano/.readpico/uploads/` | 暂存、分块记录、安装日志及备份 | 未完成文件不入书架，不手动清理活动事务 |
| `/piconano/.readpico/volume.sync` | FAT同步标记 | 设备存储适配管理 |

阅读进度、书签、设置及持久分页窗口位于内部data分区；已应用壁纸A/B位图位于内部wallpaper分区。它们不随公开TF目录改成存卡。页窗口最多512项/书、内部缓存目录全局128KiB，可删重建；位置和书签不是可丢缓存。

新增TF页表优先保留已生成的较多分页边界，原内部窗口仅作退路，RAM仍最多512项。内部indexes目录的`<layout-sha>.pnrt`为140B可信根缓存，含书籍/布局、新旧整表SHA及CRC，独立16KiB配额；构建新表先完整读回/摘要确认，先提交新旧根再提交TF表。TF表的CRC/排序/长度/EOF及完整SHA都须通过，不能用卡上自报摘要代替信任。CACHE_WRITE只管理固定派生路径；原书、设置、书签、壁纸A/B与上传事务不迁移，删派生目录会重建且不清进度。页表/可信根回收均保护活动会话及未知文件，不自动格式化。

## 各入口必须复用的契约

没有显式全局/逐书正文字体时，默认正文与UI共用已加载的完整系统字体，避免正文仍受应急子集覆盖限制；已保存的用户字体选择优先，缺失记录保留。

字体目录接受单字体TTF及CFF轮廓OTF（`.ttf`/`.otf`），字体集合仍拒绝。字体管理可把其中一款设为系统（界面）字体，选择记录在内部`/data/progress/system-font.a|b`，只存规范路径与身份；文件被删、移走或打不开时回到下述默认系统字体，再回到内置应急字库，记录保留。

完整系统中文字体默认使用 `piconano/fonts/HarmonyOS_Sans_SC_Regular.ttf`，原始TTF不嵌入应用。产品owner打开并验证源后按需读取，共享既有池预算；主机同源加载器使用配置字体目录中的同名文件。缺失/损坏/换卡使用内置应急字库，保存选择不被覆盖。USB独占和资源传输前必须关闭阅读与系统字体消费者、释放文件租约，停止并重挂载后再加载；字体管理前也释放系统源，以便安全更换。普通客户端以字体类别上传同名文件，不能指定安装目录。首开/换卡仍需校验，热UI绘制不重复全文件摘要。

AP/STA网页、设备/PC HTTP和LocalSend接收都必须复用类别映射与共享安装事务。客户端只给资源类别与安全文件名，不能给目录；拒绝分隔符、绝对/上级路径、控制字符、保留名及不匹配后缀，未知类别拒绝。主机文件端口拒绝符号链接绕过目录；不能据主机rename测试宣布FAT掉电原子性。

网页上传的每张图片都在浏览器按EXIF转正、缩放并重新编码，不直接发送原图，也不在转换失败时回传原图。封面居中裁切为184×256（与书架缓存一致，亦覆盖首页及书签锁屏的显示需求），白底合成后量化为16灰阶、4位灰度普通PNG；锁屏图保持比例、只缩小不放大，竖图不超过684×1216，横图不超过1216×684以支持旋转，非透明图同为4位灰度PNG，透明图使用16灰阶×16级透明度的8位索引PNG。浏览器优先Deflate压缩，缺少压缩流时仍输出有尺寸/位深上界的合法PNG，不使用原图。后缀统一为`.png`，摘要、续传和冲突检查绑定重新编码后的字节；原文件不改。已有同主体JPEG封面仍沿原匹配优先级，可能优先于新PNG；替换后仍显示旧图时需删除旧封面，不静默删除或迁移。该处理只覆盖网页，直接复制和LocalSend仍沿原完整格式/大小校验。

图片必须明确“封面”、“锁屏图片”或“阅读背景”，不按MIME/文件名猜用途。类别相同目录内才计算同名冲突，覆盖需用户确认及旧内容身份核对；写暂存→完整摘要/格式校验→可恢复备份替换→同步/提交，最终事务完成才显示已保存。分块ACK只代表持久偏移，不代表字体校验/图片应用/最终安装完成。

传书先保存、关闭阅读源/字体并独占TF，退出等HTTP/worker/事务停止和租约释放后才恢复产品访问；真拔卡使旧epoch失效，临时检测I/O不永久冒充拔卡。取消不能清其他成功文件，恢复不格式化、不静默擦NVS。

未来USB应用协议与转换助手同样走上述规则。USB MSC是电脑直接复制到卡，不经过上传安装层，固件不能强制其目录；必须独占卸载/移交、退出重挂载/重扫，不能声称所有电脑复制都受资源事务校验。0.6.6已有手动MSC源码和停止屏障，真实电脑读写/弹出/串口恢复尚未验收；LocalSend完整设备互通仍待验收。

## 封面关联、缓存与缺失

开发中的共用缓存协议已接入壁纸/背景/遮罩预览：主包缺失或损坏时，允许尝试同样完整验证的.bak，.tmp不作为读取候选。目录缺失可在合法CACHE_WRITE资格下按需建立；只读/满盘仍回原图处理。新代读回核验后才发布，失效媒体租约上的清理不再操作路径；此协议不改变上传目录、原件或锁屏内部A/B记录。

壁纸缓存与书封缓存分目录。壁纸列表缩略图按源路径、大小、mtime及算法版本探测变化，完整验证缓存CRC后呈现；它不是源身份，不能用于应用壁纸。完整预览缓存仍逐次读取源文件全部字节核对SHA，再完整验证缓存CRC，匹配才复用684×1216/16灰阶像素及遮罩透明度。每张源图的缩略图、壁纸预览、遮罩预览各保留一个文件，变换变化替换相应预览；原图不改。缓存临时文件读回核验后经备份替换提交，失败可重新解码，原锁屏记录不变。所有缓存写入使用固定目录的CACHE_WRITE，不冒充用户上传或改变书籍身份。

books书籍优先匹配集中covers目录同名主体，后缀顺序 `.cover.jpg`、`.cover.png`、`.jpg`、`.png`；再检查旧同目录侧车，EPUB之后回退内嵌封面。选中的外置原图损坏显示占位，不悄悄改用另一张原图。TXT/EPUB同主体会共用封面，需独立时用不同保存名称；逐书显式关联管理仍待完善。

当前缩略图缓存版本6，包含来源和预算等有效性/失败控制；大小/mtime可用于可重建缩略图的变化探测，不能作为书籍身份。保持大小/mtime的外部修改不保证自动识别封面，可停止阅读/传输后重建该缓存。视框/算法/来源变化必须更新对应缓存键，不能把旧低清缓存扩大当原生质量。开发中的分步写入使用`.pnc.tmp`暂存；FAT不能覆盖时以`.pnc.bak`保留旧包，主文件缺失可读取经同样校验的备份，暂存不作为有效缓存。它们仍是可重建缓存，不改变原图与上传目录。

旧卡根及旧books/fonts/wallpapers目录不自动扫描，用户保留原件自行整理到piconano路径。缺目录显示空列表，缺书返回书库并保留内部位置，缺字体回退有效默认，锁屏优先内部缓存/系统默认；不自动格式化或删除历史。

外部阅读背景补充（2026-10-21）：background类别追加为5，既有类别值不变。网页封面/阅读背景透明部分填白，锁屏遮罩保留16级透明度；不透明图片使用4位灰度PNG、五种行预测无损压缩，并与原三预测候选比较实际压缩大小取较小值，不嵌入原照片元数据，处理失败不传原图。手机/PC原文件不修改。LocalSend与USB原件通过设备展示缓存适配，USB直接拷贝不能承诺已执行网页缩小。

上传完成并归还TF后，已有安装通知使对应缩略图失效并在首页空闲预热；通知溢出仍保留受影响类别并重建该类缩略图。完整原生缓存按实际预览/应用生成，同一源只保留该用途的当前变换，损坏可删重建；背景更换只保留当前内存底图。选中背景由逐书schema8持久保存文件名与完整SHA，同名内容被替换后需重新选择；源缺失/摘要变化时先用白底，字体、排版、位置和原引用保留。缓存不是用户原件，不扫描进入书库，不迁移/删除旧资源。
