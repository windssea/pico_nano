# 存储卡目录与上传规则

SD卡挂载点在固件内部为 `/sdcard`，用户看到的卡根目录按以下规则划分。目录名是跨平台路径标识，界面类别仍用中文。

| 卡根相对路径 | 保存内容 | 使用方式 |
| --- | --- | --- |
| `/piconano/books/` | 校验通过的TXT/EPUB书籍 | 书架读取；未实现格式不能因扩展名正确而安装成功 |
| `/piconano/fonts/` | 校验通过的TTF字体 | 字体管理/选择；上传不会自动替换当前字体 |
| `/piconano/covers/` | 书籍封面JPEG/PNG原图 | 与书名主体一致，例如绍宋.epub对应绍宋.jpg |
| `/piconano/wallpapers/` | 锁屏JPEG/PNG原图 | 锁屏设置中预览、裁切、旋转并应用 |
| `/piconano/.readpico/covers/` | 生成的缩略图缓存 | 系统管理，可重建；与封面原图分开 |
| `/piconano/.readpico/indexes/library.pni` | 可重建文件书库索引 | 按目录/介质变化失效，打开书籍仍核对完整SHA |
| `/piconano/.readpico/uploads/` | 上传暂存、分块记录、安装恢复日志 | 未完成上传不能出现在书架；不直接手动清理进行中的事务 |
| `/piconano/.readpico/volume.sync` | 设备FAT同步标记 | 设备存储适配管理 |

持久分页窗口暂放内部状态目录的独立`indexes`子目录，最多512边界/书及128KiB全局配额，可删重建；实现及清理边界见[阅读索引](READING_INDEX.md)。

阅读进度、书签及已应用的锁屏A/B缓存在内部存储分区，不因上述目录划分改为放在TF上。

## 所有入口共用的安装契约

客户端只提交资源类别与安全文件名。共享层 `pn_upload_directory` 映射固定目录，最终文件事务创建目录、校验实际格式、核对摘要并完成可恢复安装。热点/家庭网络只是网络通道，设备HTTP和PC开发HTTP共用同一安装层。未知类别拒绝；路径分隔符、绝对路径、上级目录、控制字符、保留名称及不匹配的文件扩展名不能绕过验证。主机文件端口拒绝符号链接路径；FAT真实掉电持久性仍需硬件验收。

同名文件只在同一资源目录内冲突，覆盖需明确确认并核对旧内容身份，不能由客户端指定其他目录或直接写最终文件。传书期间介质独占，关闭/取消/拔卡/锁屏遵守既有停止屏障。临时文件、备份与日志不进入书架。

LocalSend尚未实现：其协议层必须复用上述共享安装层，不能自行按MIME或客户端路径选择目标目录。图片需在设备确认时明确为“封面”或“锁屏图片”，不能把模糊的image类别自动混放；后续USB/转换助手亦须执行同样的分类与介质所有权规则，未实现入口不能宣称已受测试覆盖。

若USB采用电脑直接访问卡的“大容量存储”方式，电脑复制不会经过上传安装层，固件无法强制目录。因此需要全部上传入口强制分类时，USB导入应使用应用层传输协议；不能把直接文件复制宣称为已受目录路由控制。

## 封面来源与兼容

书籍位于books目录时，优先匹配piconano/covers中的同名主体，后缀顺序为 `.cover.jpg`、`.cover.png`、`.jpg`、`.png`。没有集中封面时保留旧同目录侧车；EPUB再回退内嵌封面。选中的外置文件损坏时显示占位，不静默换用其他原图。TXT和EPUB同名主体会共用封面，因此需要独立封面时使用不同保存名称。

缓存版本3记录外置封面候选序号、大小及mtime。添加/删除/通常的修改会使缓存失效；刻意保持大小与mtime不变的修改不保证自动发现，可以在停止阅读/传输后清理缩略图缓存重建。上传封面目前通过同名主体关联，网页自动重命名/逐书绑定管理仍是后续功能。

现有文件不自动移动、删除或格式化。旧版卡根和旧 books/fonts/wallpapers 不再自动扫描；用户保留原文件并自行整理到 piconano 对应目录。书籍目录固定，不因上传而切换扫描根。目录或文件缺失不删除内部进度记录；书库/字体/壁纸目录缺失显示空列表，缺失书籍返回书库，字体回退到内置默认，锁屏继续使用有效缓存或系统默认。
