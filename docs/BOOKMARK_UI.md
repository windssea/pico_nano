# TXT书签界面与编辑

0.0.11将每书100条持久管理连接到设备与PC：列表、添加当前页、选择、跳转、返回原位置、改名草稿、删除确认。范围目前是TXT，不代表EPUB/PDF或第一版全部功能完成。书签记录和源位置契约见 [阅读状态](READING_STATE.md)。

## 操作

设备点正文顶部“书签”，列表每页六条。添加保存已经成功显示的页首，同位置返回已有书签并定位到所在列表页。点条目进入操作页，再选择跳转、修改名称或删除；删除先显示确认页，取消保留记录。删除当前列表页最后一条时，自动回到前面仍有条目的页。跳转后正文顶部“返回”回到跳转前源锚点；字号改变后按同一源位置重排。

设备软键盘支持字母、大小写、数字、空格、点、连字符和下划线，提供退格/清空/保存/取消。当前没有设备中文输入法。名称最多48 UTF-8字节；PC可通过SDL系统输入法提交中文或其他合法UTF-8，退格按完整字符删除。输入太长或非法时保留原草稿；取消不写文件，保存同步成功才更新列表。

两种PC窗口（--book或--library）均可按M打开书签，U返回跳转前位置。列表上/下选择，Enter进入操作，A添加，PageUp/PageDown切页；操作页J或Enter跳转，R改名，Delete打开删除确认；名称编辑用系统文本输入，Backspace退格、Delete清空、Enter保存；确认页Enter确认。Esc按界面层级返回/取消，从正文退出或返回书架。鼠标与设备使用相同逻辑坐标命中及释放提交规则。

名字绘制先用常驻UI字体，缺字尝试会话已选正文TTF的36px独立引擎；不放大正文位图，不改变正文大小。没有字体覆盖/内存不足或打开失败时仍有方框退路。此处只解决书签名称，书架及完整字体管理的回退仍待完善。该回退引擎按需打开、至会话关闭保留，拔卡先关闭再释放字体源，全部引擎计入既有2MiB池；BSP/任务/文件系统另计。

同一位置再点“添加当前页为书签”不重复写入：逐页比较已有书签的位置（TXT原文偏移，EPUB章节路径与语义位置），找到即选中并提示“当前位置已添加”。列表为带书签图标的卡片行，EPUB显示“第 N/M 节”，TXT显示已读百分比；成功提示不显示“重试”。

## 呈现与安全边界

界面模型与成功呈现分开。进入删除确认需要先成功推屏/SDL呈现；呈现失败则输入被阻拦，重试只重画，不自动删除。只有再次确认才写墓碑。设备失败呈现最多每秒重试一次；列表重试可以重新查询，编辑重试保留草稿，不能自动保存。单指滑出、无效读数、多点取消仍由共享触摸识别器处理。

覆盖界面复用阅读帧、保持正文visible位置；列表/键盘/确认本身不计翻页或写阅读进度。退出/跳转复用阅读显示确认，失败留在原界面；只有本次导航确认才能退出，不能复用此前成功的标志。显示确认后保存仍可能失败，这时位置已显示、dirty和关闭屏障仍保留；软件日志/PC标题的错误反馈并非完整产品保存故障引导，后续存储状态提示仍需完善。

进入/模式切换/未知参考/失败重试使用GC16；同模式修改使用GL16，每12次成功GL16后清一次。正文退出覆盖界面强刷。按键未做DU跟手或250ms合并，仍是同步刷新，实际输入延迟/残影/功耗未实测。

render只绘制，不列目录或读写书签；字体服务允许在有效租约下只读字形源。这项边界替代早期“绘图完全不做I/O”的表述：外部TTF字形是懒读的，禁止的是持久状态与书签操作。换书/锁屏/拔卡取消临时界面和未保存草稿，不能替代正文关闭保存屏障。

## 可复跑验证

```powershell
python tools/dev.py host
python tools/dev.py sdl
python tools/dev.py firmware-ci
python tools/dev.py firmware-board
python tools/dev.py docs
```

host的bookmark_ui测试使用真实TXT/字体/文件操作，覆盖中文草稿与退格、设备键盘命中、48字节限制、显示失败禁止确认、取消/确认删除、跳转/返回、100条17页及删除末页回退。bookmark_ui_fallback使用2.4KB OFL小字体，无网络依赖，验证36px回退源及资源回收；这个样本不是产品字库。

SDL bookmark_window分别跑书架窗口和独立阅读窗口，经真实SDL键盘/文本/鼠标事件完成改名、跳转/返回、取消/确认删除和重启后的空列表；返回界面后的首个正文点击也验证一次提交。脚本事件逐个排队，防止停止系统文本输入时清掉还未进入编辑模式的未来文本事件。脚本的鼠标坐标是逻辑坐标；真实DPI、中文IME候选位置与设备触摸仍需人工验证。

设PN_BOOKMARK_CAPTURE_DIR为已存在目录运行test_bookmark_ui，可保存同源PGM列表/操作/键盘/确认画面；可另设PN_BOOKMARK_FONT为完整TTF测试任意中文名字覆盖。产物是共享绘制快照，不是面板照片，也不是刷新/功耗证据。

已运行软件测试与SDK编译不能代替真机操作、随机断电、坏卡和长时间性能验收。最近20条入口已接入；通用格式书签、字体上传/管理及完整阅读工具栏继续按原第一版范围开发。

布局采用48px页头、36px主要标签/名称/键盘、28px位置说明；控件和键盘最小80px命中。字号均原生光栅化，居中按字体实际度量，名称最多两行。这些字号只作用临时界面，返回正文后常驻UI字体恢复24px，正文大小不变；实际4.7英寸纸屏可读性仍待上板确认。

另有bookmark_ui_bad_glyph测试：只破坏临时测试字体副本的单个中文轮廓，字体容器仍可打开，名称字形报错时回退方框，按钮/编辑/确认保持可用；它不替代任意恶意字体的长时间fuzz和安全验证。

原生EPUB自0.0.32使用同一中文列表、名称编辑、删除确认和输入门禁；原文位置及格式特有跳转通过EPUB会话分派，不生成TXT位置，见[EPUB书签](EPUB_BOOKMARKS.md)。
