# 异步输入、显示回执与邻页预排

2026-10-13 开发实现。产品入口使用同源 `pn_async` 邮箱与取消范围，FreeRTOS 和 SDL 只替换线程、事件和显示端口。主机测试、可见窗口与两套固件构建分别验证软件行为；面板时延、欠载、PSRAM 带宽、栈水位和功耗仍需真机验收。

## 执行与所有权

设备输入任务在 core 0、优先级 6，按 10ms 节拍读取触摸并归一三键/阅读手势，电源短按按 100ms 节拍取事件。它只借用稳定 BSP 句柄和原子上下文，不访问页面、字体、池或介质租约。产品 worker 在 core 1、优先级 3，独占模型、文档、字体、`pn_pool` 和租约。唯一显示任务在 core 0、优先级 5，拥有扫描、参考像素与高压轨空闲期限。任务栈配置分别为 4/32/8KiB；这些是配置值，尚未测水位。

SDL 书库入口由主线程拥有窗口、事件泵和纹理，产品线程运行同源控制器。PGM 截图写入也留在产品线程。单书 `--book` 仍是原有格式调试窗口；异步产品验证使用 `--library`。

显示队列只允许一个不可变借用帧。worker 发出后等真实端口回执，期间输入继续采集；帧不能改写或释放。扫描等待期间不并发预排/解码，避免抢占 PSRAM 带宽。设备显示任务不分配共享池；`shown_px` 由产品 worker 预分配，正文恢复副本只在成功显示后更新。管理页成功呈现推进输入页面代次，旧页面的点击/确认会被丢弃。

## 排队、取消与屏障

邮箱固定为 24 个控制边沿和一个待执行导航，端口载荷最多 64 字节。连续翻页替换未执行导航；已排队的紧急离页/工具请求不会被普通翻页覆盖。控制溢出先取消指针状态，避免孤立松手触发选择。队列锁只做短拷贝，不包含分配、I/O、模型或硬件调用。

空闲邻页/封面准备收到任意输入即取消；返回、首页、阅读工具等紧急请求也取消未交出的前台准备。取消点位于文本字符、XHTML 事件、目录项、4KiB 身份读取、文件/ZIP 读取、字体调用边界、JPEG 进度回调与 PNG 行处理。取消后的页不交给显示端口；资源按原 owner 关闭，位置保留。

封面取消保留PENDING且不缓存失败，回到空闲后重试；不会因快速打开更多而永久留下占位封面。

帧已经交给显示端口后，必须等回执。成功显示的阅读 receipt 在屏障内再次验证介质并提交位置，后到输入不能撤销物理事实；介质失效与显示失败仍拒绝提交。保存/安装事务不强停写任务。锁屏经保存、显示 owner 断轨、输入暂停确认后再进入 PMU/睡眠交接；断轨或暂停屏障失败时保持唤醒。

开书前呈现一次静态“正在打开书籍”，不画假百分比或持续动画。`pn_async_block_controls`进入时清理旧普通输入，读取期间丢弃触摸/确认/翻页连点；仅紧急导航继续投递并协作取消。设备开书view18把左返回/中首页编码为独立取消事件，防止恢复到书架或正文后被误解为确认/翻页。SDL保留Esc/Home/窗口关闭。所有返回路径解除控制门，取消不发布正文、不提交位置；加载帧和其字体在显示回执后释放。

阻塞中的单次文件系统/BSP 调用仍要等其返回。FreeType 内部长调用及各取消片段尚未达到真机 10ms 目标的测量出口；本实现不能据 PC 数据宣称所有 I/O deadline 或 W03 性能门完成。

## 邻页节点缓存

当前页先准备和显示，空闲时预排下一页；实际翻到下一页前保存当前节点供上一页使用。缓存仅保留相邻页的 glyph/image 引用节点，不加常驻全屏 bitmap，也不生成全书页号。TXT 使用源锚点，EPUB 使用资源路径和语义锚点，并分别保存章节入口请求键和实际首字位置，跨章也能命中。

预排使用临时页，不改可见页、历史、receipt ticket、书签或保存状态。命中后仍验证源/介质，并生成真实显示 receipt。重排、字体变化、跳转、关闭和会话代次变化释放/失效邻页。低预算或分配失败可跳过预排，下一次仍正常准备；EPUB 大图绘制前释放可选邻页节点。书架封面与正文预排都只在空闲阶段运行。

128KiB 单章字节缓存继续保留完整 CRC/XML 校验；邻页节点命中可以省去本页 XML/度量，未命中仍完整解析。持久页边界窗口和附近冷反向补排已接入，见[阅读索引](READING_INDEX.md)；样式/事件模型缓存、库索引增量维护和真机性能门仍在 [W04](V1_DEVELOPMENT_PLAN.md) 范围内。

## 可复跑验证

`python tools/dev.py host` 包含邮箱并发/拥塞、TXT/EPUB 前后及跨章节点命中、解析中取消、分配失败、重排、介质失效、显示提交屏障。`device_async` 运行实际 IDF 端口分支，线程替身检查显示阻塞时仍能捕获输入、不可变帧借用、任务启动失败清理、断轨/暂停与旧控制丢弃；它不测真实 BSP。

`python tools/dev.py sdl` 的 `async_window` 用 600ms 模拟显示等待，注入 40 次翻页和等待中的首页/更多，检查合并、输入采集、续读位置及资源归零。测试等待不是面板实测。可见重建入口：

该回归还注入原生窗口焦点事件，检查它们不会覆盖脚本回执；20MiB TXT 冷打开中请求首页能取消准备、保留原书且释放资源。

```powershell
py -3 tools/dev.py sdl-run
docker stop pico-sim
powershell -ExecutionPolicy Bypass -File tools/run_sim.ps1 -Timing -PresentDelayMs 600 -Script 'library,enter,wait:900,race-next-tools:300,wait:300,back,home'
```

不指定 `PresentDelayMs` 则没有人工显示等待。窗口脚本仅开发验证；正常窗口始终可用键盘和触摸模拟交互，不刷机。
