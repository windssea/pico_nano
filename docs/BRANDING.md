# PicoNano 品牌与默认图

产品在各语言中统一显示为 PicoNano，公共定义为 `components/pn_core/include/pn_brand.h` 的 `PN_BRAND_NAME`。界面、模拟器窗口、传书网页、设备状态接口、热点名称及本地测试接收端使用这一名称。旧版自有示例书作者和内置字体名称仅在显示时映射；资源文件名、阅读记录键、字体原始元数据、硬件来源与许可证保持原值。

## 开机图与默认壁纸

源文件为 `assets/image/logo.png`，1254×1254 RGBA。构建脚本 `tools/build_brand_image.py` 检查 PNG 完整性，将透明区域合成白色，裁去外围空白，再按比例缩放到 560×900 安全区域内。当前图案为 560×323，居中放入 684×1216 画布，左上角为 (62,446)，完整保留书形和 PicoNano 字样。

构建生成 16 灰阶、4bit 像素数据，约 90KB，源图不修改。运行时直接复制到已有帧缓冲，不再解码 PNG 或额外分配图像缓存。开机临时帧在显示后释放；设备只在有效 VCOM 和 PMU 就绪检查通过后显示开机图，不增加固定停留时间。可见模拟器通过 `PN_SIM_BOOT_PREVIEW=1` 短暂展示开机图，方便观察。

默认锁屏复用开机图，底部操作提示独立绘制。已保存的简洁、用户壁纸或书封选择继续生效；选择“默认”即可预览或应用该图。锁屏提示描述实体电源键，模拟器的 L、回车、Esc 操作只写在开发说明，不显示在产品画面。

## 验证边界

自动测试检查裁剪比例、透明合成、数据稳定性、坏 PNG 拒绝、开机与默认锁屏像素一致、帧缓冲释放，以及 VCOM/PMU 失败时不推屏。SDL 验证原生尺寸帧和可见窗口；面板实际灰阶、清晰度、刷新时间与功耗仍须真机验收。
