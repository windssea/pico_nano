# 字体目录、信息与样例预览

0.0.35新增字体专用分页、实际元数据读取、稳定资源对象和中文样例面板；字体选择菜单、正文原锚点预览/应用和上传/替换/删除流程仍未完成。本阶段不是完整字体管理产品。

## 目录与校验

pn_catalog_font_page及before复用有界六项目录扫描，按UTF-8文件名升序，仅识别TTF扩展名，保留原文件名/大小/路径，不混入书架。扩展名识别不等于字体有效；错误媒体和IO保持原状态，PC不跟随叶符号链接，设备FAT使用stat。扫描不是字体完整索引，仍O(N)，没有递归、自然排序、后台批次或时间片。

pn_font_asset_open用独立READ租约和稳定私有地址保留文件、源回调、字体引擎、完整SHA引用及信息。外部guard必须保持有效，asset不释放guard，不移动活动pn_text_file。路径按[选择记录](FONT_PREFERENCES.md)的绝对UTF-8规范，大小12字节至32MiB，expected_size可检测目录快照后大小变化。真实引擎按已有单glyf TTF规则校验，关闭/失败释放资源，不写字体或选择记录。调用方排除并发字体修改。

## 信息边界

pn_font_info返回UTF-8族名、样式名、OS/2字重、字形总数及可变表标志。族名优先标准Windows中文语言记录，同语言优先typographic名称。最多扫描256个名称记录，每条最多处理2048字节，输出各128字节；正确处理UTF-16BE补充平面与代理对，拒绝控制字符、坏代理对及旧编码误作Unicode。Mac名称仅接受ASCII；不支持/过长的名称跳过并标示names_limited，缺失可显示文件名或未提供名称。

原始样式名保留在API中，面板将Regular/Bold/Italic等标准名称显示为中文，未知自定义名称和字体品牌按原文保留。字重是原始OS/2的1..1000值，0为未知，不推断任意加粗或当前可变轴状态。variable只标记fvar表存在；尚无轴选择。字形数量含.notdef，不等于中文字覆盖数量。

## 样例与绘制

pn_font_asset_sample检查最多128个Unicode样例的字形映射和实际灰阶光栅；缺字计数只覆盖这些样例，错误保持输出。样例中可以重复字符，计数不是全字体唯一字符统计，也不是全书覆盖率。暂存小画布走pool，不在设备栈上放大型像素阵列。

pn_font_preview_draw纯绘制已校验模型，展示中文标题、字体族/样式、字重、字形数、文件字节数、样例缺字数量及实际字形。正文样例直接用候选字体，缺字画方框，不用备用字体掩盖缺字；字体族名可借候选补绘常驻UI子集缺失的字，系统标题/提示仍使用独立UI字体。样例底部明确“样例检查不代表全部字符”。面板不选字体、不写配置、不修改阅读位置。

host的font_asset_capture FONT_ABSOLUTE OUTPUT.pgm可复跑同源684x1216面板；输出和本机字体留在忽略的build目录。此入口不是已有设备/PC字体选择交互，也不代替阅读中原文预览。

## 验证

python tools/dev.py host包括：字体六项分页/前页/大小写扩展名/书架隔离/符号链接/失效媒体；元数据与原字体源失效输出保持；独立标准库SFNT重建验证中文优先、UTF-16补充字符、坏代理对、过长名称、旧编码及原始字重；asset源地址保持、映射/光栅检查、源大小变化、READ租约归属、媒体失效和每个观察到的打开分配失败回收；中文面板实际捕获。原TXT/EPUB、选择恢复、排版、目录、书签测试保留。

实际本机霞鹜文楷：族名正确显示“霞鹜文楷”，字重400、14178字形，102个样例字符中3个缺字并显示方框，pool峰662062bytes、关闭0。完整静态Noto Sans SC字重400、样例缺字0；本机可变源正确标出variable=true和原始默认字重100，样例缺字0、pool峰619453bytes。仅为有限样例和软件绘制验证，不宣称全字库、整机资源、刷屏或真实屏视觉验收。

稳定资源已用于正文原锚点预览/取消/应用和全局/逐书/备用选择。使用中替换/删除的源关闭屏障及上传服务仍待完成。SDK实际链接入口，真机体验尚未验收。
