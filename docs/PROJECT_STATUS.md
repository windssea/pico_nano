## 下一批待办与依赖

1. **最高优先级技术门：**原生PDF许可/引擎/资源样机，以及第一轮板级安全启动、显示/无线/TF同步实测。PDF不被转换方案替代。
2. **传输产品闭环：**STA配网/扫描/保存，真实手机扫码及AP/STA上传，新建回复丢失的ID找回、孤立会话管理；保持停止屏障和介质独占。
3. **阅读资源闭环：**字体引用/覆盖/删除与回退、封面回退来源/网页替换与网格大图、锁屏壁纸选择/裁切/灰阶/缓存。
4. **阅读体验与格式：**广泛EPUB语料、分页/预绘制/热翻页、三键/手势，T02通过后PDF产品化，随后FB2/CBZ与搜索/分类/收藏。
5. **维护和发布：**睡眠/关机/唤醒及功耗、USB技术门、OTA回滚、完整稳定性和发布包。

未取得真机证据的门不以绿色主机测试替代。USB可在其硬件门未过时不纳入1.0，但原生PDF及用户明确要求的基础功能不删减。开发继续按阶段提交，本机样本、过程账本、日志、截图和编译产物不入库；必要字体/测试fixture及许可证例外保留。
