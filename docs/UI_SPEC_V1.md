# Pico UI 规范 v1.0 落地对照

依据：用户提供的《墨水屏电子书完整 UI / UX 设计规范 v1.0》（2026.10.10，概念方案到产品化落地规范，原件不入库）。规范以 360×640 DU 为画板，本机逻辑画布 684×1216，换算系数约 1.9（1 DU ≈ 1.9 px）；规范自身声明尺寸、灰阶与按键事件均待真机确认，下表只记录当前实现与差异，不代表真机验收。

## 已落地

## 尚未落地或与本机硬件不一致

- **按键模型**：规范按“左/右翻页键＋Home＋锁屏开关”设计（Home 回书架，左右键只分页）；本机是屏下 KEY1/KEY2/KEY3 与电源键，当前 KEY2 在阅读中开工具栏、长按回书架，并在设置/目录等页用 KEY1/KEY3 移动焦点、KEY2 确认（见 [界面与交互](UI_UX.md) 第7节）。是否把 KEY2 改为“Home”语义、列表页改为左右键整页翻，需要产品确认后再改。
- 状态带不显示时间：设备 RTC 未确认对时，不显示可能错误的时间。
- 书库搜索只匹配书名（拼音首字母/英文），没有作者、格式筛选与最近搜索记录；书内搜索（S07）未实现，工具栏“搜索”标为不可用。
- 排序只有书名排序；规范的“最近阅读/导入时间”排序、书籍长按管理（重命名/移除/详情）未实现。
- 字体管理没有逐字体中文样本与“导入字体文件”按钮（导入走传书）；锁屏壁纸没有缩略图网格与锁屏时间预览。
- S13 按键与手势设置页未做；底部上滑呼出菜单未做。
- 阅读页脚不显示章内页码（“8/…”），EPUB百分比只到章节起点。

主机截图与模拟器画面不代表墨水屏灰阶、残影与触控手感，均需目标样机复核（规范第 9、13 章）。
