# 正文字体回退

0.0.33在TXT与EPUB阅读会话接入有界回退链：正文字体、可选用户备用TTF、常驻中文UI子集。主字体已有字形时保持原字形；只有EMPTY才继续下一层。所有层均无字形才画缺字方框。常驻子集只能补其覆盖的字，不是完整中文库。

## 度量、绘制与资源

同一码点使用同一引擎的advance、ascent/descent及实际字形；不会拿主字体的方框宽度绘制另一字体。备用按主字号设置原生像素尺寸，原字形不拉伸。TXT行框取各有效字体最大垂直度量，EPUB按选中字体度量合并行框。更换字体会改变行数和换行，位置仍是原文字节或语义锚点。

备用字体源由会话持有只读介质租约。链借用主字体和源对象，备用引擎分配走pn_pool；副引擎按需打开，大图前关闭并保留配置，之后按需重开。关闭/拔卡释放或失效对应资源。字体文件不整本加载到内存，尚无字形LRU缓存、后台分页或延迟保证。

主字体、备用源出现IO/损坏/失效媒体/分配失败时保留实际错误，拒绝推屏确认，不能把它们当缺字跳过。输出选择/度量在错误时保持不变。常驻UI字体继续独立于用户正文链，设置页文字不随用户字体更换。

## 当前配置入口

两种应用提供fallback_font(app,path)，只允许首次实际显示前绑定一个备用TTF。先用真实引擎校验，失败释放候选源并恢复原回退配置；已显示或已有备用返回BUSY。这是启动装配接口，尚不是完整字体管理界面，独立启动接口本身不持久保存路径；0.0.34新增的[字体选择记录](FONT_PREFERENCES.md)可在下次打开时恢复正文与备用选择。后续管理需要原锚点重排/实际显示、逐书与全局继承、使用中替换/删除的源关闭屏障。

PC独立阅读及书架窗口可使用--font PRIMARY.ttf --fallback-font FALLBACK.ttf；headless旧TXT捕获入口拒绝该参数，避免静默忽略。EPUB实际应用捕获设PN_EPUB_FALLBACK_FONT为本地路径。设备已使用常驻子集末级回退；用户主/备用字体选择及逐书/全局偏好后续已接，见 [字体偏好](FONT_PREFERENCES.md)；不猜测卡上文件名，资源管理与真机验收仍待完成。

接受格式沿用既有单glyf TTF、32MiB、8..128像素约束，字重/可变轴选择和上传管理尚待完成。路径是受信任的启动配置，不允许直接使用上传方任意路径。

## 验证

python tools/dev.py host：font_chain用真实受限字体及常驻字体验证优先级、可选源选择、字号同步、同源度量、缺字与输出保持、主/备用源失效不吞错、备用打开各分配失败回收。TXT/EPUB应用验证无效路径后仍可绑定有效源、显示/保存/重开/拔卡清理。原导航、排版预览、书签和保存测试保持。

python tools/dev.py sdl：font_window检查实际TXT/EPUB/书架窗口源绑定、翻页、重排预览/取消、保存关闭及零保留分配。其他窗口测试继续覆盖目录/书签/最近/样式。

本机用户小说与霞鹜文楷：独立OFL字库Noto Sans SC固定本机源生成静态400字重作为测试备用，原文件不改。样本记录的33个正文缺字在28/32/44/56/72像素度量和灰阶/二值绘制均无缺字；当前小说第二页的两个方框实际补齐，原锚点text_003.xhtml element13/run0/offset14不变，pool峰1675754bytes并释放到0。该结果不代表全书所有页面、所有字体/语言或纸屏视觉验收。测试完整字体及截图保存在忽略的build-dev，不随产品分发。
