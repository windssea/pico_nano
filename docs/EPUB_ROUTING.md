# TXT/EPUB混合书架、最近阅读与设备入口

0.0.28把原生EPUB应用接入PC书架与设备app_main的已授权阅读路径。设备代码已装配但尚未烧写/真机验证；软件接入不能称面板/功耗验收通过。原生接口/独立窗口见 [EPUB应用](EPUB_APP.md)。

## 分派与保存

目录项TXT/EPUB分别打开各自实际控制器，输入前后页/字号、定期tick和关闭按当前格式分派。EPUB仍完整验证mimetype/OPF/XHTML/图片，不把“扩展名识别”当支持任意容器。PDF/FB2/CBZ等已有识别项仍不能因此打开。

切书、返书架、锁屏、拔卡沿用原保存屏障；失败不释放活动会话/dirty。实际推屏及显示回执才能确认位置，不写电源标定寄存器。设备开机VCOM只读、未标定不推屏、NVS/文件系统不格式化策略保持。

PC进入EPUB前释放书架字体与frame，保存/关闭成功后按需重建；目录页与最近快照保留。设备FAT/LittleFS VFS使用stat确认目录，PC以lstat另外拒绝符号链接；不假定ESP-IDF支持所有POSIX函数。失败打开仍重画书架。不能为了大图片把书架frame和全部字体都长期重叠保留。

## 最近20条与继续阅读

EPUB首次实际确认显示和成功关闭时触碰共用PNRH，format=2、完整实例路径/原文件大小/内容SHA，进度预览用UNKNOWN，不伪造按章节数推算的百分比。逐书PNEP原文位置仍是真正续读来源。相同MRU内容不重复写入；最近记录写失败也阻挡关闭供修复。

继续/历史打开首先比对实际原字节SHA与历史身份，再呈现；同路径内容改变拒绝旧记录，历史及旧位置不清除。源码别名的去重与20条上限沿用共用最近记录契约。PNRH不是跨平台同步服务。

## 设备预算与界面边界

BSP已分配后读取实际free PSRAM，将应用pool限为min(6MiB, free-256KiB预留)，不是预先占用整个pool。大渐进式若剩余预算不足明确NO_MEMORY，不绕过预算/申请普通malloc。预留值只是软件保护，还没有实测整个8MiB PSRAM、最大连续空闲块、DMA/Wi-Fi并行及长时间碎片；第一版硬件验收必须覆盖这些条件。

当前EPUB页面已提供中文阅读控件和书名。TXT书签/七项草稿UI保持可用，EPUB同区域不派发无效TXT控制器；共享目录界面已接入，见 [目录UI](EPUB_TOC_UI.md)；EPUB书签与七项预览现共用中文界面，见[EPUB书签](EPUB_BOOKMARKS.md)及[排版设置](TYPESETTING_SETTINGS.md)。设备已接EPUB翻页/字号/返架/继续，不能说全部菜单已完成。保持用户书名/正文/必要格式原文，其余产品UI中文。
