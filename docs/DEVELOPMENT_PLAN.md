| 3 | 持久续读页、图像/字形变体、可选同源PC编译器 | 已验证命中时的软件准备P95目标<=100ms；总时延分别记录面板扫描与CPU/TF成本，目标不冒充已实现 |

先做两本真实EPUB（文字/大图或超长章）及一个大TXT的原型，不先铺全书全文搜索或通用数据库。每阶段保留旧管线A/B：未识别首次打开、已验证但清空RAM的重开、已预备热开、跨章首NEXT、快速连续NEXT、反向和图片回翻分别测P50/P95/P99；同字体/布局/锚点与完整数字帧对照，另测真实光学、内存峰、磁盘放大和后台能耗。后续全文检索、准确总页数和批注跳转可复用内容/页表，但不在原型前宣布支持。本方案独立于1.0.6 loading批次，不自动混入该版本或执行大范围内核改造。

## 规划：TF资源与缓存统一策略（2026-10-23，总体方案，分阶段推进）

用户进一步要求覆盖索引、缓存、壁纸、字体等资源的生成、读取、写入，以及卡上缺文件时的正常退路。本节扩展上面的整书索引方案；优先复用现有格式/适配器，统一身份、生命周期和调度，不先重写全部缓存或引入数据库。本节保留总体目标，已落地行为以“当前执行”和现行架构为准；其余规划不写成已支持。

### 存储分工与现有基础

| 层 | 保存内容 | 边界 |
| --- | --- | --- |
| 内部Flash | 进度、书签、设置、已应用锁屏壁纸A/B、应急资源、少量有界可信根 | 用户状态不能当缓存回收；锁屏继续具备无TF退路；可信根记录合并提交，不逐字形写Flash |
| TF公开目录 | 原书、TTF/OTF、封面、锁屏原图、阅读背景原图 | 沿用固定资源分类与安装事务；不以派生包取代或静默改写用户原件 |
| TF私有目录 | 可删除重建的内容包、页表、页计划、图像变体、字体元信息/字宽/字形包 | 统一全局/分类配额与低空间退让，丢失只影响性能；未验证缓存不能获得用户状态的地位 |
| RAM工作集 | 当前内容块、邻页描述、现有字形/源块缓存、当前底图及原预绘帧 | 保持6MiB池及分类硬顶，沿用可回收/借用保护；新索引不常驻整书或另增全屏帧池 |

已有TF书库索引、封面缩略图、壁纸/遮罩预览、阅读背景缓存和RAM字形/菜单/图片缓存；新增的是跨资源的统一规则及可随机取用的持久阅读成果。pn_wallpaper_preview目前在完整预览命中时仍整读原图SHA，prepare_cached还同步尝试写回；pn_paper已保证普通翻页不读取/解码背景。pn_font目前已有字宽与带亚像素偏移的字形RAM缓存，字形保存256级覆盖率，再按原算法合成16灰阶画面。因此背景落盘优化主要改善预览/应用/重开，不能宣称已经零图片IO的普通翻页再获同等提速；字体持久化也不能把覆盖率降成4位来省空间。

### 按资源保存什么、怎样复用

| 资源 | 持久成果与读取策略 | 生成/失效条件 |
| --- | --- | --- |
| 书库/资源目录 | 规范路径、类别、显示名、关联和变化提示；先显示已确认列表，分步核对目录，缩略图按当前可见行取用 | 安装通知定向更新；USB/重新挂载后校对；目录缓存不能证明原书身份，也不能长期展示已确认删除的原件 |
| 书籍 | 上节的分块语义内容、章节定位、布局页表/覆盖范围和近期页计划；从语义位置直达所需块 | 完整原书SHA绑定内容；字体/几何/引擎变化只失效有关布局；背景变化不重建几何页表 |
| EPUB内图/封面 | 原算法、目标尺寸下的无损解码结果，书内图绑定原书SHA及资源定位；缩略图与正文原生变体分开 | 解码成功后按重用收益准入；源/裁切/旋转/尺寸/量化与解码版本变化失效，不能扩大低清缩略图冒充正文 |
| 壁纸/阅读背景/遮罩 | 延续已有144×256缩略图及684×1216原生缓存；按用途保留灰度/透明平面与精确变换 | 选中或预览后生成原生结果；安装后先预热可见缩略图，不在上传事务内展开所有裁切变体；应用锁屏仍提交内部A/B |
| 字体目录/预览 | 名称、字重、格式、覆盖提示及固定样张；列表不为显示一行反复全开字体 | 完整字体摘要/解析版本/样张文本与绘制参数组成键；字体样张缺字仍用缺字框，不让后备字体伪装候选覆盖率 |
| 字体字宽/字形 | 常用码点到glyph的映射、精确advance/缺字结果，按实际字号/样式生成的覆盖率块包；UI与阅读可共享同身份资源 | 不预生成所有汉字×全部字号；字体SHA、face/charmap、glyph、字号、亚像素相位、hinting/载入标志、合成字重、清晰度、引擎版本等均进入有关键 |
| 续读页/静态UI | 最近已确认正文像素与页描述可选持久化，菜单/样张静态部分按需复用 | 必须绑定实际字体、正文像素样式和背景身份；时钟、电量、日期、阅读进度等动态层即时绘制，不能将旧快照当新状态 |

字体的跨书共享以完整字体身份为基础，不能只用文件名或码点；若未来支持可变轴，轴坐标也须进入身份。持久字形先按页/若干字形批量载入原RAM缓存，再绘制，避免每个字一次文件打开/seek；用少量pack文件，不能每字一个小文件。字体元信息/字宽先试，光栅落盘必须证明“读包+解压+校验”比现有FreeType与源块缓存更快才启用。图像同样按复用概率、生成成本和体积准入，一次性大资源可沿原流式处理，不为凑命中率无限写卡。

### 生成、读取、写入生命周期

统一描述记录资源键、依赖摘要、schema/算法版本、媒体代次、生成代号、覆盖范围、长度上限和完整性信息；协议统一，资源载荷格式可以不同。缓存状态至少区分未生成、生成中、可用、失效、暂不可写；底层错误保留诊断，上层正常缓存MISS不显示“操作失败”。

1. **生成**：用户当前页/当前预览优先，随后NEXT、反向邻页，再是持久化、整书补齐和其他缩略图。首次缺缓存直接使用原管线得到可用结果，有价值的中间结果顺便保留，不为写缓存重复解析一次。原安装完整校验可交接同一受保护媒体代次的源身份；事务提交、归还TF后才启动派生任务。空闲/充电只是准入条件，还要满足电量、内存和近期操作预算；不能读书期间无节制全卡预编译。
2. **读取**：先RAM，再已验证TF块/图像包，最后回原件与内置退路。读取前先校验固定头/版本/依赖和长度计数，限制展开量/索引算术，再分配有界工作集；按所需块随机读取、合并相邻请求，避免为一页重读整本内容包、整张全书目录或逐字开文件。启动不全盘验缓存；先恢复当前资源与小目录，剩余校对在后台推进。
3. **写入**：绘制/使用成功与“缓存保存成功”分开；普通资源结果不因可重建缓存写不下而报失败。先产生有界脏块，合并顺序写入少量新代pack；通过固定CACHE_WRITE租约落盘，按批次/提交点同步，避免每字形、每缩略图小块或每次按键都sync。用户进度仍遵守原可靠提交语义，不能与可丢派生数据一起无限延期。
4. **发布**：新代暂存→同步/关闭→完整读回校验→提交代清单/可信记录→允许新读取；未完成文件不参与命中。活动读取持有旧代引用，禁止改写/重命名/删除仍打开的包，最后一个借用归还后再回收。重启按完整校验和提交证据选择最后有效代，发现不确定状态就MISS重建，不能只取最大代号/最新mtime。
5. **取消/交接**：用户翻页、换书、改字体、进入传输时取消无关预热；可接续工作只记录已确认块/覆盖范围。USB独占前停止任务并关闭所有源/包句柄，旧epoch立即失效；上传/USB/换卡后重新建立信任，不能继续借用旧指针或旧未校验结果。

FAT写入/rename不是跨文件掉电事务。新旧代/备份用于检测及恢复，不能承诺文件系统任意掉电绝不受损；失败保持旧可用显示与用户记录，不自动格式化。顺序多扇区与扇区对齐作为优化候选，块大小先沿上节8/16/32KiB实机筛选；必要时评估pack预分配/文件seek加速，但不能预分配整卡或绕过存储owner。每次fsync、close、分配簇和GC都可能长阻塞，单独统计最坏耗时；扫描期间不强行塞入大写入。

### 完整校验与精准失效

- **已有源身份保护继续复用**：同一有效READ保护、介质实例/epoch、源WRITE计数与规范路径匹配时，可复用已完整算出的身份。当前pn_text_file已有8槽备忘，扩展图片等入口时沿用其信任边界，不另造只看mtime的捷径。CACHE_WRITE只可改固定派生目录，不能替换源；普通写入/USB、换卡/重挂载使有关证明失效，PC外部修改也不受设备租约保护。
- **跨重启不凭TF声明信任**：TF包内自报原书/字体SHA不能证明源没变。未知/失效代次按原要求完整验证原件，再匹配缓存依赖；保留现行延期字体复核的提交屏障，不能让缓存绕过它。严格完整校验下，首次未知文件或换卡后的整源读取成本仍在，不能承诺所有冷开都是百毫秒。
- **大包按块完整核验**：设备完成构建和读回后，用有界内部可信记录绑定已提交manifest摘要；manifest列出的块摘要受该根约束，每个实际消费块完整校验。大manifest可分层按页认证，不能为验证目录把全表放RAM，也不能只检查TF上可同时伪造的CRC与自报SHA。没有可信根时先走完整验证/原生成管线，不能将不可信外部语义结果仅凭源SHA相同就视作正确编译；PC提前生成以后单独设计验证出口。
- **分离依赖**：换背景只失效有关正文像素，保留几何页表；换字号保留源语义，切换目标布局变体；换字体只影响使用该字体的布局/字形；引擎或格式升级按版本懒重建，避免启动时删除全卡重建。布局身份采用实际生效的主/补字体，不拿缺失时的保存偏好冒充已加载字体。

### 缺文件、坏包与容量退路

| 情况 | 产品行为 | 后台行为 |
| --- | --- | --- |
| 私有缓存目录/文件不存在 | 正常从原件打开/预览，列表先用占位；不弹通用错误 | 可写且获得owner后按需建目录/重建；无TF/USB期间不尝试mkdir |
| 坏CRC/摘要、截断、版本不兼容 | 拒用坏包，回原件；新结果未完成前不覆盖当前有效资源 | 记录一次诊断并退避；仅隔离/回收确定为本组件拥有的坏缓存，不删整个私有树或uploads |
| TF只读/已满或缓存配额耗尽 | 已有有效缓存照读；原件正常处理，新缓存写失败不阻断本次使用 | 停止可选写入，容量/介质/任务条件变化或显式重试后再恢复，不能每帧重试/强制清卡 |
| 缺字体原件 | 按现行规则用有效默认完整字体，再用内置应急字库；保存原选择 | 实际字体变化使用相应新布局键，后续找回字体再按原选择恢复；应急字库不能保证全文覆盖 |
| 缺壁纸/背景原件 | 已应用锁屏保留内部A/B；阅读背景白底、保留引用；列表占位/默认封面 | 不把旧TF缩略图当应用授权，不静默选另一张同名资源；找回/重新选择后再验证 |
| 缺原书/书籍目录/整卡 | 返回可用书库空态或提示“书籍未找到”，保留进度/书签；不崩溃、不无限loading | 原件恢复再校对；不把局部页快照伪装为可继续阅读整书，不自动格式化 |
| 构建中断/掉电后残留 | 忽略半成品；有已校验可用旧代就复用，否则正常重建 | 有界检查恢复记录，择机回收失去引用的自有临时文件；不清理活动安装事务 |

缺原件不能靠可丢缓存保证全部功能，尤其完整书籍内容与字体覆盖；“不报错”指可选缓存缺失不升级为用户操作失败，真实资源缺失提供清楚且可返回的状态。失败退避/缺失记忆绑定媒体代次、源变化提示和资源键；避免每次翻页都重复查不存在文件，安装通知/重挂载/相关配置改变或用户重试再放行，不能永久负缓存挡住新资源。

磁盘空间采用全局硬配额、分类软/硬配额、单书/字体变体上限、低水位保留与新旧代暂存余量；具体数值由卡容量、生成放大和实机成本确定，不把空卡可用空间全部占满。LRU年龄在RAM累计、批量记账，不能每个命中写一次卡。当前读取/预备页与应用中的资源暂时pin，按重建成本/最近使用/体积淘汰闲置派生包，超过配额也必须能退回原件。GC分批且让出前台，manifest损坏时允许暂时停写并后台有界重建目录统计，不在首次开书递归扫卡；只清自有派生路径，原件、状态、uploads和未知文件不自动删除。

### 落地顺序与验收

| 优先级 | 实施范围 | 应证明的收益/退路 |
| --- | --- | --- |
| P0 | 从现有壁纸/背景/封面缓存接入共同身份与结果分类、延迟写回、缺失退避、代次/借用保护和计数 | 预览/应用少重复整源校验（仅信任边界内），缓存保存失败仍显示正确；不改变当前资源目录与像素 |
| P1 | TF内容块、章节/整书页表逐步覆盖、当前页/首次NEXT优先、书内图变体 | 未命中可读，跨重启/换书可复用；正文准备不反复章首重放，图片回翻保持精确结果 |
| P2 | 字体元信息/样张/字宽持久化，测量后决定字形块包、近期页计划/续读像素 | 字体切换/冷字供数实测有收益，避免字形随机IO比重新光栅还慢；少见字与任意字号可原路处理 |
| P3 | 可选同源PC预编译、全文搜索等复用能力 | 外部缓存独立验证，设备自身仍能生成；不让桌面工具成为基本阅读依赖 |

对照需包含首次未知资源、同代已验证重开、断电/重挂载后重开、跨章首次NEXT、连续NEXT/PREV、图片回翻、字体/背景预览应用和大书库首屏。记录P50/P95/P99、首次可操作时间、完整SHA/解码/排版/读取/同步各自成本、命中/失效/退路原因、读写字节及放大、生成/淘汰/取消的无效工作、磁盘占用和后台耗电；池/分类峰值、内部堆最小余量及最大空闲块也要核对。热命中不能掩盖首次构建成本，后台能耗不能只看前台变快。

故障注入至少覆盖缓存全删、目录不存在、只读/满卡、包截断/错版本/异常长度、同名同大小同mtime的源替换、文件句柄在用时GC、构建/发布各阶段中断、USB交接与实际拔卡。主机/模拟器验证状态机与逐像素一致，真机另验TF长尾、面板扫描/光学和真实断电恢复；诊断启动不等于这些验收。本次只完成设计与文档，不构建/刷写/发布，也不把本方案自动并入尚未收口的1.0.6批次。

- **P1 取消遗留开书门并可阻止解锁恢复。** `stop_reader_impl`先清identity_takeover_active，导致`opening_abort`错过解除opening的分支；不存在foreground任务及挂起结果时opening保留为true。探针复现：接管→退出→首页→锁屏→电源唤醒，仅新增锁屏帧，locked已为false却仍opening=1，`start_reader`直接返回，屏上保持锁屏图。需统一任务、加载门、回执与取消出口；接管完成也不能绕过`start_reader`对opening_overlap_result的消费。此软件路径可形成用户所述症状，尚未证明真机本次一定经过该路径，独立PMU/显示恢复故障仍需设备日志区分。

### 任务顺序与依赖

1. **P-00 → P-01 → P-02 → P-03**：先拿掉字体完整SHA和fallback成本，风险最低。
2. **P-04 → P-05**：让已有身份缓存真正抢在点击前，且不重复读。
3. **P-10 → P-11**：先测清TF瓶颈，再决定读块改动；与阶段A/B可并行。
4. **P-06 → P-07 → P-08 → P-09**：临时身份是最大收益也是最大语义变更，必须最后做，默认关闭。
5. **P-12/P-13/P-14**：首屏小项，在A/B后按设备数据取舍。
6. **P-15**：每阶段都可先跑单场景，最终全矩阵；不以主机计数替代设备验收。

### 非目标与硬边界

- 不实现PDF/MOBI/FB2/CBZ阅读；PDF仅保留枚举兼容，旧索引重建后不再出现。
- 不改波形/刷新策略；面板时长以当前板级诊断为准，不能把历史约0.5s当作固定下限。
- 1-bit SDMMC 40MHz是硬件上限；4-bit需要改板，不在软件范围。
- 临时身份不是安全认证；完整SHA仍用于跨设备/长期身份，后台完成。
- 任何“已提速”结论必须来自设备`-diag`同书/同字体/同刷新模式A/B；主机profile只用于定位。

## R01：无线/充电故障定位和修复

**目标：**插线状态下网页与安装事务仍可响应，中断有准确原因并能恢复持久偏移。当前设备无重启，不能继续围绕复位假设修修补补。

测量矩阵固定同一设备/卡/路由器/固件/手机文件，分别纯电池、电脑 USB、普通充电器；同时记录电量/线缆/距离/RSSI。AP/STA 分组，WiFi 连接、分块接收、同步、摘要、TTF 校验、安装分别计时。每组传小 TXT 与用户24.4MiB字体，再用5×32MiB受控样本检验有效持久 ACK 速率。

先用已实现 `/api/v1/status` 的 RSSI、断连次数、恢复次数、last reason 和普通阶段日志关联请求失败；增加诊断时不输出密码/token。无线期 USB 数据暂停时日志采集需设计有界内存摘要或网页诊断，不能为了日志重新开启已隔离 PHY。保留失败时间点、I2C 卡检测错误、真实在位状态、媒体 epoch、文件写/sync 结果和内部堆/连续块。

技术分支：

- RSSI/SDK disconnect 明确异常：复核 STA 重连次数、同 IP 保会话、IP 变化终止；检查路由器、射频与插线相关性。PS_NONE 只在活动期，清理必须恢复生命周期。

- HTTP 仍在线但同步/校验很慢：拆 write/sync/SHA/TTF 全字形成本、超时和响应调度，先改善工作分片/进度反馈，不能提前报已保存。
- 仅插线异常：保持 USB/RF 互斥候选，测供电纹波/电压与硬件条件。没有电气测量前不修改 PMU 厂时序，也不宣布供电就是根因。
