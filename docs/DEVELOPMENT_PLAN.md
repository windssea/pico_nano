## R01：无线/充电故障定位和修复

**目标：**插线状态下网页与安装事务仍可响应，中断有准确原因并能恢复持久偏移。当前设备无重启，不能继续围绕复位假设修修补补。

先用已实现 `/api/v1/status` 的 RSSI、断连次数、恢复次数、last reason 和普通阶段日志关联请求失败；增加诊断时不输出密码/token。无线期 USB 数据暂停时日志采集需设计有界内存摘要或网页诊断，不能为了日志重新开启已隔离 PHY。保留失败时间点、I2C 卡检测错误、真实在位状态、媒体 epoch、文件写/sync 结果和内部堆/连续块。

技术分支：

- RSSI/SDK disconnect 明确异常：复核 STA 重连次数、同 IP 保会话、IP 变化终止；检查路由器、射频与插线相关性。PS_NONE 只在活动期，清理必须恢复生命周期。
- WiFi 在线但卡检测返回 I/O：继续区分“未知”与“拔卡”，有界重试期间不提交块 ACK；真实拔卡必须使旧租约失效。不能忽略所有 card detect 以掩盖问题。
- HTTP 仍在线但同步/校验很慢：拆 write/sync/SHA/TTF 全字形成本、超时和响应调度，先改善工作分片/进度反馈，不能提前报已保存。
- 仅插线异常：保持 USB/RF 互斥候选，测供电纹波/电压与硬件条件。没有电气测量前不修改 PMU 厂时序，也不宣布供电就是根因。

**出口：**三种供电状态均完成 AP/STA 的真实 Android/iOS 队列、字体、壁纸与覆盖；断网/熄屏恢复最终文件 SHA 一致，无误报失卡、不提前 ACK、不自动待机。不能复现也保留本组条件与失败率，不能用一轮成功关闭问题。
