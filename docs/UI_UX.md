# 界面与交互规范

设计目标：安静、有层级、可单手操作，所有动作可预期。以下是原生设备像素规范，不是手机 CSS 尺寸。示意：[书架、阅读、排版三屏](assets/ui-overview.svg)。

![三屏布局预览](assets/ui-overview.png)

## 1. 视觉语言

白纸背景、深黑正文、细线分隔、封面承担视觉识别。避免大面积灰色卡片、阴影、渐变、玻璃效果和装饰动画。圆角只用于按钮与浮层，封面矩形保留出版物感。图标采用 2–3 px 线宽的单色矢量轮廓，旁边带文字；图标先转为原生资源再绘制，不把 SVG 解析器放入固件 UI。

| Token | 竖屏值 | 使用方式 |
| --- | --- | --- |
| 逻辑尺寸 | 684×1216 | 原点左上，触摸转换与显示旋转共用坐标映射 |
| 栅格 | 8 px | 少量光学对齐允许 2 px 调整 |
| 基本边距 | 32 px | 阅读可由用户改为 20–64 |
| 控件间距 | 16/24/32 px | 避免紧贴命中区 |
| 交互最小命中 | 80×80 px | 约 6.8 mm（按推算 297 ppi）；重要按钮 96 px 高 |
| 大标题 | 48 px | 主页面标题 |
| 栏目/按钮 | 36/34 px | 设置与菜单 |
| 正文/说明 | 32 px | 设置说明，不作为阅读正文默认 |
| 辅助文字 | 28 px | 作者、百分比；不低于 26 px |
| 笔画/边线 | 2/3 px | 小尺寸线条需真机清晰度检验 |
| 背景/前景 | 白/黑 | 黑白对比为主 |
| 灰阶 | 4bpp 目标码值 0–15 | 只在 GL16/GC16 使用；实际可辨层级需测 |
| 圆角 | 12 px，浮层 20 px | 不给每个文字区域套卡片 |

视觉字号是像素高度，不是字体文件的 point size。UI 中文字形必须在内置字体覆盖内；公共 UI 字体不随用户正文字体改变。

## 2. 信息架构

```text
启动 / 恢复
  ├─ 书架（最近 / 全部；网格 / 列表；搜索 / 集合）
  │    ├─ 详情与单书管理
  │    └─ 阅读
  │         ├─ 工具栏 → 目录 / 书签 / 搜索 / 排版或视图 / 强刷 / 书架
  │         └─ 图片预览 / 脚注弹层
  ├─ 传书（热点 / 局域网 / USB，互斥）
  └─ 设置（显示与字体 / 锁屏与壁纸 / 操作 / 电源 / 存储 / 升级与关于）
```

每个子页保存进入来源与滚动/页码位置。“返回”恢复来源，不能固定跳首页。最多一层阻断确认弹窗；目录和排版不能彼此叠加。系统诊断放关于页的维护入口，不出现在阅读主菜单。

## 3. 书架像素布局

- `y=0..63`：状态带；左上产品名或当前分类，右侧电池与网络状态，不显示秒钟。
- `y=64..143`：标题“书架”，右侧搜索命中 80×80；搜索入口显示放大镜与可理解说明。
- `y=144..319`：最近阅读条目：92×136 缩略封面、书名两行、作者、进度、继续阅读。无历史时变为入门提示。
- `y=320..399`：最近/全部切换、排序与网格/列表入口；每个操作至少 80 px 高。
- `y=400..1055`：三列两行封面网格，共六本；列 x=32/244/456，宽 196，列间距 16；封面 184×256，标题两行 30 px，超长尾部省略，详情显示全名。
- `y=1056..1103`：当前分页与结果数，仅信息，不作为小按钮；页码不覆盖封面。
- `y=1104..1215`：底栏“书架 / 传书 / 设置”，三个等宽点击区；手势翻页操作书库分页。

布局实现必须做整页计算：六张封面与标题均不得超出 `y=1055`，不足时缩小封面至 176×240，而非压小触摸目标。封面慢提取先显示书名卡，按区域成批更新；用户正在触摸时不插入导致命中位置变化的新条目。

列表模式每页 5 行：80×112 封面、全名最多两行、作者/格式/进度；右侧选择入口用于批量管理。筛选/排序时返回首个有效页，收藏与选择不混用。

## 4. 阅读页面

默认没有顶部系统栏。正文矩形默认 `x=32,y=32,w=620,h=1112`，底部状态带 `y=1144..1215`。隐藏页脚时可扩大正文，但这属于 layout_key 变化，需要重排。标题页和图片可用额外边距，绝不能画进保留页脚。

交互分区：左边 0–171 为上一页，右边 513–683 为下一页，中间 172–512 打开工具栏；上下 80 px 可保留为工具唤出区。左右手模式交换边缘含义，三键映射在设置中独立调整。图片/链接命中优先于边缘点按；横向滑动优先翻页，不误开图片。

工具栏占底部 320 px，白底细线覆盖，不使用透明暗幕：两行三列“目录 / 书签 / 搜索 / 排版 / 强刷 / 书架”。PDF/CBZ 将“排版”替换为“视图”。工具栏打开时不允许正文边缘点按翻页。点正文中央或 KEY2 关闭。

页脚显示“第 3 节 · 8/…”与“27%”。只有布局已完成时显示确定章内总页数；重排文本不伪造纸书页码。点击进度条打开跳转面板，使用数值步进/输入＋预览＋确认，不让一次随手触摸直接跨越大量内容。

## 5. 排版面板

面板全屏，顶栏返回/标题“排版”/应用；各入口都 80 px 高。上部 260 px 当前段落样例；下方显示字体行与字号、行距、段距、缩进、边距，更多进入第二页。底部“舒适 / 紧凑 / 大字”三个预设与“恢复默认”。

主要控件用“− 数值 ＋”和离散档位，不用细滑条。长按 +/- 每 180 ms 改一档，按住超过 600 ms 才开始重复；显示数值可局部 DU，每 250 ms 无新输入才重排样例。点击应用后保持原文锚点并整页 GL16；灰阶/二值模式变化做 GC16。取消恢复原布局。

字体行显示名称、静态/可变、缺字覆盖抽样结果。缺少中文字不以“已安装”误导。静态字体没有可变轴时禁用轴调节并说明“可选另一字重字体”，不伪造任意加粗承诺。

## 6. PDF 与漫画视图

工具：整页 / 宽适配 / 裁边 / 缩放（100/125/150/200%）/ 横屏 / 分区阅读。比例相对适配整页基准，不声称每个 PDF 原始像素比例通用。

宽适配时 KEY3 或下一页手势先移动到下一个视口，走到底再翻 PDF 页；KEY1 逆向，保持确定顺序。页脚“12/240 · 视区 2/3”，用户知道是移动视区还是换页。慢速两指缩放只在松手后提交一次，移动中显示倍率与视区框，不连续全灰阶重绘。没有文本层时隐藏文字搜索。

## 7. 三键与手势规则

| 场景 | KEY1 | KEY2 | KEY3 | 长按 |
| --- | --- | --- | --- | --- |
| 阅读 | 上一页/视区 | 工具栏开关 | 下一页/视区 | KEY2 600 ms 回书架；KEY1/3 默认不自动连翻 |
| 书架 | 上一书架页 | 当前页第一项焦点/确认焦点 | 下一书架页 | 无隐式删除 |
| 设置/目录 | 上一项 | 打开/确认 | 下一项 | 无隐藏危险操作 |
| 确认弹窗 | 取消 | 确认当前焦点 | 切换焦点 | 不自动确认 |
| 图片预览 | 关闭 | 关闭 | 关闭 | 无 |

长按 KEY2 前的短按可能打开工具栏，保持按住到阈值后跳书架，一次触摸周期只触发一次长按。电源键短按锁屏，长按遵循 PMU 关机行为，应用不重复改协议。

手势参数初值：点按移动容差 24 px；横滑提交阈值 64 px 且 `abs(dx)≥1.5×abs(dy)`；抬起提交；长按 600 ms；滑出、多点中断、读触摸错误、切页、锁屏取消。参数是待真机调优初值。

刷新中最多保留一个待处理导航意图，后续相同方向合并，反向撤销待处理意图；不累加无限翻页。设置保存、删除、格式化、升级不合并，必须保留事务结果。

## 8. 传书界面

页首“传书”与“返回书架/阅读”。三个通道采用独占分段选择，未验证 USB 时显示“USB 暂未启用”与原因，不给无效入口。热点界面大二维码至少 280×280 px，黑白硬边、4 modules quiet zone、整数像素 module，不加图案或中间 logo。

状态分开显示：已连接设备数、正在发送文件、写入进度、校验、入库。设备屏进度至多每秒一次小区域更新，网页可 4 Hz 更新；扫描二维码期间不刷其区域。停止传书显示“正在保存已接收片段”，完成后回进入来源。

手机网页提供图书/字体/壁纸三个标签、批量队列、封面缩略图、格式提示、重复文件选择、暂停/继续/取消、容量。字体显示校验状态与安装后设备选择指引；壁纸显示比例预览，上传不自动应用。不以大量轮询拖慢上传。MOBI/AZW3 明确引导电脑转换工具，网页不宣称能本地转换所有格式。

### 字体管理与锁屏壁纸

“显示与字体 → 字体管理”提供样例、缺字提示、真实字重轴、全局默认与删除；逐书选择留在阅读排版页。正在使用的字体删除前必须选择替代或确认回退，系统UI字体不可删除。

“锁屏与壁纸”先选择系统默认/自定义/当前书封面/简洁模式，自定义列表有上传指引；预览提供完整显示、铺满裁切、90°旋转、方向步进与应用/取消。恢复默认是明确按钮，当前书封面提示锁屏隐私。锁屏可选静态电量/日期/提示，不在睡眠中定时刷屏。详见 [专项流程与状态](FONTS_AND_WALLPAPERS.md)。

## 9. 全局状态与可访问性

加载 150 ms 内结束时不闪出等待页；超过 150 ms 显示静态原因，超过 1 s 更新阶段；取消按钮始终可触达。错误保持到用户处理，不靠两秒自动消失的小提示传递失败。待保存失败显示持久状态，不把未落盘进度显示为已保存。

交互只依赖黑白形状、文字和位置，不以浅灰区分启用状态。关闭控件用删除线图标或“不可用”文字。QR、对齐、断行、边缘触摸、中文长书名、日文名、右手/左手与戴眼镜大字场景均需真机验收。大字号 UI 模式采用更少行分页，不缩小字体塞满。

## 10. 书签与上次阅读位置

此节是产品目标，0.0.4仅有TXT持久记录/自动保存策略，界面尚未接入。

继续阅读卡显示最近书封面、标题与已识别进度，一触返回源位置；未知总页数使用章节/百分比，不伪造页码。缺卡/原书已移走显示原因和重新定位入口，清进度与清历史分开确认，均默认保留书签。

工具栏“书签”打开列表；顶部固定“添加当前位置”，已有书签显示选中状态。每行含名称、章节与进度，点行跳转，长按或明确更多按钮提供改名/删除。名称按UTF-8字符边界截短显示，编辑过长说明字节限制；删除单条确认，不能把滑动误当删除。跳转后提供“返回跳转前位置”，该回退位置不覆盖书签本身。

书签操作同步失败显示持久错误，保留列表和重试入口；只有确认提交后更新成功状态。位置保存失败也保留提示，锁屏/离书流程由带deadline的上层屏障决定，不能把同步codec直接当完整电源流程。
