# 界面与交互规范

1.0新增目标见 [产品计划](V1_PRODUCT_PLAN.md) 第6、7节：列表/3列与4列网格为必做，大封面先过板级原型门；标准/极简/隐藏页脚、阅读预设、响应合并和轻量个性化尚待实现。当前首页与独立书库软件行为见第2、3节及[专项设计](READING_HOME.md)；后续阅读能力与真机出口不因页面改版而标记完成。

设计目标：安静、有层级、可单手操作，所有动作可预期。本规范以《Pico Mono Glass V2.0》设计文档为准（原件不入库，落地对照见 [UI 规范 V2 对照](UI_SPEC_V2.md)），按本机硬件与已确认的产品决定落成原生像素规范：4.7 英寸 E0470A01，物理 1216×684、逻辑竖屏 684×1216，约 297 ppi（1 mm ≈ 11.7 px），16 级灰阶。设计稿 360×640 逻辑单位（u）与本机正好同为 9:16，1u ≈ 1.9 px。

## 1. 视觉语言：Mono Glass

白底、深色文字、浅灰“拟玻璃”卡片承担分区，主操作用深色填充。拟玻璃是静态的：雾面（G14）＋单层细描边（G11）＋下沿一级灰差的“影”，不做实时模糊、半透明动画、多层投影或全屏纹理。阅读正文区不叠任何卡片或纹理。图标为等线宽圆头线条，旁边带文字；状态至少由形状、文字、选中标记中的两种表达，不只靠灰度深浅。

| Token | 值 | 使用方式 |
| --- | --- | --- |
| 逻辑尺寸 | 684×1216 | 原点左上，触摸与显示共用坐标 |
| 灰阶 | G00 黑、G05 次要文字、G11 描边/分隔、G13 选中底、G14 雾面卡片、G15 白 | 4bpp 码值 0–15；真机 LUT 校准后再调 |
| 基本边距 | 32 px（≈16u） | 阅读页边距另有窄/中/宽 |
| 最小命中 | 88×88 px（≈7.5 mm） | 规范要求不小于 7 mm；视觉可小，透明命中区不小 |
| 圆角 | 控件 16 px、卡片 22 px、分段与抽屉 28 px | 对应 9u/12u/16u |
| 字号 | 首页大标题 50、页面标题 36（加粗）、卡片标题 32–34、正文 28–30、说明 22–26 | 像素高度；说明不低于 20 |
| 加粗 | 标题、选中项、主按钮 | 由控件层以 0.6 px 错位重绘实现，UI 字体只有一个字重 |
| 线条 | 2 px，图标线宽约尺寸的 1/14 | 抗锯齿覆盖率混合进灰阶 |

主按钮深色填充白字；次按钮雾面加描边；危险操作（删除）只用描边与明确的“删除”字样，不用深色强调，“取消”的点击区不小于“删除”。

## 2. 信息架构

2026-10-12确认采用[阅读首页与独立书库](READING_HOME.md)：将继续阅读移到独立首页，书库保留3列/4列/列表，统一首页、书库、传书、设置四栏导航。页面像素与行为如下；实现仍复用同源绘制、封面队列、阅读记录和设置事务。

```text
启动 / 恢复
  ├─ 首页（一级）：继续阅读 / 实际最近记录 / 书库入口
  ├─ 书库（一级）：全部 / 最近 / 收藏；3列 / 4列 / 列表；搜索；长按书籍→操作面板
  │    └─ 阅读：工具栏 → 目录 / 书签 / 跳转 / 排版 / 刷新 / 返回
  ├─ 传书（一级）：热点 / 局域网 / USB（按能力显示）、存储与格式说明
  └─ 设置（一级）：字体管理、锁屏壁纸、书架外观、按键与手势、刷新与屏幕、局域网传书（已保存网络时）、存储与关于
```

首页、书库、传书、设置四个一级页底部固定同源四栏导航，任何书籍数量或字号下都完整显示；阅读页与二级页不显示底栏。二级页左上返回回到来源（例如字体管理返回设置）。最多一层阻断确认。

## 3. 首页与独立书库

默认进入阅读首页，状态带显示“PicoNano”与实际时间/电量；设备时钟只有PMU已对时才显示，模拟器用本机时间。首页大标题“读书”，y=180起突出最近一本：160×224封面、作品名最多两行、作者单行、保存进度、细进度线与88px高继续阅读按钮。y=636为最近阅读/全部图书入口，y=670/840为另外两本实际最近记录。无历史记录时提供打开书库、传入图书，不填假书籍、假阅读时长或假统计。阅读工具栏“返回”和长按KEY2回进入来源；首页打开的书返回首页，书库打开的书返回书库。

书库仅用于浏览、搜索和管理，不画继续阅读卡：

- y=0..40：品牌、有效时间/无线/电量。
- y=72..134：40px“书库”或“搜索结果”，右侧搜索/清除。
- y=158..216：全部/最近/收藏，与网格/列表切换共用一行。
- y≈252：排序说明与实际总数；本阶段仍按原文件名/拼音排序和搜索，不声称已经建立全库作品名/作者索引。
- y=284起：3列两行6本；4列起点y=308，两行8本；行距354。标题24/22px单行省略，作者20px单行，仅真实存在时显示。拟物搁板/纸页保留原样式选择，详情见[书架外观](SHELF_APPEARANCE.md)。
- 列表起点y=268，行距150，每页5本，80×112封面、作品名最多两行、作者单行与进度/格式/大小。
- y=1046..1104：分页；KEY1/KEY3翻书库页。
- y=1104..1216：共用首页/书库/传书/设置四个图标导航，无文字标签；当前页浅灰高亮，完整点击区不变。

EPUB优先OPF作品名与作者，缺失/失败回退去扩展名的文件名，作者留空；原文件名和路径不改写。元数据与真实PNG/JPEG封面共用有界空闲队列和v5可重建缓存，绘制只读快照；最多8个页面槽加最近一本，新增元数据净成本9KiB，不新增全屏画布。封面按内容验证后绘制，无真实封面用双字文字识别卡。网格保留收藏标识、更多操作和有效进度细线，类型/未读文字移到列表与详情；初次不自动画黑框，主动键盘/三键导航才显示轻量焦点。

“⋯”或长按600ms（模拟器右键）打开操作面板：真实作品名、作者、格式/大小/进度、原路径及打开/收藏/删除。删除必须确认，原阅读记录与书签保留。收藏最多50本，按路径保存；布局和分类不改变书籍身份。列表与网格的书名/作者区域也可打开书籍。空书库、无搜索结果与无收藏记录给出原因和入口。

## 4. 阅读页面

默认没有顶部系统栏。正文矩形 `x=32,y=32,w=620,h=1112`，页脚 `y=1144..1215`：上沿一条进度轨（浅灰轨、深色已读段、圆点），下方左侧章节（EPUB“第 7/27 节”；TXT 书名），右侧百分比。EPUB 百分比按各章 XHTML 原长估算到章节起点，章内页码在排版确定前不显示，不伪造。

交互分区：左 0–171 上一页、右 513–683 下一页、中间打开工具栏；左手模式交换左右。点页脚右半打开跳转面板，点页脚左侧（跳转后）返回跳转前位置。

工具栏为底部圆角面板（抓手、细描边、不加灰色遮罩，减少残影）：两行三列拟玻璃卡片“目录 / 书签 / 跳转 / 排版 / 刷新 / 返回”。TXT 没有目录时“目录”画斜线不可用。点上方正文或 KEY2 关闭。

**按百分比跳转**：TXT 与 EPUB 都按百分比，±1 / ±10 步进只改草稿，进度条与“现在在 N%”对照，点“跳转”才移动；EPUB 落到该百分比所在章节的开头并说明“约在第 N/M 节开头”。跳转后可返回跳转前位置。

## 5. 排版设置

顶栏“‹ 返回 / 排版设置 / 恢复默认（文字）”；上部段落预览（轻点看整页）；“排版模式”分段“舒适 / 紧凑 / 大字”，手动调过显示“自定义”；字体行（当前字体名 ›）；字号、行距、段距、页边距（窄/中/宽三档）四个“− 值 ＋”步进行；首行缩进开关；“字间距 ›”第二页（清残影统一在系统设置）；底部固定深色“应用”。

点字体行进入“选择字体”：点某一行直接应用到本书并回到排版页（当前字体打对勾），行右侧箭头才进字体详情。步进只改草稿；点“应用”才保存并保持原文锚点；返回即取消，恢复原布局。设备上长按 ± 满 600 ms 后每 180 ms 一档。

## 7. 按键与手势

本机是屏幕下方三个触摸键 KEY1/KEY2/KEY3 与 PMU 电源键（按压式，不是拨动开关）。阅读与书库保留原语义；管理页面按2026-10-13用户要求采用左返回、中首页、右确认：

| 场景 | KEY1 | KEY2 | KEY3 | 长按 |
| --- | --- | --- | --- | --- |
| 阅读 | 上一页 | 工具栏开关 | 下一页 | KEY2 600 ms 回进入来源；不连翻 |
| 首页 | 上一最近项 | 继续最近一本 / 打开焦点书；空记录进入书库 | 下一最近项 | — |
| 书库 | 上一书库页 | 聚焦本页第一本 / 打开焦点项 | 下一书库页 | 封面长按（触摸）开操作面板 |
| 设置、目录、书签等管理页面 | 返回上一层；预览回表单 | 保存并回阅读首页 | 确认当前项；无选择时使用首个可操作项 | 步进键长按连发（触摸） |
| 确认弹窗 | 取消 | 取消弹窗并回阅读首页 | 明确确认 | 不自动确认 |
| 工具栏 | 关闭工具栏 | 保存并回阅读首页 | 确认当前项 | — |

传输页的返回和首页请求先停止传输、等待TF归还。保存失败保留会话并提示，不宣称已返回成功。PC书库窗口数字1/2/3对应左/中/右键，方向键仍可选择阅读弹层当前项；脚本使用key-left/key-home/key-confirm。

电源键短按锁屏并保存，再按回到原处；锁屏页不显示时间。“设置 → 按键与手势”按机身实际布局画出三个触摸键与电源键，并提供左手模式、滑动翻页、边缘点按、三键翻页开关（不能全部关掉）。

手势参数初值：点按移动容差 24 px；横滑 64 px 且 `abs(dx)≥1.5×abs(dy)`；抬起提交；长按 600 ms。参数待真机调优。

## 8. 传书

传书一级页列出热点传书、局域网传书（已保存家庭网络时可用，否则提示先在热点网页里保存）、USB（暂不支持并说明原因），下方存储卡容量与支持格式。热点界面大二维码至少 280×280 px，黑白硬边、4 模块静区。停止传书显示“正在保存已接收片段”，完成后回进入来源。

手机网页提供图书/字体/壁纸上传、字体/封面/壁纸原图列表与删除；不宣称能本地转换 MOBI/AZW3。

### 字体管理与锁屏壁纸

字体管理：“当前默认字体”卡与“已安装字体”卡片列表，每行用该字体本身画“Aa”样本、显示大小，全局默认打对勾；详情页有样例、缺字抽样、设为全局默认与删除（删除需确认，正在使用的书改用默认字体）。

锁屏壁纸：系统默认 / 简洁 / 当前书封面 / 自定义图片；预览提供完整显示、铺满裁切、旋转与应用/取消。锁屏不显示时间，不在睡眠中刷屏。详见 [专项流程与状态](FONTS_AND_WALLPAPERS.md)。

## 9. 设置

一级页分组卡片：显示与字体（字体管理、锁屏壁纸、书架外观）、阅读（按键与手势、刷新与屏幕）、设备（局域网传书、存储与关于）。开关与策略立即保存，失败回滚并提示；正常时不显示内部说明文字。

- 刷新与屏幕：“自动清残影”清晰 / 均衡 / 省电（每 6 / 14 / 24 页整屏刷新一次），“立即整屏刷新”；设备 GL16 小范围变化只推变化区域（变化超过 45% 时整屏）。
- 存储与关于：版本、屏幕、存储卡容量与可用空间、内部存储状态，只显示实际读到的信息。

## 10. 全局状态与可访问性

加载超过 150 ms 显示静态原因；错误保持到用户处理；未落盘不显示为已保存。所有核心状态在黑白与 16 灰阶下都由形状或文字区分，不靠浅灰。QR、断行、边缘触摸、中文长书名、左右手与大字场景均需真机验收。

## 11. 书签与上次阅读位置

继续阅读卡显示最近一本的封面、标题与进度，一触返回原位置。书签页顶部深色“+ 添加当前页为书签”；同一位置再添加时不重复，选中已有那条并提示“当前位置已添加”。每条书签为带图标的卡片：名称、EPUB“第 N/M 节”或 TXT“已读 N%”、右侧“更多”。点行进入操作（跳转 / 改名 / 删除，删除需确认）。跳转后可返回跳转前位置。书签操作失败显示持久错误与“重试”，成功提示不带“重试”。

跳转返回入口仅在尚未继续翻页时保留；成功下一页、上一页或回开头后自动隐藏并清除。原页重绘、呈现失败不消费临时返回点。

目录使用10项紧凑分页：28px条目字、88px整行点击、长标题最多两行、层级缩进。章节唯一对应目录项时打开即定位到当前项，顶部“当前”返回其所在目录页，目录浏览不移动正文；同章多个片段不猜测精确当前项。首尾分页按钮禁用。
