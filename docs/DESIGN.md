# 小纸 Pico 独立阅读固件总体设计

版本：设计草案 v1.0；日期：2026-10-05。用户方向已纳入；涉及真实性能、PDF 引擎、硬件时序的结论需实测。文档的产品设计与实现计划均不代表功能已经交付。

## 1. 产品定位

一台开机即读、单手易用、字体清晰、翻页稳定、传书快速的离线电子书设备。复用参考固件验证过的板级能力，新建产品应用与阅读服务，不保留出厂演示菜单作为日常首页。

体验优先级：数据可靠 → 字体清晰与排版正确 → 翻页稳定 → 操作可理解 → 传书便捷 → 格式广度 → 额外功能。

“现代”体现在明确层级、封面书库、直接续读、少步骤、设置即时预览。“丝滑”体现在可取消的后台工作、热页缓存、无无意义重刷、不会丢失输入与位置。墨水屏整页刷新受波形限制，不设置 60 fps 动画指标。

## 2. 已知硬件边界

| 项目 | 设计基线 | 决策 |
| --- | --- | --- |
| 屏幕 | 1216×684 物理，684×1216 逻辑竖屏 | 所有主界面按竖屏设计；PDF/漫画增加横屏 |
| 显示 | 4bpp 缓冲与灰阶波形 | 界面与正文分别调度；灰阶数量以真机梯子为准 |
| 内存 | 8 MiB PSRAM | PDF、图片、字体共享预算，不能叠加各自最大额度 |
| 触摸 | CST836U 两点与屏下三键区 | 单指为主；PDF 两指缩放仅在技术验证后启用 |
| 存储 | 16 MiB flash，TF 卡 1-bit SDMMC | 完整中文字体、主书库在 TF；内置存储只做应急 |
| 网络 | 2.4 GHz WiFi | AP 扫码与 STA 局域网，默认关闭 |
| USB | S3 能力存在，实际连接待确认 | MSC 是第二通道；保留串口刷机恢复 |
| 电源 | PMU 管理、VCOM 在 PMU | VCOM 只读，未标定进入出厂路径 |

沿用参考波形与驱动。参考头文件描述默认整页约 430 ms、8 灰阶约 360 ms；这些是已有说明，不是新固件性能实测。默认 120 MHz flash/PSRAM 与 Zbit 型号绑定，存在温漂风险；实验配置不能直接当量产保证。

## 3. 架构方案比较

| 方案 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 原生 C 轻量 UI＋独立阅读服务 | 能精确控制 framebuffer、波形、内存与任务 | 排版与交互需自行维护 | 推荐作为主体 |
| LVGL＋独立阅读服务 | 控件与状态成熟，设置页开发快 | 墨水屏损伤区、全刷与缓冲需要专项适配；不自动改善排版 | M0 小规模对比，未达收益不引入 |
| 移植通用阅读器/桌面引擎 | 格式与排版丰富 | 内存、依赖与许可开销较大，难适配 8 MiB | 仅将 PDF 引擎作为受控模块评估 |

推荐混合：设备 UI 与重排文本引擎采用原生 C；PDF 用经过验证的独立引擎适配；电脑辅助工具只负责可选转换与管理。PDF 不以云转换冒充原生支持。

## 4. 版本边界

| 阶段 | 范围 | 发布条件 |
| --- | --- | --- |
| 技术样机 | 驱动基线、PDF 原生验证、TXT 热翻页、网络吞吐基线 | 足够证据选择架构与确定资源限额 |
| 0.1 内测 | TXT/EPUB、书架封面、续读、字体段落设置与上传、锁屏壁纸、AP/STA 传书、书签 | 不含完整格式承诺；仅内部体验验证 |
| 0.2 Beta | 原生 PDF 适配/缩放/分区阅读、断点续传、回滚升级 | PDF 技术门与许可门通过 |
| 1.0 | 加入 FB2/CBZ、书库管理、USB（硬件门通过）、稳定性与完整文档 | VALIDATION 所有正式门槛通过 |

PDF 技术门若失败，0.1 可继续内测；Beta 与 1.0 的 PDF 需求不得静默删减，也不得宣称全部目标已完成。记录失败证据，重新选择引擎/降低有界 PDF 范围/讨论硬件升级。

## 5. 关键体验决策

1. 开机回上次阅读位置；用户可改为书架。上次打开失败时直接书架，不反复自动尝试。
2. 首页三个入口：书架、传书、设置。最近阅读与全部图书在书架内切换，避免重复页面。
3. 阅读默认隐藏顶栏，底部只留轻量进度；点中央唤出控制面板。
4. 阅读屏下 KEY1 上一页、KEY2 工具栏、KEY3 下一页；KEY2 长按 600 ms 返回书架。菜单页左返回、中确认、右下一项；触摸上明确出口始终存在。
5. 字号/段落设置合并连续输入，停止 250 ms 后预览；不在拖动中整页反复重排。
6. 普通模式正文 GL16，控件小区域 DU 后定稿；快速模式二值正文 DU，明确牺牲灰阶，不把灰阶缓存直接推 DU。
7. PDF 原版模式不提供字号/段落重排设置；提供裁边、缩放、横屏、分区、页码与书签。
8. 传书默认 AP 扫码，无需账号或安装手机应用；大量文件优先 STA 批量网页或 USB。
9. 已有存储挂载失败不自动格式化；覆盖、删除、清进度、格式化四种动作明确区分。
10. 书籍身份由内容摘要与存储位置分离；同路径同大小的新文件也不会继承旧进度。
11. 字体支持手机/电脑上传、校验、样例预览与安全替换；UI字库独立，上传成功不自动换正文。
12. 锁屏支持默认图、自定义壁纸、当前书封面与简洁模式；壁纸上传后裁切预览再应用，内部缓存使拔卡后仍可锁屏，睡眠中不做时钟动画。

## 6. 成功指标摘要

标准语料与测试条件详见 VALIDATION。以下均为待测目标：热页软件准备 p95 ≤80 ms；普通 GL16 翻页从提交到完成 p95 ≤650 ms；热书打开 ≤1.5 s；常规冷 EPUB 首屏 p95 ≤3 s；常规 PDF 首屏 p95 ≤4 s、后续页 ≤2 s。超复杂 PDF 用有界失败响应，不能承诺所有文件达到同一延迟。

AP 上传有效吞吐目标 ≥0.5 MiB/s，STA ≥0.8 MiB/s（5 次中位数，正常 TF 卡与约定信号条件）；10 MiB EPUB 在上述 AP 条件下传输约 20 秒内，校验和入库另计。USB 实测后定指标，不许声称 USB 一定更快。
