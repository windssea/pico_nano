# 阅读中的字体预览与逐书应用

0.0.36把完整正文/备用字体组接入TXT和EPUB活动会话，可在原文锚点预览、取消和逐书应用。当前是控制器API与实际画面验证；中文字体选择菜单、全局设置入口和上传/删除界面尚需接入，不能称完整字体管理产品完成。

## 资源与位置

pn_font_set装配完整明确选择，校验每个文件的大小和SHA，保持asset文件/源地址稳定。常驻正文与可选备用分别管理，借用指针不转移文件对象；move只移交私有句柄所有权。挂起仅释放临时字体引擎，保留源和读取租约，需要时按原地址重开。

应用保留已接受组与草稿组，原始启动字体作为首次更换前的基线。候选先校验，重排与画字使用候选的同一字体组；TXT按最大垂直度量重排，EPUB按语义位置和实际字形节点重排。Font preview使用当前字号/行距/段距/缩进/字距/边距，不改变PNTS设置。字体和排版草稿互斥，避免一类草稿重置另一类。

第一次字体预览记录原阅读锚点，后续候选仍从该锚点显示。仅真实推屏确认后进入预览状态；失败显示恢复上一组与布局，位置不变。原文字体不同会改变行数和换行，不保存永久页码。预览上方“字体预览”，底部“设置尚未保存”。返回设置的实际命令仍由菜单owner解释。

EPUB大图前关闭所有临时引擎，包括未应用候选及旧字体组，随后按需重开；不能为了保留取消基线让整套FT缓存与渐进JPEG系数长期重叠。成功应用后关闭旧启动文件/租约，系统UI字体继续独立。

## 应用与失败

font_preview只改活动草稿不写PNFP；font_apply先读取逐书原记录、校验候选并实际确认显示，再保存逐书选择。写错误后重读完整语义候选；已确认提交才能接受新组。保存失败保留原应用意图和原记录基线，屏幕可以已经显示候选，不能声称旧画面仍在。

待提交意图与后续预览草稿分开。另预览字体后，关闭重试仍提交原应用选择；不能把当前预览草稿写入。待提交存在时，不同的再次应用返回BUSY，需重试同一请求或取消，避免丢应用请求。关闭保存屏障失败保留会话供重试。

font_cancel恢复已接受字体及原文锚点。若失败应用曾写入记录，先恢复原逐书记录，再实际显示旧字体；原记录不存在以继承语义恢复，不删进度。未知/损坏记录拒绝覆盖。取消显示失败仍保留候选与原待提交请求，关闭时仍处理该请求；只有恢复画面确认后才清草稿和待提交意图。

font_apply用于逐书明确选择。font_inherit读取已有全局实际组合用于显示确认，持久保存独立的继承标记；实际字体和持久意图分开。font_default校验后保存全局组合，保留当前接受组与所有逐书覆盖，之后打开时生效。未设置全局时继承返回EMPTY。没有state目录时应用只影响当前会话，不提供持久保证。

## 验证

python tools/dev.py host：TXT/EPUB实际字体/显示回调验证失败预览位置不变、原锚点预览/取消、逐书应用；字体组身份错拒绝、文件源稳定、挂起重开/字号、句柄移交、每个观察到的打开分配失败和失效媒体回收。EPUB在显示回调之后注入保存分配失败，再预览不同字体，验证不同应用BUSY、取消恢复、关闭失败保留、修复后保存原请求以及重开恢复正确的逐书记录。读取未初始化IO绑定的错误路径已避免。

原字体选择、分页、排版、书签、目录、保存及窗口回归继续覆盖。UI已接入设备与PC窗口；SDK真实链接入口，仍需硬件验收。

实际本机《绍宋》在已有阅读位置从霞鹜文楷切换为完整Noto Sans SC正文预览，原text_003.xhtml element13/run0/offset14保持，pool峰1730340bytes后释放到0。封面位置同时预览正文和备用文件，6MiB预算下渐进JPEG完成，pool峰5783818bytes后释放到0。截图为软件帧，不证明设备PSRAM剩余、翻页时延、纸屏观感或功耗。

可用epub_app_capture设PN_EPUB_HOT_FONT为绝对TTF路径，PN_EPUB_HOT_FALLBACK可选，先打开/翻页后再预览；不会写字体选择，若提供state目录仍按正常屏障保存阅读位置。样本、完整测试字体与输出保留在忽略的build目录。

逐书选择的用户入口自0.0.37接入[中文菜单](FONT_PICKER_UI.md)，全局/继承操作自0.0.38接入；上传仍需完成。
