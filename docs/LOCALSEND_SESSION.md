# LocalSend 元数据与会话核心

本模块已实现同源C会话与协议JSON编解码，并由 [PC HTTP/发现开发入口](LOCALSEND_PC.md) 调用。设备入口、中文图形确认界面、设备UDP发现和HTTPS尚未装配，官方客户端互通尚未验证。

## 元数据与目录

prepare-upload请求最多8192字节，预检限制8层、256节点令牌；对象键必须唯一，files中的键须与各文件id一致。最多8个文件，总大小最多512MiB，并遵守现有逐类文件上限。摘要可缺省或为null；提供时必须是完整64位十六进制SHA。

解码仅生成元数据，调用方仍须pn_ls_prepare校验。后者检查UTF8、协议2.x、安全保存名称、文件ID和重复目的名称；只接受TXT/EPUB、TTF和JPEG/PNG。MIME、preview、客户端root及无关扩展字段不决定目录，也不触发图片解码。JSON解析使用固定cJSON全局allocator，不改hooks；树的系统堆分配受字节/节点预检约束，但不计入传入pool的峰值。需在设备HTTPS接入时测整体峰值。

书籍/字体根据扩展名分类，图片等待用户明确选择封面或锁屏；实际内容仍由共享安装事务验证。未确认前不提供会话或文件令牌，不读正文、不创建目标文件。发送方名称和fingerprint由对方申报，不是身份认证；上传绑定实际连接的地址和接收端生成的令牌。

## 确认与授权

调用方串行操作同一个会话。准备成功后获取snapshot，显示发送方、实际地址和文件清单；确认事件必须携带snapshot.generation，旧请求的确认不能批准新的请求。代次只用于同一对象生命周期的界面一致性，不是网络认证。关闭/重建对象前停用确认界面、清掉旧输入和回调，并关闭网络入口、join调用方。

用户可部分接收或全部拒绝；选中的图片必须指定covers或wallpapers。只有安全随机源完整生成成功且所有128位值非零、不重复，才进入READY。授权响应为sessionId及files映射，文件ID按JSON转义，响应最多2048字节；不会暴露内部上传ID。

snapshot分别记录accepted、installed、failed。DONE仅代表本批已处理，不保证全部安装成功；拒绝同名文件等正文尚未开始的失败直接计为未安装，不阻塞在恢复状态。已经确认安装的文件不能被后来的失败回执降级为未安装。

上传检查实际IPv4/IPv6地址、会话ID、文件ID和逐文件令牌；不绑定每次连接可能变化的源端口。地址族变化需重新建立会话。不同文件不能并行接收，已处理文件不可重放。通过授权后，内部请求接入pn_transfer_receive及已有worker，仍执行固定目录、摘要/格式校验和拒绝覆盖。

## 生命周期与时限

| 状态 | 行为 |
| --- | --- |
| PENDING | 等待确认60秒，未授权 |
| READY | 等待上传5分钟 |
| RECEIVING | 正文空闲10秒，单文件总时限30分钟；只有实际字节增长延长空闲期 |
| VERIFYING | 精确EOF后校验/安装，取消网络空闲限制，总时限保留 |
| RECOVERY | 已开始安装或取消未确认，禁止新请求与直接销毁 |
| DONE/REJECTED/CANCELLED/EXPIRED | 本批结束，之后可准备新请求 |

这些是当前软件合约，真实无线与客户端体验尚未验收。网络读取应放在状态锁外，读取前后报告进度/检查取消；精确EOF后调用body_done，然后把共享接收结果交给finish。不要在耗时校验中把网络空闲超时当成文件未安装。

取消/超时只请求停止，不能立即释放正在使用的会话。已确认安装的资源保留；cleanup_pending或取消失败进入RECOVERY，内部恢复请求根据recovery_install选择安装重试或取消。收尾回执确认后才离开恢复状态。

拔卡或错误下需要退出时，先关闭新网络请求、join全部网络调用并关闭worker，随后调用stop_after_join撤销令牌；unresolved提示持久事务仍待恢复，不能声称已回滚。此函数是本机owner的屏障通知，不得暴露为网络接口。

## 验证

host入口包括localsend_session、localsend_json、localsend_receive和独立Python JSON响应oracle。覆盖来源/文件令牌隔离、全零会话拒绝、随机源失败、8文件与大小边界、旧确认代次、等待/正文超时、取消/恢复、重复键/截断JSON和真实worker安装。端到端主机用实际协议元数据生成授权后写入临时books目录，不使用客户端root或MIME选择目录。结果不等于官方客户端或设备互通验收。
