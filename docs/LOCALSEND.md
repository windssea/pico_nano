# LocalSend 接收模式

用户已要求与官方 LocalSend 客户端互通及自动接收。整文件接收层、[会话核心](LOCALSEND_SESSION.md)、[PC开发入口](LOCALSEND_PC.md) 及设备HTTP/IPv4组播接收装配已实现。设备入口在“传书 → LocalSend”；有已保存网络时使用家庭网络，否则开启热点。开启接收期间书籍/字体自动接受，退出传书关闭服务；普通阅读不开放网络接收。官方客户端真机互通尚未验收，HTTPS未实现。现有网页上传保留。

## 设备当前行为

- UDP发现使用 `224.0.0.167:53317`，发布实际HTTP服务端口80与随机指纹，声明 `protocol=http`、`download=false`；每15秒发布，收到其他设备announce时限频回应。SDK socket/无线发现仍待真实路由器与热点测试。
- HTTP提供v2的info/register/prepare-upload/upload/cancel；元数据最多8文件/8192字节，会话来自真实连接地址，随机会话/文件令牌有有效期。网页Origin请求不能绕过配对调用原生接口。
- 用户开启接收模式即授权书籍/字体自动接受，不逐文件弹框。同名文件拒绝覆盖；不支持的书籍格式仍由共享安装校验拒绝。JPEG/PNG不自动猜封面或壁纸，使用网页明确选择类别；只有图片的原生请求返回拒绝，混合请求仅授权书籍/字体。
- 整文件流复用现有串行worker及安装事务，固定写到 `piconano/books` 或 `piconano/fonts`；有SHA时验证，无SHA时计算，安装确认后才回复成功。中断、取消、摘要错或拔卡不得把未安装暂存文件列入书库。
- 设备handler主机测试实际执行共享文件安装，并核对连接来源、令牌重放、媒体独占及停止回收；它替换SDK HTTP/socket，不证明官方客户端或RF实测。下面保留早期确认/HTTPS规划，当前自动接收行为以本节为准。

[中文确认与状态组件](LOCALSEND_UI.md) 和可点击SDL演练已提供，尚未连接真实HTTP会话或设备页面；它不替代上面的图形接收闭环验收。

## 协议与产品范围

协议来源为 [LocalSend 官方协议 v2.2](https://github.com/localsend/protocol/blob/62bd3406ec80d62f2ed46269cdc06c4dcc391083/README.md)，核对日期 2026-10-11。首期实现接收端，设备在传输页由用户开启，退出或锁屏时按现有停止屏障关闭。设备名“PicoNano”，接收已支持的 TXT/EPUB、TTF、JPEG/PNG；PDF/FB2/CBZ在阅读内核支持前拒绝，不按扩展名假装支持。

目标为同一家庭网络下，官方 Windows/Android/iOS 客户端发现设备、选择文件、设备确认后接收。热点模式另外验证手机路由与组播行为，不以家庭网络结果代替。初期不实现反向下载、剪贴板或任意文件导入。

## 接入边界

所有资源遵守 [存储卡目录](SD_CARD_LAYOUT.md)，必须通过共享安装层路由到books/fonts/covers/wallpapers；LocalSend不能直接写客户端路径。图片在接收确认时明确选择封面或锁屏图片。

- 默认 UDP 组播 224.0.0.167:53317，服务端口 53317；实现 register、info、prepare-upload、upload、cancel。声明 download=false。组播不可用时验证客户端的 register 探测路径。
- 接收前展示发送方、文件数与总大小，默认等待确认，支持拒绝与取消。会话及逐文件令牌使用系统随机源，绑定发送方地址并限制有效期。单个活动会话、有界元数据、文件数/大小/剩余空间限制，路径仅取安全文件名。
- HTTPS及自签证书指纹按官方协议处理，先测握手内存与客户端互通；设备端支持是否足够需实际 SDK 构建与样机验证。HTTP是协议允许的模式，但不能把明文模式当作加密，不能跳过既有 HTTPS 服务的证书验证。
- 新建独立协议适配层，复用现有传输工作任务、介质独占、资源校验与安装恢复；网页与LocalSend不能同时抢占文件消费者。同名文件初期拒绝覆盖，后续覆盖仍需现有身份核对与明确确认。
- 官方上传是整文件请求，sha256允许缺省；现有网页API仍以已知摘要和64KiB块为前提。整文件接收基础层复用已有暂存/分块和安装事务，由owner在收完后计算摘要；不需要第二份整文件临时文件。提供摘要时核对，未提供时计算内容身份。协议层不能自行写最终文件，须接入同一配额、取消和掉电恢复。
- LocalSend不能宣称支持现有网页的跨重启64KiB续传。客户端中断后采用重发，未安装的暂存文件不可出现在书架中；取消、断连、拔卡、睡眠、离页均需收敛所有权。

## 验收

先通过主机协议测试：发现、自发现过滤、PIN/确认、令牌与地址隔离、非法路径、超限、缺省摘要、摘要不符、截断、并发、取消和安装恢复。再用官方桌面客户端实传《绍宋》与霞鹜文楷，核对完整SHA；最后验证Android/iOS、路由器组播、热点、设备内存峰值、吞吐与停止恢复。软件替身不能代替这些互通结果。
