# 字体管理与缺失回退

0.0.52加入设备/PC同源字体管理页，并把“所选字体缺失或被替换”从拒绝打开改为运行时回退。产品目标见 [字体与壁纸](FONTS_AND_WALLPAPERS.md) 的FONT-02；选择记录格式见 [字体选择记录](FONT_PREFERENCES.md)。只在主机/SDL验证，真机未测。

## 缺失回退

打开TXT/EPUB时，逐书或全局记录指向的正文字体若不存在、大小或SHA不符、记录字段非法，本次改用调用方给的启动默认字体（设备为启动参数，没有则内置界面子集），书照常打开并标记font_unavailable（pn_reader_app_font_unavailable / pn_epub_app_font_unavailable）。只有备用字体失效时丢弃该备用，正文选择照用，也标记。介质失效仍按原错误失败。

回退不改写任何记录：标记期间不把记录当作当前已接受组合，字体菜单之后的“应用本书/设为全局默认”才写新选择；恢复同内容字体后重开即回到原选择。界面暂未在正文中显示回退提示，仅提供查询接口，属于待完成项。

## 字体管理页

入口：阅读菜单（点阅读页品牌区、按KEY2，或书架左上“小纸 Pico”）→“设置”→“字体管理”。进入前保存并关闭正文及其字体源，退出回原书或书架；传输、壁纸设置期间不可进入，提示页/锁屏会关闭本页。PC书库窗口给 `--font-dir DIR` 后在书架按F进入，全局记录使用 `--state-dir`。

- 列表：显示全局默认（未设置/内置/文件名/记录不可读），`/sdcard/fonts` 中TTF六项分页，每项大小，全局默认项带标记。
- 详情：真实打开字体做102字样例检测，显示族名、样式、字重、字形数、字节与缺字统计和样例；坏字体留在列表并提示“不是可用的TrueType字体”。
- 设为全局默认：正文改为该字体，已有全局备用保留，没有则为内置；记录不可读时拒绝覆盖。保存后以读回为准。逐书明确选择不受影响。
- 删除：确认页说明使用它的书会暂用默认字体、位置与选择记录保留，全局默认另有提示。确认后先关闭本页字体资源，再取TF WRITE租约删除；有其他READ占用返回BUSY并保留文件。不清除任何选择记录。

网页端字体列表/删除API、使用中替换的二次确认流程、字体内容摘要索引与可变轴选择仍未实现。上传同名字体覆盖后，引用旧摘要的书按上述规则回退，需在字体菜单重新应用。
