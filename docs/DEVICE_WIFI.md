# 设备WiFi会话生命周期

`main/device_wifi.c` 实现传输会话的AP/STA驱动、事件与有限连接重试。主机运行同源C模块与显式SDK stub，固件构建使用真实SDK。当前主设备入口尚未装配WiFi、HTTP和传输页面，尚无真实手机连接或无线吞吐证据。

## 模式与凭据

调用方显式选择热点或已有网络，失败不自动切模式。AP名称为“小纸 Pico-”加MAC识别后缀，每次开启生成12位无歧义Base32口令，使用WPA2-PSK/CCMP、最多两台客户端。名称识别后缀不用于生成秘密，不使用固定公共口令。

STA接受最多32字节SSID、空口令或8–63字节可打印ASCII口令；空口令只用于调用方明确选择的开放网络。密码保护网络采用WPA2门槛、PMF capable及SAE两种派生方式。支持程度须结合实际路由器测试，企业认证与非ASCII口令尚未实现。

WiFi初始化配置 `nvs_enable=0`，随后使用WIFI_STORAGE_RAM；此模块不读取/写入持久凭据、不擦NVS。STA密码只复制给RAM驱动配置，状态快照不含STA密码；临时配置和AP随机原始字节在使用后清零，关闭后清零上下文。保存网络、网络扫描及中文输入界面仍待接入，不能把RAM连接API当作已保存网络功能。

## 熵与资源前提

开启前必须独占RF/ADC，不能与蓝牙、ADC或已有WiFi驱动并行初始化。模块拒绝已初始化WiFi及已有默认AP/STA网络接口。AP口令生成使用短暂bootloader_random SAR熵窗口，RF初始化前完成并disable；后续HTTP令牌在无线已启动后生成。该API约束来自固定SDK头文件，不能在未来添加ADC消费者后继续无协调调用。

不使用会在低内存时assert/ESP_ERROR_CHECK的默认网络接口创建快捷函数；分步new、attach和设置默认事件处理器，每步检查错误。借用已有默认事件循环时不删除它，只有本模块创建的循环才在关闭时删除；全局esp_netif初始化不在关闭时deinit。

## 状态与停止

回调只更新互斥保护的状态，不连接、重试、切模式或访问TF。owner的poll确认AP地址或发起STA连接；只有状态READY且地址有效时，控制层才能开启HTTP。poll成功本身不代表已联网。

每个STA连接窗口最多三次连接调用、二十秒总窗口，重试间隔至少一秒。收到有效IPv4后READY；断连/丢地址清除旧地址，增加网络代次并开始新的有限重连窗口。HTTP控制层必须察觉地址丢失/代次变化，停止旧地址服务，不能继续展示失效链接。AP停止事件报告失败并清空客户端数。

关闭前先停止并清理HTTP/传输worker，再停止WiFi、注销本模块事件、deinit驱动、检查清除默认驱动/处理器、销毁网络接口，最后删除自己拥有的循环和上下文。部分启动后失败也尝试停止驱动。任何关闭失败保留对象与停止状态，供重试；不能提前释放仍被回调引用的内存或继续开启第二个会话。

控制API只由一个owner串行调用，读状态用锁保护；close时不得有其他控制/状态调用方进入，SDK事件注销后才能释放上下文。控制层的介质交接、锁屏/返回阅读位置、配网和二维码仍待装配。

## 可复跑检查

`python tools/dev.py host` 的device_wifi使用显式SDK驱动/事件/时钟/RNG stub：检查AP每会话口令改变、熵窗口先关闭再初始化RF、RAM配置、有效地址、STA断连三次/二十秒边界、不自动切模式、停止失败重试、部分启动失败清理、低内存接口创建返回错误、已有驱动/默认接口拒绝及共享循环保留。stub默认创建快捷函数设置为断言陷阱，确保新模块不调用它。

真实ESP-IDF编译不证明RF、SAR熵、手机兼容、重连、停止耗时、任务栈、功耗或网络性能已验证。这些门需在控制层和设备页面接通后通过真机测试。
