# 翻页手势、屏下三键与设置页

0.0.54实现FLIP-01的软件部分：手势阈值按 [界面与交互](UI_UX.md) 第7节初值、左右手与滑动/点按/三键开关、屏下触摸三键，以及设置页（现为一级页，翻页开关在“按键与手势”子页）。2026-10-13统一刷新周期，仅由“刷新与屏幕”的全局策略决定；逐书排版入口已移除，历史字段仅兼容读取。设备已有用户连续阅读反馈，最新刷新实现的光学效果仍待验收。三键坐标沿用参考固件实测值。

## 正文手势

pn_reader_input一次按下-释放最多提交一个动作（两次空采样确认释放，多点/读错/滑出按钮取消）。正文区y=100–1059：

- 横滑：|dx|≥64且|dx|≥1.5|dy|，向左下一页、向右上一页；不受左右手影响。
- 点按：移动≤24px；左边0–171、右边513–683。右手模式左上右下；左手模式交换（左边下一页）。中间区域点按不翻页。
- 底部按钮行（上一页/下一页/字号）不受开关影响。

pn_reader_input_config_t的零值即默认（右手、滑动与点按开启），设备每轮从已保存标志更新。

## 屏下三键

三键是触摸面板显示区以下的感应区，不是GPIO：y≥1300，x按160px分列，中心约80/240/400（参考固件实测）。pn_key在单点按下起点位于键区时开始，滑到别的键、多点、读错或起点在显示区都取消；按住满600ms发一次长按，否则释放（两次空采样）时发短按。

| 场景 | KEY1 | KEY2 | KEY3 | 长按 |
| --- | --- | --- | --- | --- |
| 阅读 | 上一页 | 打开/关闭工具栏 | 下一页 | KEY2回书架；KEY1/3不连翻 |
| 书架 | 上一书架页 | 聚焦本页第一本 / 打开焦点项 | 下一书架页 | 无 |
| 设置、目录、书签、排版、字体、壁纸、传书、搜索等管理页面 | 返回上一层；预览回表单 | 保存并回阅读首页 | 确认当前项，无选择时确认首个可操作项 | 无 |
| 确认弹窗（删除书签/字体/图书） | 取消 | 取消弹窗并回阅读首页 | 明确确认 | 无 |

管理页面KEY3确认等于点击当前项；阅读弹层使用已有语义选择，无选择时管理列表取首个可操作项。KEY1返回上一层，KEY2保存后关闭资源并回阅读首页；传输页面先等待停止与TF归还。保存失败保留会话。PC书库窗口数字1/2/3及key-left/key-home/key-confirm脚本对应新键位。“三键翻页”关闭时阅读中KEY1/3不翻页，KEY2仍可打开工具栏。左手模式不交换三键。锁屏时三键忽略。

## 设置

设置是一级页（底部三栏），进入前与其他子页面相同先保存并关闭正文。翻页相关在“设置 → 按键与手势”：机身示意（三个触摸键与电源键）、键位说明和四个开关：左手模式、滑动翻页、边缘点按翻页、屏下三键翻页。“设置 → 刷新与屏幕”有清晰/均衡/省电三档自动清残影（每6/14/24页整屏刷新一次）与“立即整屏刷新”。

每次成功前翻/回翻计一页，第6/14/24次直接使用GC16；首次打开、失败后的恢复和布局强制重绘另行全刷。重画当前页、工具栏、预览、EOF、取消、失败和预排不消耗页数。改变档位保留当前计数，下一次翻页按新阈值判断；成功物理GC16/手动深清/欠载恢复通过显示回执重置阅读周期。

普通正文使用原GL16全像素刷新，周期GC16直接整屏转换，不另插`epd_clear`。手动按钮（系统与阅读工具栏是同一动作的两个快捷入口）明确深清；未知参考/欠载也使用clear/from-white恢复。两处快捷动作不是两个配置。管理页面保留24次实际成功更新的独立保洁周期，局部区域≤45%（书籍操作面板≤60%）可GL16局部刷新；相同帧跳过、失败不提交计数。用途随本次操作传递，不从尚未更新的输入页面状态猜测。

三次面板翻页过渡改为一次最终16灰阶显示，系统不再提供动画选项。PNIP v2历史位6–7仍兼容读写，旧扫除/页折值统一直接呈现；无动画临时帧和模拟延迟。显示失败尽力恢复借用旧帧；取消/未进入显示队列的忙碌不额外恢复刷新。只有最终页成功才确认位置，保存失败与显示失败分别反馈。

四个开关和刷新策略立即写入`/data/progress/input.a/b`（PNJR，PNIP v2）；位0–3为开关、位4–5为策略，位6–7仅保留历史值，值3仍拒绝。v1继续读取，不自动改写旧记录；写失败重读并提示，显示已保存值。滑动、点按、三键不能同时关闭；内部存储不可用时显示默认值且不能保存。PC书库窗口在书架按P或点底栏设置进入，使用`--state-dir`。

工具栏只暂存y=888以下覆盖区112176字节，显示回执后无论成功/失败都恢复原正文像素，省去完整415872字节临时帧（减少303696字节）。正文备份仍不可回收；输入邮箱继续在扫描期间工作，导航最多保留最新一个，返回/工具可取消未交出的准备。失败提示随工具栏显示，后台保存错误等用户下一次打开工具栏再显示，普通翻页不额外刷新状态条。模拟器标题展示忙碌和保存错误，设备不把标题当物理反馈。
