# 翻页手势、屏下三键与设置页

0.0.54实现FLIP-01的软件部分：手势阈值按 [界面与交互](UI_UX.md) 第7节初值、左右手与滑动/点按/三键开关、屏下触摸三键，以及设置页（现为一级页，翻页开关在“按键与手势”子页）。刷新周期由“刷新与屏幕”的全局策略与逐书排版的“清残影”共同决定。全部只在主机/SDL验证；三键坐标沿用参考固件实测值，真机触摸坐标、灵敏度和手感都未测。

## 正文手势

pn_reader_input一次按下-释放最多提交一个动作（两次空采样确认释放，多点/读错/滑出按钮取消）。正文区y=100–1059：

- 横滑：|dx|≥64且|dx|≥1.5|dy|，向左下一页、向右上一页；不受左右手影响。
- 点按：移动≤24px；左边0–171、右边513–683。右手模式左上右下；左手模式交换（左边下一页）。中间区域点按不翻页。
- 底部按钮行（上一页/下一页/字号）不受开关影响。

pn_reader_input_config_t的零值即默认（右手、滑动与点按开启），设备每轮从已保存标志更新。

## 屏下三键

三键是触摸面板显示区以下的感应区，不是GPIO：y≥1300，x按160px分列，中心约80/240/400（参考固件实测）。pn_key在单点按下起点位于键区时开始，滑到别的键、多点、读错或起点在显示区都取消；按住满600ms发一次长按，否则释放（两次空采样）时发短按。

| 场景 | KEY1 | KEY2 | KEY3 | 长按 |
| --- | --- | --- | --- | --- |
| 阅读 | 上一页 | 打开/关闭工具栏 | 下一页 | KEY2回书架；KEY1/3不连翻 |
| 书架 | 上一书架页 | 聚焦本页第一本 / 打开焦点项 | 下一书架页 | 无 |
| 设置、目录、书签、排版、字体、壁纸、传书、搜索等页面 | 上一个可操作区 | 确认焦点项 | 下一个可操作区 | 无 |
| 确认弹窗（删除书签/字体/图书） | 取消 | 确认当前焦点（默认取消） | 切换焦点 | 无 |

页面里的三键焦点由 `pn_focus` 扫描页面命中函数得到，KEY2 确认等于点击该区域，焦点画圆角粗框。“三键翻页”关闭时阅读中KEY1/3不翻页，KEY2仍可打开工具栏。左手模式不交换三键。锁屏时三键忽略。产品决定维持这套键位，不改为规范V2的Home语义（见 [UI 规范 V2 对照](UI_SPEC_V2.md)）。

## 设置

设置是一级页（底部三栏），进入前与其他子页面相同先保存并关闭正文。翻页相关在“设置 → 按键与手势”：机身示意（三个触摸键与电源键）、键位说明和四个开关：左手模式、滑动翻页、边缘点按翻页、屏下三键翻页。“设置 → 刷新与屏幕”有清晰/均衡/省电三档自动清残影（每6/14/24页整屏刷新一次）与“立即整屏刷新”。

开关与刷新策略立即写入 `/data/progress/input.a/b`（PNJR，载荷PNIP v1：魔数、版本、标志字节；位0–3为四个开关，位4–5为刷新策略，其余位与未知版本拒绝）；写失败重读并提示，界面以已保存值为准。滑动、点按、三键不能同时关闭。内部存储不可用时显示默认值且不能保存。PC书库窗口在书架按P或点底栏“设置”进入，使用 `--state-dir`。

## 验证

`python tools/dev.py host`：key覆盖命中边界、短按、单次长按、单空采样抖动、滑键/多点/读错/取消/起点在外；settings_ui覆盖阈值边界、左手、滑动与点按开关、记录往返与未知版本、开关保存、不能全关、WRITE占用、子页请求、无存储及打开时逐分配失败；reader_input原有用例保留；transfer_view覆盖五槽菜单。`python tools/dev.py sdl`：settings_window覆盖“按键与手势”里开关跨进程保存、不能全关与跳转字体管理后返回设置；settings_ui另覆盖刷新策略、整屏刷新与存储与关于。设备三键与菜单装配只经两套ESP-IDF构建编译链接。
