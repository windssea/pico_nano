# 格式、元数据与封面设计

## 1. 支持矩阵与对用户的承诺

原生表示源文件由设备离线解析/渲染，无需预先转换。以下是目标范围，不是现有功能。

| 格式 | 级别/阶段 | 功能 | 明确边界 |
| --- | --- | --- | --- |
| TXT | 原生 / 0.1 | UTF-8/BOM、UTF-16 LE/BE、GBK；目录推断、段落设置、封面侧车 | GB18030 全覆盖不承诺；错误编码可手选，无 silent replacement |
| EPUB 2/3 | 原生子集 / 0.1 | OPF、NCX/nav、流式文本、基础 CSS、内联图片、脚注、封面 | 不宣称完整 EPUB reading system 合规；JS/音视频/远程资源/DRM 不支持 |
| PDF | 原生有界 / 0.2 | 原版页、目录、缩放、裁边、横屏、分区、文字层搜索、书签 | 不保证所有 PDF；复杂特性受预算与引擎过滤器限制，无自动 OCR |
| FB2 / FB2.zip | 原生 / 1.0 | 标题层级、段落、基础样式、base64 图片、封面 | XML 有界；无外部实体；压缩包仅一个主 FB2 |
| CBZ | 原生 / 1.0 | JPEG/PNG 顺序图页、首图封面、适配/宽适配/分区 | ZIP，不接受 RAR/CBR；无任意脚本 |
| MOBI / AZW3 | 电脑转换 / 1.0 | calibre 转 EPUB 后导入，保留能提取的元数据与封面 | 无 DRM 解密；不声称设备原生支持 |
| DOCX / HTML / MD / RTF | 可选电脑转换 / P2 | 转 EPUB/TXT | 不加入固件核心解析器 |

用户回复“1，2”按“转换方案可以接受，同时 PDF 必须原生”纳入；MOBI/AZW3 原生不是本版目标。EPUB 标准包括重排和固定布局；本产品默认支持重排子集，固定布局 EPUB 必须检测并提示转换为 PDF/CBZ，不能按乱码正文打开。[EPUB 3.3](https://www.w3.org/TR/epub-33/)

## 2. 公共文档模型

文档适配器输出 Metadata、Capabilities、SectionIndex 和 BlockStream。重排 block 包括 paragraph、heading、list_item、quote、code、image、link、footnote、table_fallback。每个 block 带源定位与样式引用，不将整本书展成一个巨大字符串。

固定页面输出 `page_count`、页边界、渲染条带与可选 text spans；PDF/CBZ 页不进入文本分页器。文档对象最多一个正在阅读；封面提取不能并发调用同一 PDF 引擎 context。

短章完整加载，长章切成 ≤256 KiB UTF-8 工作窗口；XML/HTML token 不在任意字节边界切断；跨窗口段落用有界续段状态。单段超过 64 KiB 产生连续段片段，但记录一个逻辑段落身份，设置缩进只作用首片段。这些能力需实现，不是参考代码已有的章节整段加载接口。

## 3. TXT

编码探测先 BOM，再严格 UTF-8，再 GBK；有效 UTF-8 的罕见 GBK 歧义仍给用户手动选择。UTF-16 校验代理对，拒绝奇数字节。解码错误统计并展示“编码可能不匹配”，不静默删掉字符。

章节：识别“第…章/节/卷”、英文 Chapter/Part 和明显单独标题，最小标题间隔防正文误判。导入后台扫描目录，未完成可立即读首段。标题规则和段落规范化版本纳入索引键。字节偏移始终映射源文件，转换后的临时偏移不作为永久进度。

段落模式先抽样最多 64 KiB 判断：空行比例、缩进、行长分布、结束标点；自动模式不合并诗歌/列表/代码疑似段。用户可切换每行一段/空行分段/合并硬换行，保留原文而非改写原书。

封面侧车优先同目录同 basename `.cover.jpg` / `.cover.png`，再 `.jpg` / `.png`；网页上传封面绑定 content_id 后存内部封面目录，不要求重写 TXT 文件。无封面生成书名＋作者/格式的黑白排版卡。

## 4. EPUB

ZIP reader 验证中央目录、本地头、CRC、重复规范化路径、解压大小、偏移溢出、加密与 ZIP64；继承参考的防御测试并扩充。资源路径在根内归一化，URL percent decode 一次后再拒绝越界；不请求远程图片、字体、样式或实体。

元数据 OPF：书名、作者、语言、标识符、系列（可识别扩展才使用）；目录优先 EPUB3 nav，次选 NCX，再生成 spine 标题。受限 CSS：font-size 相对比例、font-weight/style、text-align、text-indent、margin/padding 的有界 em/px、line-height、display:none、page-break、白空格；只支持 tag/class/id 的有限选择器，层叠优先级明确。没有 Grid/Flex、伪元素、复杂选择器与全浏览器 layout。

正文标题/引用/列表/代码保持语义；段落样式可由用户覆盖。表格采用窄列文本回退或图片视图，不挤压成难读一行。链接跳本地资源/锚点；脚注使用弹层与明确返回点；外链仅展示地址，不启动网络。

图片 JPG/PNG：可设“正文内嵌”或“占位点击”。默认小图内嵌、大图占位，像素预算内按比例缩放；解码失败不妨碍文字。SVG 仅识别包含单张本地 JPG/PNG 的 wrapper，不实现通用 SVG。

封面优先级：manifest `properties=cover-image` → EPUB2 meta name=cover 指向 manifest → guide cover 文档内第一张有效图片 → spine 首页有效大图 → 排版卡。必须查内容类型与资源有效性，不能只看扩展名。误取封面可在详情或网页更换。

EPUB 嵌入字体默认关闭，避免内存/缺字与授权混乱；开启仅接受通过校验的 TTF，跟随文件许可。标准字体混淆与 DRM 是不同事物；未实现混淆时给“嵌入字体不可用，已用设备字体”的明确回退，不解密 DRM。

## 5. 原生 PDF：前置技术门

候选为经过裁剪和预算分配器适配的 MuPDF；仅候选，不预设可在 ESP32-S3 成功运行。其公开发行采用 AGPL，另有商业授权；在接受相应发行许可/采购许可前不能把它塞进 Apache-only 产品。[MuPDF 官方发行与许可说明](https://mupdf.com/releases)

技术样机内容：交叉编译无 GUI PDF-only 引擎，保留中文字体/字形、常用压缩、图像过滤器；关闭 JS、网络、其他格式与不可用特性。记录 commit、裁剪项、许可证和对应源码。引擎所有分配接入 ≤3 MiB PDF 堆预算，CPU 超时与取消通过可中断点控制；条带输出并不保证解析/display list 的峰值降低，必须测实际整条管线。

样本必须有：文字 PDF（嵌入 TrueType/CID/CJK 字体）、扫描 JPEG/PNG PDF、混合图文、xref stream/object stream、透明度、旋转 CropBox、损坏文件、超大图片、缺字字体、加密 PDF。常见过滤器支持需引擎实际测试确认；初版不支持的 JBIG2/JPEG2000/复杂透明组合明确报错，不返回白页成功。

原生门：标准 PDF 语料至少 90% 成功打开且内容可见；无系统 OOM/看门狗；峰值符合总预算；常规首屏 p95≤4 s/后续页≤2 s；6 MiB app 槽保留 10% 余量；中文无缺字回退异常；许可发行方案可执行。90% 是选定 40 本基准语料的指标，不代表全世界 PDF 兼容率。

文字型 PDF 与扫描型 PDF 均需原生能力。失败时先对比引擎/过滤器开销与字体库，不自行写“完整 PDF 解析器”；必要时重新讨论资源或硬件。电脑可选转换是故障替代途径，不替代原生需求。PDF 转重排文本可能破坏多栏、图片和数学布局。[calibre PDF 转换限制](https://manual.calibre-ebook.com/en/conversion.html#pdf-conversion)

渲染：fit-page 基准 → CropBox/旋转 → clip 视口 → 684×96 灰阶条带（65,664 bytes）→ 4bpp 全屏页。先定义整页、宽适配与固定倍率，再评估松手提交的 pinch。取消需在条带/对象边界响应；无法达到 100 ms 软件取消目标的引擎必须说明和优化。

PDF 封面是首个可渲染页面缩略图，可后台生成；页面无法渲染时显示带 PDF 标签的排版卡。视图设置与原 PDF 内容分离。初版不支持密码输入，检测加密给明确提示；密码支持列 P2，不承诺绕过权限。

## 6. FB2 与 CBZ

FB2 SAX/token streaming、禁 DTD/外部实体；section 层级、p、title、emphasis、strong、poem/stanza、cite、image 与 coverpage；base64 解码边界及资源预算校验，不能将所有 binary 同时常驻。

CBZ 自然排序：数字段按数值，同值按原名字稳定排序；优先 ComicInfo.xml 已验证的页序元数据，否则目录排序，跳过隐藏/非图像条目；封面首图或显式封面。图页可整页、宽适配、旋转、由上到下分区，不承诺自动漫画格子检测。

## 7. 限额与降级

| 项目 | 初始限制 | 行为 |
| --- | --- | --- |
| TF 单书 | 128 MiB | 导入拒绝更大；PDF/CBZ 单独实验可提高，不放开内存预算 |
| 内置单书 | 512 KiB | 内部 data 与日志共享 1 MiB，实际可用空间先核验 |
| ZIP 条目/章节 | 各 32768 | 拒绝 ZIP64/多磁盘/加密，继承参考计数保护 |
| ZIP 中央目录 | 8 MiB，窗口读 | 不整体加载；名称 ≤1024 bytes |
| OPF/nav | 各 4 MiB 解压 | 流式解析且内存分配另有预算，4 MiB 不是允许整表常驻 |
| 单文字资源 | 16 MiB 解压，窗口处理 | 每章页表磁盘分段，不受旧 4096 页内存数组限制 |
| 单图资源 | 8 MiB 压缩上限 | 必须同时符合解码像素与堆限额 |
| 基线 JPEG | 16M 源像素，最长边 8192 | decode-time scale，超限提示 |
| PNG/渐进 JPEG | 1M 源像素 | 缩放输出不能掩盖源解码大内存，失败可电脑预处理 |
| TTF 文件 | 32 MiB | TrueType outlines；文件大小不等于 RAM 占用 |
| 单层 XML 深度 | 64 | 超深错误，绝不递归栈溢出 |

以上是拟定产品限额，M0/M3/M6 验证后只允许在文档与测试同步更新的前提下调整。文件大小、条目数、图像像素、解析堆和耗时是互相独立的限制。

## 8. 封面缓存

统一缩略图 184×256 / 4bpp=23,552 bytes，预览大图按需生成；contain 不裁书名，不拉伸。缓存键=book_id＋cover source digest＋算法版本＋尺寸。灰阶量化先 linear/感知对比度，再选择轻度有序抖动（仅封面），不对文字用抖动。

RAM 最多可见六张＋一张候选，共约 161 KiB；磁盘缓存默认 32 MiB、上限 128 MiB，LRU 优先清理未收藏且最近未读封面。缓存损坏重新生成，不删除原书。封面导入阶段失败可继续入库，详情展示失败原因与重试入口。

0.0.14仅完成EPUB所需ZIP资源层及本地路径解析，不能视为EPUB原生阅读完成；实际源码边界见 [容器层](EPUB_CONTAINER.md)。
