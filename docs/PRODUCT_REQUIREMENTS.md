# 产品需求与用户流程

状态：设计 v1.0。本文编号用于开发计划与验收追踪。P0 为首个内部可读版本必需，P1 为完整 1.0 必需，P2 为后续增强。PDF 属于 P1 且必须在最早技术阶段验证。

## 1. 用户与场景

- 中文小说读者：长时间离线阅读，字号、字重、段落适合眼睛，唤醒继续读。
- EPUB/PDF 资料读者：保留章节、图片与原版页面，能看清小字，快速跳转与书签。
- 手机传书用户：不安装专用 App，扫码即可传书及字体。
- 电脑批量管理用户：拖放多文件、保留封面、转换 MOBI/AZW3，可靠覆盖与续传。

设备无前光硬件依据，不设计“亮度”滑条；无扬声器/TTS 产品需求，不提供假朗读功能。

## 3. 阅读设置的范围与默认

| 项目 | 默认 | 范围 | 作用域 |
| --- | --- | --- | --- |
| 正文字体 | TF 完整中文字体；缺失用 UI 子集提示 | 通过校验的 TTF | 全局默认＋逐书覆盖 |
| 字号 | 44 px | 28–72 px，每 2 px | 重排文本 |
| 字重 | 字体正常字重；可变字体 wght=400 在可用范围内夹取 | 字体真实轴范围；静态字体另选文件 | 重排文本 |
| 行距 | 1.45 em | 1.15–1.90，步进 0.05 | 重排文本 |
| 段距 | 0.40 em | 0–1.20，步进 0.10 | 重排文本 |
| 字间距 | 0 | 字号的0–50%，步进5%；与其他段落参数均可预览 | 重排文本 |
| 首行缩进 | 2 em | 0、1、2 em；诗歌/标题不继承 | 重排文本 |
| 左右边距 | 32 px | 20–64 px，步进 4 | 重排文本 |
| 上下边距 | 32/40 px | 20–64 px，步进 4 | 重排文本；包含独立页脚约束 |
| 对齐 | 中文两端，英文左对齐 | 自动、左、两端 | 禁止过度拉伸最后一行 |
| 段落模式 | 自动检测并保留原文 | 自动、每行一段、空行分段、谨慎合并硬换行 | TXT |
| 翻页 | 边缘点按＋水平滑动＋三键 | 左手/右手、滑动、三键可单独开关 | 全局 |
| 刷新 | 清晰均衡 | 清晰均衡、快速、图片优先 | 全局＋逐书覆盖 |
| 周期强刷 | 12 页 | 6、12、24 页；快速档不允许无限关闭 | 灰阶内容切换也强刷 |
| 状态栏 | 底部百分比＋章内页码 | 隐藏/简洁/详细 | 全局 |
| 自动锁屏 | 5 分钟无输入 | 1、3、5、10、30 分钟、关闭 | 全局 |
| 深度节能 | 锁屏后 15 分钟 PMU 软睡 | 5、15、30 分钟、关闭 | 软睡重启恢复位置 |

预设：舒适（44 px/1.45/32 px）、紧凑（38 px/1.30/24 px）、大字（56 px/1.50/40 px）。预设只改排版，不改字体选择和逐书书签。

PDF 原版与 CBZ 不展示 FONT-01/TYPE-01 重排控件；用页适配、宽适配、90°旋转、裁边、缩放、分区步进替代。PDF 后续“文字重排”是 P2 独立能力，不假定所有 PDF 可正确提取文字。

## 4. 核心旅程

### 第一次使用

首次开机展示语言（默认中文）与三键提示 → 检查 TF 与完整字体 → 进入空书库，提供“扫码传书”和“查看内置使用指南”。无卡可使用内置小书库，不循环提示插卡。VCOM 未标定先进入独立出厂流程，不出现在日常设置。

### 找书与开始阅读

书架“继续阅读”卡片一触恢复 → 可见章节正文先出屏 → 剩余页后台分页。网格点击封面直接打开；长按 600 ms 展示详情、收藏、书签、清进度和删除；删除须独立确认。最近记录不是文件身份。

### 调整排版

点中央 → 排版面板 → 点字号/行距档位 → 停止 250 ms 后更新预览区域 → 点“应用”保存并回到同一文本锚点；“取消”恢复设置及位置。预览是当前段落节选而非整本书重排。退出未应用时默认取消，不偷偷保存。

### 导入图书

书架点“传书” → AP 模式显示加入热点二维码与打开网页二维码，切换时明确说明两个步骤 → 手机网页拖放/选文件 → 显示发送、校验、入库三个阶段 → 完成书架可打开。STA 已保存网络可一键连接，配网密码不写日志。

### PDF 阅读

封面点击 → 自动适配整页 → 点中间显示“宽适配/裁边/缩放/横屏/目录” → 宽适配使用分区前进而非连续滚动画面 → 保存实际 PDF 页与视口，唤醒原位恢复。无文本层的扫描 PDF 仍可原版阅读，不显示无效搜索。

## 5. 必须定义的异常

| 条件 | 用户看到 | 保留什么 | 下一步 |
| --- | --- | --- | --- |
| 缺完整字体 | 正文缺字提示＋“选择字体” | 原书和位置 | 传完整 TTF，UI 继续可用 |
| EPUB 超限/损坏 | 具体限制与文件名 | 书库入口 | 查看详情/删除/电脑转换 |
| PDF 超内存/不支持过滤器 | 指明复杂页面与失败页码 | 已读位置 | 换页面、降低缩放、电脑转换副本 |
| TF 拔出 | “卡已移除，已停止阅读” | 内部进度记录 | 重插后显式重挂载，不自动读旧句柄 |
| 同路径新内容 | “文件已更新” | 旧书历史另存 | 按新内容身份打开 |
| 上传空间不足 | 所需与可用空间 | 已有文件、可续传状态 | 清理后继续或取消 |
| 文件系统损坏 | “存储需修复” | 不自动格式化 | 只读恢复/电脑检查；格式化二次确认 |
| 升级失败 | 回旧版本＋错误原因 | 可兼容的设置与书库 | 换升级包重试 |

## 6. 暂不加入

字体上传与锁屏壁纸的完整流程、限额、缓存和管理契约见 [专项设计](FONTS_AND_WALLPAPERS.md)。二者属于0.1基础体验，分块续传在后续Beta加入，不把普通流式上传称为持久续传。

商店、账号云同步、DRM 解密、浏览器、在线视频、持续翻页动画、手写笔记、OCR、通用 MathML/JavaScript、复杂文字塑形与全书 PDF 自动重排。中文、日文横排和拉丁文本优先；RTL 与复杂文字需额外塑形引擎后才能宣称支持。

## 7. 基础阅读功能完整性与恢复规则

上次阅读位置、书签和最近阅读原已包含在READ-02；现拆成READ-02/05/06，避免一条需求掩盖遗漏。需求存在不代表设备功能已实现；当前实现状态见 [位置与书签维护契约](READING_STATE.md)。

- 上次阅读位置：每本书独立保存，A读一半切B再返回A仍回A原位。只记录成功显示的位置，不保存预绘制或旧会话完成。改字体、字号、段落、方向后保留源锚点；正常唤醒回当前书，重启首页提供继续阅读，不擅自打开已删除/替换的同名文件。
- 自动保存：5次有效翻页或首次未保存变化满30秒先到即触发；连翻不能推迟时间起点。离书、锁屏、关机执行保存屏障；失败保持待保存状态，不能显示已保存或直接切电。异常断电仅保证最后有效提交；文件系统损坏/存储失败时不能承诺5页/30秒上限。
- 书签：工具栏添加当前可见位置，默认名称来自章节/短正文摘要；同书同语义位置重复添加提示已有书签。列表显示名称、章节/进度，支持跳转、重命名、单条删除；删除需确认。跳转保留跳转前位置，提供返回。重排不会把书签永久绑定到旧页码，清进度默认保留书签。
- 恢复：TXT按原字节与编码/段落策略，EPUB/FB2按章节/块/偏移及锚点，PDF/CBZ按原页与视口。换卡、同名不同内容不能误恢复；相同内容移动路径可以经重新识别关联历史。书签删除用可恢复事务，不清其他书或上次位置。
- 历史：最近阅读与继续阅读使用内容身份和可用路径实例，支持查看详情、清除单条历史/明确确认清全部；清历史不删除原书/书签。无历史显示空态；卡缺失或文件不可用保留历史并提示重插/重新定位。
- 其他基础功能已覆盖：章节目录、前后页、百分比跳转、阅读进度、封面、字体排版、翻页设置、锁屏壁纸、传书、逐书设置与错误反馈。阅读时长/统计、划线批注、笔记和云同步不是本轮P0承诺。


## 界面语言约束

所有产品界面的标题、按钮、设置名称、引导、状态与错误反馈使用中文；后续传书、字体上传、壁纸及配网界面沿用此约束。首行缩进、行间距、段落间距、字间距必须在配置界面可修改、可预览，并提供应用/取消；预览明确标为未保存，不偷偷写入设置或移动到章首。既有全局预设与逐书覆盖目标保留。

必要的格式/协议名（TXT、EPUB、PDF、Wi-Fi等）、品牌Pico和用户自己的书名、正文、文件名、字体名、SSID按原样保留；不能为了中文化修改用户数据。UI用“像素”“缩小”“放大”“缺字”等中文，工程CLI选项、测试脚本标识、日志、代码API可保留必要英文。中文菜单常驻字体不依赖用户正文TTF，避免英文/不完整字体导致中文控件失效。
