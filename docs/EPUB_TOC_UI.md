# 中文EPUB目录界面与跳转

0.0.29新增pn_toc_ui，设备、PC书架和独立EPUB窗口共用紧凑十项目录页、层级标签、翻目录页、返回/重试与条目跳转。图像来自已实现原NCX/nav数据，不虚构章节。它不是全部EPUB书签/设置功能交付，真机仍待验收。

## 菜单与确认

每行88逻辑像素，短标题垂直居中，长标题最多两行，层级缩进保留。打开时，若目录唯一对应当前章节，直接进入所在页并标出当前条目；顶部“当前”（PC Home）可从其他目录页快速定位回来，不跳正文。单个章节文件有多个片段目录时不猜测精确条目，保持普通分页，定位按钮不展示。首尾分页按钮禁用；菜单浏览不保存或修改正文位置。

正文右上“目录”进入；PC也可按T，目录中上下选条目、Enter选择、左右/翻页键换目录页、Esc/T回正文、F5重试。鼠标与设备触摸共用逻辑hit，两次空触摸确认单次点击，滑出/失焦取消，PC顶栏需要完整按下/抬起。目录显示最多两行标签，保留用户原文，层级缩进限3级的可视宽度；更深层的语义数据仍保留。

页数由完整目录条目数计算，每页10条；纯分组不可作为目标，显示中文反馈。无目录显示“暂无目录”，不是生成假的目录。源读取错误不改为成功的空列表，重试仍重新核对目录数量及介质有效性。

菜单通过pn_epub_app_overlay的纯绘制回调和显示owner呈现，不调用核心位置complete/保存；原visible位置保持。只有菜单已显示成功才能执行翻菜单页/条目选择，未确认返回BUSY；重试和安全返回可用。跳转经过id/章节解析、完整正文/图片CRC/真实显示确认，失败保留目录与原位置，成功才关闭菜单。保存错误可能发生在显示成功之后，若位置已确认则退出菜单留真实新页，外层保留保存屏障。

返回正文走CURRENT再呈现，保持同语义锚点，接下来正文强刷清残影。关闭/拔卡/系统错误丢菜单，不删除目录或原文位置；书架/设备共用原保存与媒体租约约束。

## 字体和资源

标题/操作中文常驻36px字体，条目使用28px常驻字体，缺字沿用元数据字体回退，仍缺字显示方框。用户的中文/英文目录原文保持，不为了中文化改书。overlay借用FT/帧且paint不得写配置、I2C、蜂鸣或睡眠。菜单数据只持10个标签/层级/目标标志，完整路径由出版物模型在选择时重新验证。

本机《绍宋》480条目录显示48页，第一目录页含制作设计、简介、卷和前三章，层级缩进与中文标签真实显示。捕获在忽略build目录，原EPUB/TTF不修改；主机图不是纸屏照片/速度测量。
