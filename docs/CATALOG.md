# 文件书架与选择阅读

0.0.9提供共享文件书架，可在设备及PC选择TXT。它是第一版开发中的一个入口，封面提取、元数据索引、最近阅读和书签列表仍在后续开发范围。

设备优先读取TF上的books目录，目录不存在时读取TF根目录，不递归进入子目录。每页六本，0.0.56起按书名拼音首字母排序（见下文“排序与字母跳转”）；不是完整拼音或自然数字排序。点TXT行进入阅读，点阅读页左上方返回书架，底部按钮切换书目页。上次阅读位置按内容SHA恢复，同名不同内容不会混用位置；同内容不同文件名共享位置。

TXT/EPUB/PDF/FB2/CBZ扩展名均可识别并展示，大小写不敏感。当前TXT和EPUB连接解析器；PDF/FB2/CBZ条目提示尚未接入，保留文件。0.0.49起EPUB/TXT有可用封面时显示真实缩略图，无封面、不支持或提取失败仍显示格式占位卡，见 [书架封面](COVERS.md)。显示文件名和文件大小，不读取作者/标题元数据。长名称最多两行，超出裁切；UI字体子集缺字显示方框，完整书名字体回退仍待完善。

## PC窗口

先运行 `python tools/dev.py sdl` 验证SDL构建及dummy事件测试。真正显示窗口需要有桌面环境的Linux/WSLg，在该环境构建并执行：

```sh
cmake -S simulator -B build-sdl -DPN_SIM_SDL=ON
cmake --build build-sdl
build-sdl/pn_sim --library /path/to/books --state-dir /path/to/state
```

上/下选择，Enter打开，PageUp/PageDown切书目页，Esc从阅读保存返回、从书架退出。阅读中左右键翻页，+/-调整字号；鼠标支持书架行/按钮、正文翻页和左上方返回。`--font FONT.ttf`选择正文TTF，不改变书架常驻UI字体。保存失败留在阅读会话，Esc重试，不丢dirty位置。窗口关闭请求同样先保存。

`--library`不可与`--book`、静态捕获或headless组合。Windows Docker的dummy驱动只跑自动事件，不展示Windows桌面。PC模拟共享逻辑、字体和状态，不模拟ESP32指令、电纸波形、功耗或真实SD时延。

## 版面（0.0.56后）

书架按 [界面与交互](UI_UX.md) 第3节排布，坐标为684×1216逻辑像素：`y=0..63` 状态带（产品名；有电量数据时右侧显示电量，设备暂无PMU电量接口故不显示）；`64..143` 标题“书架/搜索结果/最近阅读”与右侧“搜索”入口（放大镜加文字；搜索结果态改为“清除”）；`144..319` 继续阅读卡（最近一本的封面、书名、进度，整卡可点）；`320..399` 全部/最近页签、排序说明与（可选）网格/列表切换；`400..1055` 三列两行封面网格（封面184×256，列x=32/244/456，封面下一行书名、一行“进度 · 格式”，如“27% · EPUB”“未读 · TXT”）；`1056..1103` 页码信息“n / m 页 · 共 N 本”，有上一页/下一页时两端出现可点箭头；`1104..1215` 底栏“书架 / 传书 / 设置”。传书未接入的平台（PC窗口）画删除线且不响应。

渲染与命中通过 `pn_shelf_options_t`（电量、搜索入口、网格/列表切换、搜索结果态）定制，不传选项即旧外观。点标题行下排的网格/列表图标切换：列表模式每页5本（80×112缩略封面、全名最多两行、“进度 · 格式 · 大小”），取页函数用 `pn_catalog_*_n` 的 limit 参数把页容量设为5，翻页、搜索结果和最近阅读都按同一容量计页；切换后回到第一页。选择/批量管理入口尚未实现。

## 搜索

点“搜索”打开搜索页：输入框加6×6屏幕键盘（a–z、0–9），“删除/清空/搜索”三个操作键。匹配规则见 `pn_catalog_match`：小写字母与数字对书名里的英文原文做不区分大小写的子串匹配，或对汉字书名的拼音首字母序列（如“bnzd”）做连续片段匹配；结果仍按书名排序、每页6本，分页与“n / m 页”按匹配结果计。搜索结果态下标题为“搜索结果”，点右上“清除”或切换全部/最近即回到完整书架。搜索只匹配书名，不匹配作者或正文；汉字输入法与联想不在范围内。PC窗口按 `/` 打开。

没有封面的书画排版卡（细框、书名、格式标签），有阅读进度的书在封面底部画进度条。书名取文件名去掉已识别的扩展名；UI字体只是常驻子集，缺字时借阅读字体补，仍缺才画方框。电池、搜索、排序切换没有对应数据或功能，所以不画入口；“按书名排序”只是说明文字。上一页/下一页行高只有48px，低于80px的命中下限，是已知偏差。

## 有界分页契约

pn_catalog借用已挂载介质的READ租约，扫描前、逐条和结束校验代次，不挂载、写文件或取得长期独占权。每次扫描只保留六条候选；previous查询选择游标之前最近六条，next选择之后最近六条。page.more始终表示本页末尾之后还有条目，返回前页后仍可以再往后翻。

忽略隐藏文件、不支持扩展名、非普通文件、非法UTF-8/控制字符/路径符号、超长名称或完整路径。主机lstat拒绝条目符号链接；设备FAT使用stat。目录路径由可信owner提供，调用方不得用不可信上传参数直接指定扫描目录。无法stat的条目计为跳过，opendir/readdir/closedir失败返回IO；损坏介质不能被当作成功的空书架。

文件名缓冲768bytes、完整路径1024bytes，每页固定六条；绘图帧为684×1216、4bpp。实现每页全目录扫描且逐条stat，内存不随库大小增长，但时间仍为O(N)，没有异步取消、deadline或持久索引，不承诺大书库打开速度。1000个真实文件测试验证分页和过滤；真实FAT长文件名、DPI/触摸、性能与媒体拔插仍需上板测试。

静态书架捕获工具 `pn_shelf_snapshot BOOK_DIR OUTPUT.pgm` 使用相同查询和绘制，只写指定图像，不打开正文或修改阅读历史。自动回归入口：`python tools/dev.py host`、`python tools/dev.py sdl`、两个firmware构建和`python tools/dev.py docs`。

基础阅读功能的实际覆盖见 [阅读状态契约](READING_STATE.md)，设备挂载及硬件边界见 [设备接入](DEVICE_PORT.md)。

## 排序与字母跳转

pn_catalog_compare逐字符比较排序键：拉丁字母不分大小写，GB2312一级汉字（3755个常用字）取拼音首字母，其他ASCII（数字、符号）保持原码位排在字母前，二级汉字、假名等其余字符排在字母之后；全部键相同时再按UTF-8字节，因此是全序，翻页游标仍用完整文件名。“Apple”排在“安徒生”前（第二字p<t），“bible”排在“北京”前。首字母表由 `tools/gen_pinyin.py` 用Python严格gb2312 codec与一级汉字拼音分界生成 `pn_pinyin.generated.h`（约11KB），host测试 `--check` 防手改。只用首字母，不区分多音字，不比较完整拼音或声调。

书架标题“书架 · 按字母”可点开A–Z与#的字母页（最近模式不显示）；选字母后从第一个首字母不小于该字母的书开始一页，之后正常前后翻页；该字母没有书时落到下一个有书的字母或“其他”区；之后都没有书则显示最后一页；#回到首页。设备三键在字母页不生效。PC书库窗口按J打开。字体与壁纸目录同样使用此顺序。

0.0.12顶部增加“最近/全部”切换与“继续”入口。R切列表，C继续最近一本，读取时核对期望SHA；原文件缺失或同路径内容改变不会清历史。详细维护契约见 [最近阅读](RECENT_READING.md)。
