# 日期与网络对时

当前为开发代码，尚未构建或发布到网页安装器。入口为设置 → 存储与关于 → 日期与时间。显示完整日期与分钟，时区固定UTC+8；未知时间明确显示未校准，不用编译时间推测。开机仅从PMU读取已对时的UTC，不自动联网。

保存家庭WiFi后可选择“立即联网校时”。控制层读取内部data的已保存凭据，创建单owner对时任务；首次轮询才启动STA无线，临时口令用后清零。网络对时不使用TF，不与传书共享无线所有权。连接沿用二十秒/最多三次尝试规则，连通后向pool.ntp.org请求SNTP，等待最多十二秒；需要路由器能访问互联网和解析DNS。

每次推进调用esp_netif_sntp_sync_wait(0)，不等待网络结果。只有本次SNTP确认成功且UTC在2024–2099年范围内才接受结果。已有系统时钟不能替代本次确认；SNTP可能自动调整系统时钟，但产品显示和PMU只在完整提交成功后更新。

先停止SNTP并完整释放WiFi、恢复原USB数据状态，再按单调计时补偿清理耗时，由控制层发TIME_SYNC（四字节小端UTC）和TIME_GET；单调时间倒退或补偿后超范围不提交。必须读回已对时标记与相符时间才更新日期及状态带时钟；不写VCOM、校准、电源时序或NVS。读回失败保留原显示，并提示设备时钟未确认。PMU保存的是其运行期间的时基，PMU复位后仍可能需要重新校时，不宣称永久RTC保持。

页面可以返回上级，任务继续有界推进。“结束对时”请求取消后等待资源释放；停止失败保留句柄重试，不提前恢复USB或睡眠。电源键先取消，完成清理再走保存/锁屏屏障；对时期间禁止自动待机，不能开始第二个传书会话。页面绘制只使用控制层状态，不做网络或硬件I/O。

主机SDK替身覆盖本次确认、零等待、超时、开始前/等待中取消、无线清理失败重试、SNTP初始化失败和非法UTC；PMU替身覆盖命令限制、小端载荷、释放门、读回失效及输出保留。共享设置UI覆盖日期跨天/闰日、禁用/运行按钮、未呈现屏障与返回层级。PC模拟器显示本机时间、禁用联网按钮；不模拟网络或PMU成功。真实DNS/SNTP、功耗、按键取消和PMU走时仍需构建后刷入验证。
