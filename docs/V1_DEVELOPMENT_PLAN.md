# PicoNano 1.0 开发执行计划

更新：2026-10-12。对应 [1.0产品与验收计划](V1_PRODUCT_PLAN.md)，源码基线`cf99c18`。本计划列剩余开发工作，全部勾选项初始未完成；当前已有实现见 [PROJECT_STATUS](PROJECT_STATUS.md)。软件测试、编译、模拟器观察、真机启动和产品验收分别记账。

## 1. 执行原则

- 在`D:/dev/windssea/pico_nano`开发，参考仓只读；路径由工具相对工作区解析，不继续依赖旧`D:/windssea/dev`硬编码。
- 使用ESP-IDF v6.1、ESP32-S3；两套SDKCONFIG独立。VCOM仅从PMU读取，无有效值不推屏；不写SY7636A标定/时序，不格式化失败介质，不静默擦NVS。
- 共享源实现阅读、排版、字体、UI和状态机，PC只替换port。render只绘制，存储/电源/网络副作用在控制和适配层。
- 新代码注释中英双语，公开API/成员使用`///`；vendor、波形、stb和生成fallback表保持来源与许可证，不借优化手改。
- 各上传通道复用固定目录和共享安装事务；USB独占与阅读/传输租约不能重叠。
- 不启动子agent；任务依赖图仅表示工程依赖，不代表授权并行agent。按工作包持续开发、验证与阶段提交。
- UI开发保留可见模拟器；重建后重启窗口。过程日志、性能数据和照片放忽略的`docs/local/`或`build-dev/`，长期行为写对应功能文档，CHANGELOG轻量记录。
- 本文件的候选文件/接口是拟建范围，先核对既有模块后增量落地，不为符合目录示意重写已验证组件。
- 微信读书不参与1.0实施、依赖与验收，后续演进不挤占本计划。

## 5. 风险与降级规则

| 风险 | 处理与允许降级 | 不允许的替代 |
| --- | --- | --- |
| PDF许可/内存失败 | 更换引擎或重新评估硬件，保持开发版 | 删掉原生PDF后称1.0完成 |
| TLS/WiFi挤占内存 | 阅读/传输分时、收回可回收帧/缓存、握手限额 | 关闭证书校验或无界分配 |
| PNG/大渐进JPEG | 行/条带缩小、预算与取消、保旧图/明确错误 | 不支持PNG或坏图覆盖有效锁屏 |
| 网格/大封面欠载 | 暂停封面、占位/列表；大封面未过门延期 | 牺牲输入或隐藏书目 |
| 快速二值/反色不清晰 | 保留默认GL16，候选能力不启用并说明 | 默认模式丢细笔画仍称300ppi优化 |
| 索引损坏/外部换卡 | 受控重建、重新SHA、取消旧代 | 格式化/误用其他书进度 |
| 壁纸A/B空间不足 | 压缩元数据/校核文件系统或单独评估布局，保进度与双槽 | 侵占位置分区、自动格式化 |
| 缺样机/测试卡 | 软件继续，阶段出口未验收/Beta | 用SDL速度、截图或编译代替实测 |
| USB硬件门失败 | 1.0无线导入，记录失败与恢复路径 | 并发访问TF或虚假可用入口 |
