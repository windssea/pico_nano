# 阅读字体选择

字体选择只针对电子书正文，界面始终使用当前常驻UI字体。列表只有“默认字体”和“外置字体”；外置字体是用户上传到 fonts 的 TTF，PC使用配置的字体目录（本机 mockDoc/LXGWWenKai-Regular.ttf 可用于测试）。文件名保持原名，不改私人字体。

## 操作

从正文排版页进入“阅读字体”。顶部默认字体为系统内置阅读字库，点击名称立即应用本书；右侧箭头可看详情/预览。选择默认会保存本书的明确默认选择，不读取外置阅读默认，也不写继承标记。默认正文为内置 Noto Sans SC Regular（400字重）黑体阅读字库，覆盖GB2312常用汉字、标点、现有界面字集及全角符号，不依赖SD卡字体文件。界面仍使用原来的精简字库。生僻字、繁体全集及其他文字不保证完整覆盖，可选择外置完整字库。

外置字体六项分页，点击名称校验实际内容、摘要和字体格式后应用本书；右侧箭头进入详情。详情有原文预览、应用本书、设为默认阅读字体及取消。原文预览不保存，应用实际呈现后才保存本书选择，重开恢复；保存失败沿用原来的重试/取消屏障，原文锚点保持。

不再展示“继承全局”“正文/备用”或“内置界面字体”。新选择只设置正文，额外备用文件归零，缺字由内置阅读字库回退链处理。既有记录仍兼容读取，未选择前不擅自改写；新的明确选择才替换旧组合。字体菜单标签只用常驻UI字体，不借所选阅读字库改变菜单字体。字体详情的原文预览和管理页字形样本按所选字库展示。

“设为默认阅读字体”仅用于之后打开且未单独设置的书，不改变界面字体、不覆盖逐书选择，当前书仍需应用本书。保存该默认后，取消本书草稿不会撤销已保存的阅读默认。文件内部仍使用原有全局记录格式，产品界面不暴露继承操作。

字体管理使用“默认阅读字体”“外置字体（用户上传）”文案；上传继续经共享安装层进入 /fonts。列表与详情都说明设置针对阅读，界面字体固定。

## 输入和测试

PC排版页F进入；上下选择、Enter看详情/应用，PgUp/PgDown翻页。I查看默认详情，H恢复本书默认；不再提供2键备用选择。详情P预览、G保存阅读默认、Esc返回列表，列表Esc取消。

主机与SDL验证TXT/EPUB/书架的预览取消、正文选择与系统回退、逐书持久保存、阅读默认保存不修改逐书记录、默认恢复不写继承标记及点击入口。字体和排版草稿保持独立；未成功呈现时禁止保存。具体字体事务与旧记录兼容见 [字体切换](FONT_SWITCHING.md)、[字体偏好](FONT_PREFERENCES.md)。原始小说/字体只读，捕获和输出放build-dev，不作为真机显示或全字库覆盖证明。

## 字库维护

阅读资源是 assets/fonts/read-pico-reading.ttf，来源与OFL许可、请求/实际码点和SHA记录在 LICENSES/reading-font-manifest.json；与界面资源分离，两者共用 assets/fonts/OFL.txt。由 tools/subset_reading_font.py 从固定SHA的 Noto Sans SC 可变源生成400字重，子集按OFL要求改为 Read Pico Reading Sans 内部族名。使用清单记录的fontTools版本和 --replay 可复建同一字库；tools/check_docs.py 校验来源、许可和产物摘要。嵌入生成C文件留在构建目录，不提交。

苹方不随固件分发；采用Noto的OFL授权。覆盖范围明确按GB2312而不是整部Unicode，罕用文字应通过原文预览与外置字库检查。此字库增加约2.34MB固件只读资源，不整体复制到PSRAM；FreeType按既有有界源和字形缓存读取。字体变化可能改变旧默认正文的换行，逐书阅读位置仍按原文锚点恢复。
