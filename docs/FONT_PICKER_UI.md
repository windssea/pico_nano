# 中文字体选择菜单

0.0.37接入设备触摸和两种独立PC窗口/混合书架窗口。从正文“排版”页右上“字体”进入，六项分页，选择正文或备用目标，再选择文件。菜单保留另一项字体，不悄悄清掉已选备用或正文。

## 操作

文件选择后实际读取字体、内容摘要和元数据，并检查102个样例字符。详情展示名称、原始字重/字形数量及样例缺字统计；示例通过不等于全书或全字库覆盖。字体文件名、品牌和原始数据按原文保留，标题/按钮/提示中文。

“预览原文”使用当前原文锚点显示完整字体组，不保存；点击正文或PC返回设置键回详情，再“应用本书”或取消。应用调用[字体事务](FONT_SWITCHING.md)，实际显示后才保存逐书选择，跨重开恢复。保存失败保留选择与会话，重试/取消走既有屏障。

列表“正文/备用”切换修改目标；“内置”用于正文时仅选择内置界面子集，详情提示覆盖有限；用于备用时移除额外备用文件，仍保留常驻末级回退。未取得当前完整选择时不能乱改默认或丢另一项。没有外部字体启动时目录默认/sdcard/fonts（PC为当前目录/sim-fonts）；已有字体时使用其所在目录。当前没有多目录浏览/搜索。

菜单进入前，排版草稿字段保留。已有未应用排版预览会先恢复实际原配置，选择字体后回排版表单仍可继续修改；失败的排版应用请求未完成时字体入口提示先应用或取消，不擅自丢请求。字体和排版草稿不会混写。

## PC与触屏

PC排版页按F进入字体，或点击右上字体按钮。列表上下选择、Enter检查、PgUp/PgDown分页、1/2切正文/备用、I选择内置；详情P预览、Enter应用，Esc返回列表；列表Esc取消回排版页。预览Enter/Esc/F返回详情。点击与键盘共用同源状态机，只有有效按下/抬起配对触发；失焦/切键盘取消指针。

未成功呈现的菜单禁止应用，重试仅重读/重画不执行保存。所有大页面模型走pn_pool，不在32KiB设备栈或预算之外calloc。离书/锁屏释放UI，字体待提交请求仍由app保存屏障负责。

## 全局默认与逐书继承

详情页“设为全局默认”保存当前正文/备用组合到fonts.a/b，保留所有逐书覆盖和当前已接受字体。之后打开未覆盖或明确继承的书时使用新默认；当前草稿仍需“应用本书”或取消。该按钮是立即保存操作，取消字体草稿不撤销已保存的全局默认。PC详情按G执行。

菜单顶部“继承默认”（PC按H）读取已有全局配置，在本书原文锚点校验、实际重绘成功后保存逐书inherit标记，而非复制全局引用。本书之后重开会跟随更新的全局默认。未设置全局返回提示；损坏/未知配置或缺失、替换过的字体不猜测回退，也不改逐书记录。取消失败的继承应用恢复原逐书记录和已接受字体。

字体保存故障会保留原请求，允许同请求重试，关闭时仍按原请求处理；另一个全局或逐书提交会返回BUSY。全局写入失败但尚未排除提交可能时，不能把菜单取消当成撤回全局操作。实际字体与持久继承标记分开，后续预览不会改变待提交意图。菜单未成功呈现仍禁止这些保存操作。
