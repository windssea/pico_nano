## 阅读顺序与事实等级

开发者先读仓库 [AGENTS.md](../AGENTS.md)、构建文档、硬件规格和架构，再依据开发指南选择工作包。用户刷机直接读安装文档。当前未完操作及本机证据位置留在被忽略的 `docs/HANDOFF.local.md`；它不是公开文档或唯一功能依据。

文档明确区分四个等级：**源码实现 → 主机/模拟器验证 → 固件构建 → 真机产品验收**。通过前一级不自动通过后一级。最新架构标明已发布与工作区内容；本批0.6.6，网页默认来源以在线发布清单为准。

2026-10-14 归档保留 86 份原始文档：85 份项目专题和原仓库 README。浏览副本的相对链接已重新定位；[原始 ZIP](archive/2026-10-14/originals.zip)保留完整原字节，[清单](archive/2026-10-14/manifest.json)提供摘要。旧文档中“尚未上板”“仍需配对码”“目标模块”等历史描述不得覆盖现行结论。

## 以后如何维护

硬件数值与资源限制只在硬件文档维护；已落地行为、数据格式、错误边界和源码入口写架构；未实现需求、风险和方案写开发指南。目录契约与开发/刷机操作保持独立，避免将安全规则埋入历史。每次变化只在 CHANGELOG 记短条目。

新增功能优先补充现行文档相应章节。只有确实需要独立长期规范时才新增文件并在本页登记。原始分析、构建输出、测量数据、截图、参考源码快照和临时审查放在被忽略的 `build-dev/` 或 `docs/local/`；许可证/vendor 文档及既有发布包保持原位。默认不启动子 agent，不把本机私人样本纳入公开归档。
