# EPUB语义书签

0.0.31提供独立持久书签管理和实际阅读会话API；0.0.32接入共享中文管理界面与PC/设备入口；真实设备体验尚待验证。TXT复用同一界面。

## 行为

每书最多100条有效书签，以原文件内容SHA区分。位置是资源路径及locator-v1的元素、文本段、原始字符偏移，使用既有PNEP验证规则，不能保存临时事件顺序或永久页码。相同位置重复添加返回原编号，不修改名称。名称最多48字节合法UTF-8，拒绝控制字符；编号升序有界分页，可由调用方使用六条容量。

root由内部存储owner提供并已存在；init只绑定，首次添加才创建独立SHA.emarks目录。每条16位小写十六进制编号.a/.b，删除仅写墓碑，保持已观察编号且不复用。达到UINT64_MAX后禁止绕回。READ租约只可读，失效媒体拒绝继续，PC拒绝书签目录和叶文件符号链接，设备FAT/LittleFS使用stat。

列表从文件重建，没有中央索引。坏/未知记录或身份错误中止，不猜测，不擦除，不覆盖；错误count=0/more=false，其他输出不可使用。仅双槽不存在为EMPTY；可恢复另一有效槽。未删墓碑会积累，目录扫描成本随全部记录增长；尚无整理、分片或deadline保障。owner串行调用，不允许其他消费者并行修改目录。

## 持久格式

PNEM schema1载荷：magic[0..3]、version16[4]、deleted16[6]、id64[8]、SHA32[16]、locator-version16[48]、kind8[50]、reserved8[51]、element64[52]、offset64[60]、run32[68]、path-length16[72]、label-length16[74]、reserved32[76]，随后是原UTF-8路径与名称，不含NUL。整数小端，最大1151字节。未知版本/标志/locator/reserved拒绝，路径/长度/标签损坏拒绝。外层使用既有PNBL双槽CRC、同步读回及序号机制；不修改PNJR或TXT书签格式。

写失败可能已提交；调用方保留请求并重试，重复添加按实际位置去重、改名覆盖同项、删除幂等。没有产品修复引导时不得自动清坏记录。

## 阅读会话

pn_epub_app_bookmark_add只添加最后实际显示确认的位置，未呈现返回EMPTY。list/rename/delete不移动位置；无state-dir不持久化并返回UNSUPPORTED。拔卡后所有书签操作返回STALE_MEDIA。

jump读取有效书签并通过既有EPUB实际正文/图片/显示owner确认链路；只有last_confirmed时建立跳转前返回点。失败显示保持原位置；显示后保存错误仍以真实画面为准。return成功确认后清返回点，失败保留供重试。该返回点只属于当前会话，不作为持久历史保存。删除书签不删除已建立的临时返回点。

## 验证与边界

python tools/dev.py host：真实文件覆盖100项上限、语义位置去重、墓碑编号、中文改名/非法标签、六项分页、跨对象恢复、缺失A槽、损坏最新槽回退、坏记录阻止写、最长路径/名称、最大ID墓碑、符号链接及READ/失效租约；实际EPUB/字体/显示回调覆盖未呈现拒绝添加、失败跳转/返回、成功恢复原锚点、关闭重开列表与拔卡。此层验证不是真机断电、整机资源或纸屏体验验收。

## 中文界面与输入

正文顶部“书签”打开六条列表，支持添加、前后页、修改名称和删除确认。EPUB列表显示“原文位置”及编号，避免伪造按字节或章节计算的阅读百分比。菜单只保留ID与名称，不把EPUB锚点转换成TXT偏移；跳转时从EPUB记录重新读取真实位置。按“返回阅读”回正文，成功书签跳转后顶部出现“返回”，返回成功后该入口消失。

PC独立窗口与书架窗口：M打开书签，A添加，方向键选择，Enter打开操作，J跳转，R改名，Delete进入删除确认，Esc取消/返回，U返回跳转前位置。名称编辑支持系统中文输入；设备沿用既有字符键盘并保存UTF-8名称，尚无中文输入法。按钮、状态和删除确认使用中文。设备主循环按活动菜单优先解释命中，避免编辑退格/大小写误开排版/目录。PC抬起事件必须有对应按下，滑出/失焦/键盘切换取消未完成指针操作。

同源控制器保留未呈现确认页禁止删除、保存失败保留草稿/会话的门禁。菜单不提交原文进度；回正文按真实显示确认。界面GL16/GC16规则沿用[书签界面](BOOKMARK_UI.md)，没有DU滚动或异步目录扫描保证。

python tools/dev.py sdl的bookmark_window新增真实EPUB独立及混合窗口事件旅程，覆盖触屏入口、无按下抬起不添加、中文改名、跳转/触屏返回、删除取消/确认及跨进程恢复。host actual EPUB额外覆盖失败删除确认BUSY、重试、取消、跳转原锚点及返回。设备SDK检查现在实际链接对应书签代码，仍不等于烧写、断电或纸屏体验验收。

本机真实样本菜单捕获可在epub_app_capture中设PN_EPUB_BOOKMARK_MENU=1并提供独立state目录；该显式测试会向该目录添加样本书签。输出和状态留在忽略的build目录，不能改用户EPUB/字体。完整第一版字体、传输、壁纸、其他格式、性能及硬件验收继续。
