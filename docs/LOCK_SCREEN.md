# 锁屏与壁纸缓存

0.0.50建立锁屏壁纸内核：原图预处理、内部A/B记录和三种锁屏绘制，并把设备电源键锁页改为读取内部记录；0.0.51加入同源设置页。产品目标与完整流程见 [字体与壁纸](FONTS_AND_WALLPAPERS.md)；本页只描述已实现部分。“当前书封面”模式（见下）已接入；EXIF方向尚未实现，浅睡见 [锁屏浅睡](POWER.md)；壁纸分区需先单独写入空镜像（见 [设备接入](DEVICE_PORT.md)），否则设置页可预览但无法应用。全部只在主机验证，没有面板观感、写入耗时或掉电实测。

## 预处理

pn_wallpaper_prepare读取TF上的JPEG/PNG（按内容签名识别），生成684×1216、4bpp整屏位图：

- 完整显示（contain）：等比放入屏幕，白色留边；铺满裁切（cover）：等比覆盖屏幕，溢出方向按shift −4..4裁切，0居中，−4贴左/上，+4贴右/下。
- 旋转为顺时针0/90/180/270°，先确定旋转后的几何，再映射回未旋转窗口解码，最后逐像素旋转采样。
- 透明PNG合成到白底。原图足够大且临时帧不超过2MiB时2倍超采样再均值，否则最近邻。暂无EXIF方向读取、对比度增强档或有序抖动。
- 铺满后单边超过4096像素（极端长宽比）返回LIMIT。
- 全部临时分配走调用方给定预算的子池，并计入父pool；任何非OK都不改输出帧。主机测试对每个分配点注入失败。

## 内部A/B记录

记录写在独立wallpaper分区（设备挂载 `/wallpaper`，文件 `lock.a`/`lock.b`）。每条记录同时包含模式与位图，所以“选择”和“图像”一次提交，不存在只改选择不改图的中间态。小端格式：

| 字段 | 字节 |
| --- | --- |
| 魔数 `PNWP`、版本1 | 4+2 |
| 模式（默认/自定义/简洁）、适配、旋转、shift、提示带、保留0 | 各1 |
| 序号（1起，单调） | 8 |
| 原图大小、mtime | 8+8 |
| 原图路径长度与UTF8路径 | 2+N |
| 位图（仅自定义，逐行342字节×1216） | 415872 |
| 以上全部的CRC32 | 4 |

load先读两槽头部，按序号从高到低完整校验，返回首个有效记录；自定义记录直接流式读入调用方整屏帧，不额外分配全屏缓冲。较新槽截断或CRC错误时回退旧槽；两槽皆坏返回CORRUPT，设备随即用系统默认锁屏。save需要WRITE租约，写到不含当前有效记录的那一槽，序号为最高有效代加一（两槽皆坏时也高于任何可读头部），fflush/fsync后读回校验；失败可能已提交，调用方应重新load。恢复默认就是保存一条更高序号、无位图的默认记录。原图删除或拔卡不影响已保存的位图。

## 锁屏绘制

pn_lock_render纯绘制，使用常驻UI字体，结束时恢复其字号：

- 系统默认：白底黑线纸页叠影与书脊、“小纸 Pico / Read Pico”和底部提示，纯黑白利于GC16。
- 简洁：白底产品名、细线与提示。
- 自定义：保留位图，提示带开启时在底部112像素铺白、加分隔线和提示，避免黑字落在照片上。

设备电源键锁页和传输停止后的锁页调用show_lock：非破坏挂载wallpaper分区（format_if_mount_failed=false），READ读取记录，失败、空分区或未挂载都使用系统默认，最后才退回文字页。锁页显示后进入浅睡（见 [锁屏浅睡](POWER.md)）；时钟、电量等静态叠加未实现。

## 当前书封面

设置页列表第三个按钮“当前书封面”写入一条模式为BOOK的记录，不含位图和原图路径，只保存模式与提示带开关。锁屏时设备若正有一本书打开（TXT/EPUB），用封面提取（EPUB OPF声明或cover文件名候选、TXT同名侧车）contain缩放到整屏，底部再叠提示带；没有打开的书（已回书架）、格式不支持、无封面、封面损坏或内存不足时，回退系统默认锁屏，并记录一条警告日志。设置页的预览只显示系统默认图占位，不解码封面。封面解码使用pool余量减512KiB；大型渐进式JPEG封面的内存与耗时尚未在真机测过。

## 设置页

入口：阅读中点品牌区或按KEY2打开菜单（书架点左上“小纸 Pico”亦可），选“设置”→“锁屏壁纸”。进入前与热点传书一样先保存并关闭正文以释放内存，退出后回原书（无书时回书架）。PC书库窗口给出 `--wallpaper-dir` 后按W进入，`--wallpaper-store DIR` 模拟内部分区；不给记录目录时可预览但应用返回UNSUPPORTED。

列表页显示当前锁屏（系统默认/简洁/自定义原图名；记录损坏显示不可用），“系统默认”“简洁锁屏”两键，以及 `/sdcard/wallpapers` 中JPG/JPEG/PNG六项分页（按扩展名列出，内容由解码器确认）。选择任一项进入预览页：上部为实际锁屏效果的半尺寸2×2均值预览，下部为完整显示/铺满裁切、旋转90°、铺满时的裁切位置−/+、底部提示开关，以及取消/应用。只有参数或原图变化才重新预处理；提示开关只重绘。重新选择当前已保存的原图时继承其参数。

预览不改当前锁屏。应用在内部分区取WRITE租约保存，随后以读回结果为准（保存失败也可能已提交）；租约被占或写失败停留预览并显示“应用失败，保留原锁屏”，不修改已知选择。伪图片、内存不足或读取失败停在列表并说明原因。页面持有约两个整屏帧加四分之一预览帧，预处理使用pool余量减256KiB。卡移除、锁屏和其他提示页都会关闭设置页。

## 验证

`python tools/dev.py host`的wallpaper测试：四象限图contain/四个旋转、cover居中与两端shift、透明铺白、大图超采样、坏PNG为CORRUPT与纯文本为UNSUPPORTED、全部分配点失败与小预算不改输出；A/B首存、交替、模式与参数往返、新槽截断回退、坏槽被下次保存覆盖、像素位翻转被CRC拒绝、双坏CORRUPT后可重新保存、READ租约不能保存、介质失效；三种锁屏绘制与字号恢复。wallpaper_ui以真实目录驱动列表/伪图片/预览/铺满/裁切边界/旋转/提示/应用并独立读回、取消、WRITE占用失败、无分区UNSUPPORTED、缺目录、呈现失败与打开时逐分配点失败；SDL wallpaper_window覆盖窗口打开、点击、Enter应用、Esc取消/返回、无记录目录与选项校验。设备装配只由两套ESP-IDF构建编译链接。
