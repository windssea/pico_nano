# Pico Mono Glass V2 落地对照

依据：《Pico Mono Glass V2.0 墨水屏阅读器完整 UI/UX 设计规范》（2026.10，原件不入库）。规范把分辨率、按键事件等列为“待确认”；本机已知为 4.7 英寸 E0470A01、物理 1216×684、逻辑竖屏 684×1216、约 297 ppi、16 级灰阶，设计画板 360×640 与本机同为 9:16，按 1u ≈ 1.9 px 换算。界面行为以 [界面与交互](UI_UX.md) 为准，本页只记录对照、产品决定与未落地项。主机与模拟器截图不代表墨水屏观感，均待样机复核。

## 产品决定（覆盖规范的对应条目）

| 规范 | 决定 |
| --- | --- |
| 左/右翻页键＋Home＋锁屏开关 | 本机为屏下三触摸键＋电源键，**维持现有键位语义**（KEY2 阅读中开工具栏、长按回书架；列表页 KEY1/KEY3 移动焦点、KEY2 确认）；“按键与手势”页按实际机身画 |
| 书架纵向滚动 | **书架分页**（C12 分页栏），KEY1/KEY3 与滑动翻书架页 |
| 快捷菜单灰阶遮罩 | **不加遮罩**，底部面板不透明 |
| “书库 / 书架”命名 | 统一叫“**书架**” |
| 状态栏时间 | 显示**开机时读到的时间**（PMU RTC 已对时才显示，按开机计时推算，UTC+8）；**锁屏不显示时间** |
| 书内搜索 | 简化：工具栏原“搜索”位改为**按百分比跳转**；书库搜索保持书名（拼音首字母/英文） |

## 已落地

| 规范条目 | 实现 |
| --- | --- |
| 4.2 灰阶令牌、4.5 圆角与线条 | G05/G11/G13/G14 令牌；控件 16、卡片 22、分段 28 px；最小命中 88 px（约 7.5 mm） |
| 4.4 字阶 | 标题加粗（控件层错位重绘）、次要文字 G05 墨色 |
| Mono Glass 拟玻璃 | 静态雾面＋细描边＋下沿一级灰影，无模糊 |
| C01 状态栏 | PicoNano、时间（已知时）、无线（连接时）、电量 |
| C02 底部导航 | 书架/传书/设置三个一级页固定；当前项浅灰底座＋加粗标签 |
| C04 继续阅读卡 | “正在阅读”、书名、已读进度条、深色“继续阅读 →” |
| C05/C06 封面网格 | 3 列 176×244；无封面时按书名生成抽象几何占位封面；末页虚线“导入图书” |
| C06 分类 | 全部 / 最近 / 收藏，深色胶囊为当前 |
| C07 列表行 | 列表模式每页 5 本，整行可点 |
| C08/C09/C10 | 主次按钮、开关（开深色轨道/关浅灰轨道）、步进（长按 600 ms 后 180 ms 连发） |
| C11 快捷抽屉 | 3×2 拟玻璃卡片“目录/书签/跳转/排版/刷新/书架”，抓手，无遮罩 |
| C12 分页栏 | ‹ n / m ›，首末页箭头置灰 |
| B02 书籍操作 | 长按封面：打开、收藏/取消收藏、信息与路径、删除文件（整页确认，保留阅读记录与书签） |
| B03 书库搜索 | 浅灰搜索框、清除图标、屏幕键盘；结果用列表 |
| T01 传书 | 一级页按能力列出热点/局域网/USB，不可用只写原因；存储与格式说明 |
| R01 阅读页脚 | 进度轨＋“第 N/M 节”＋百分比；EPUB 进度按章节估算并写入最近阅读 |
| R02 快捷菜单 | 见 C11 |
| R03 目录 | 当前章节浅灰底＋黑色侧条 |
| R04 书签 | 深色添加按钮、卡片行；同一位置不重复，提示“当前位置已添加” |
| R06 排版 | 预览、排版模式分段（自定义标记）、字体行、四个步进、页边距窄/中/宽、首行缩进开关、底部固定“应用” |
| S01 设置 | 一级页分组卡片，去除内部调试文案 |
| S02 字体管理 | 默认字体卡、每行“Aa”实际字体样本 |
| S05 按键与手势 | 机身示意、键位说明、四个翻页开关 |
| S06 刷新与屏幕 | 清晰/均衡/省电自动清残影策略、立即整屏刷新；设备 GL16 小范围局部刷新 |
| S07 存储与关于 | 版本、屏幕、存储卡容量/可用、内部存储，只显示实际读到的值 |
| 跳转 | 新增：按百分比跳转（TXT 字节比例、EPUB 章节起点），可返回跳转前位置 |

## 未落地

- 书内全文搜索（R05）与中文输入法；书库搜索的作者/格式筛选、最近搜索。
- 书库索引：作者、添加时间与“最近打开”排序，分类“作者”；书籍“从书架移除”（只删记录不删文件）。
- 阅读页可选顶部短标题、章内页码。
- 传书任务记录（T02）、同名文件冲突处理、USB 传输。
- 锁屏壁纸缩略图网格与默认现代抽象壁纸素材；锁屏预览时间。
- 真机：灰阶 LUT、残影、局部刷新区域、触控热区与按键手感、功耗，均未在样机上验证（规范第 8、12 章）。
