# 验证、性能与发布门槛

**产品性能指标均为待测目标。** 0.0.4已建立共享核心/模拟器、内容记录、自动保存与TXT书签测试及两配置编译，尚未上板；当前状态与操作见 [构建与运行](BUILDING.md)。测试不能只验证函数返回成功，必须核对内容、内存、可见画面与失败恢复。

测试分四层：共享真实源的主机核心测试、桌面UI模拟器、可选芯片仿真、真机。操作入口、环境及覆盖边界见 [开发与PC模拟测试](DEVELOPMENT_AND_TESTING.md)。PC截图用于像素/布局一致性；波形、残影、带宽、电流及WiFi/USB硬件以真机为准。

## 1. 测试环境记录

每次真机记录板型/硬件版本、固件SHA、IDF v6.1、MSPI/pclk档、TF型号与写测速、字体摘要与字号、温度、供电与电量、WiFi RSSI及连接方式。私有MAC/PMU UID/密码不进入公开报告。

标准条件：室温23±2°C、正常电池/USB分别测、竖屏、44px/1.45em/32px边距、清晰均衡、同一许可完整中文TTF、可用TF卡。显示对比固定曝光、距离、照明，至少120fps摄影看视觉延迟；软件计时`display_end`并不保证已经测到所有光学稳定。

## 2. 语料集

| 类型 | 最低数量 | 覆盖 |
| --- | ---: | --- |
| TXT | 30 | UTF8/UTF16/GBK、长段、诗歌、无章节、20MiB小说、错误编码 |
| EPUB | 50 | EPUB2/3、nav/NCX、中文日文英文、脚注、长章、插图、基础CSS、封面变体 |
| PDF | 40 | 文字15、扫描10、混合10、复杂边界5；CJK/CID/xref/透明/CropBox |
| FB2 | 15 | 层级、诗歌、引用、base64、压缩版、深XML |
| CBZ | 15 | 自然排序、JPG/PNG、大图、横图、ComicInfo、隐藏项 |
| 字体 | 12 | 静态/variable/复合/缺字/错误表/超复杂glyph |
| 壁纸 | 12 | 横竖图、JPEG EXIF、透明PNG、全黑/白、超像素、损坏与极端比例 |
| 损坏样本 | 每格式至少20 | 越界、截断、重复、压缩炸弹、非法path、超限、加密 |

自生成fixture优先，授权样本标明来源和许可；PDF 90%技术门只针对40本标准语料，不把故意损坏样本算成功率分母。全部损坏样本要求有界失败、无泄漏/崩溃。

## 3. 性能定义与目标

每条件至少30次，报告p50/p95/最大、失败数，不丢弃慢样本。热状态明确缓存命中；冷状态清理相应可再生cache并关闭session。构建/字库不同时不混合统计。

| 指标 | 定义 | 初始目标 |
| --- | --- | --- |
| 输入采集 | 事件发生到路由接收，软件instrument＋摄影 | p95≤30ms，非长I2C故障状态 |
| 控件可见反馈 | 按下到局部显示job完成 | p95≤180ms，扫描忙时标明排队 |
| 热文本准备 | intent提交→display enqueue | p95≤80ms |
| 热GL16翻页 | intent提交→display end | p95≤650ms |
| 快速二值翻页 | intent提交→display end | p95≤350ms；M0波形不能达成时修订有实测依据 |
| 热书恢复 | 点击→正文首屏完成 | p95≤1.5s |
| 常规冷EPUB首屏 | 文件<=20MiB、首章<=1MiB解压、标准字体 | p95≤3s，取消软件响应≤100ms |
| 常规冷TXT首屏 | ≤20MiB，不等全章索引 | p95≤2s |
| 常规PDF首屏 | 基准文字/扫描/混合，非复杂边界 | p95≤4s，单页p95≤2s |
| 设置样例更新 | 最后一档输入→等待250ms→样例出屏 | 总p95≤900ms；合并不多次全刷 |
| 千本书库首页 | 库已索引、封面cold，点击书架→文字卡可见 | p95≤1.5s，不等全部封面 |
| AP/STA有效上传 | 首块→最后持久ACK，5×32MiB | 中位≥0.5/0.8MiB/s；校验/入库另计 |
| UI取消 | 提交cancel→worker停止新的计算与释放中间结果 | 通常≤100ms；显示相位安全结束另计 |

M0发现物理/介质能力无法达到目标时，记录原因并更新目标与方案，不把deadline内返回但没出屏算成功。多图/跨章/长章末页另立冷任务组，不与热页指标混比。

## 4. 内存与资源

- 文本/PDF总PSRAM峰值分别满足ARCHITECTURE预算，保留至少1MiB余量目标；核对实际epdiy缓冲与所有栈，不能漏算隐藏分配。
- 内部SRAM空闲≥64KiB、最大连续块≥32KiB目标；M0 baseline不足则重新分配并公开实际值。
- 打开/关闭书500次、切字体100次、切PDF视口200次、传书启停100次后回到稳定资源基线；缓存常驻部分与泄漏分开统计。
- ASan/UBSan主机全通过；target budget allocator做每个分配点失败注入，释放顺序不double free。
- fuzz parser/font/ZIP/name/manifest至少每模块24小时持续运行（可复用累计预算），任何崩溃加入固定回归。
- RTOS stack high-water余量至少25%，WiFi/epdiy任务不得因应用栈挤压欠载。

## 5. 正确性与UI

文本：相邻页串联恢复原规范化内容，不丢字/重字；中文禁则与标题/引用/列表对照golden布局；可见像素/行盒可差异比较。位置：换字体、字号、段距、段落模式、旋转后回到同一或最接近可定位原文；不得跳章首。

封面：EPUB优先级正确、TXT同名侧车、PDF首图、CBZ自然排序；有坏封面不阻塞入库。书库：千本不卡、选中条目不随后台封面变化位移、UTF8长标题不越界；大字号UI减少行数而非裁字。

交互：每个动作最多一次、滑出取消、工具栏防穿透、左右手、KEY2长按、刷屏期间反向取消、锁屏与返回来源一致。PDF视区前后是逆操作，横屏点击映射正确；不会出现文本字号控件。

刷新：100次文字翻页、黑白反转、灰阶梯子、封面切正文、二维码、侧栏/页脚边界；观察残影与强刷间隔。photo golden必须真机，不用浏览器截图代替面板灰阶。

字体上传：32MiB边界、非TrueType轮廓、错误字体、缺卡、空间不足、同名新内容、使用中字库覆盖/删除、上传后设备预览与逐书/全局选择；失败保留旧字库，UI不缺字失效。字体和壁纸分块续传在T11加入后单独验收，0.1流上传不冒充持久续传。

壁纸：contain/cover/旋转/裁切、透明铺白、方向元数据、黑背景文字安全带、模式切换/取消/恢复默认；A/B写入每阶段断电、双槽损坏回默认、拔卡后已有壁纸锁屏、原图删除缓存保留提示、横屏阅读锁页与唤醒方向恢复。应用失败保留旧选择；壁纸缓存不得占用原书/位置分区，睡眠不因时钟展示定时唤醒。

## 6. 可靠性故障矩阵

| 故障 | 注入位置 | 必须成立 |
| --- | --- | --- |
| 断网/网页刷新/手机熄屏 | 每个分块/最终complete | 已ACK块可恢复；旧书未损坏；重新配对可续 |
| 掉电 | part同步、manifest、旧backup、新安装、索引、清backup | 原旧书或校验新书至少一份有效；phase可判定 |
| TF拔出 | 读正文/字体/PDF/写块/入库 | epoch失效、后台停止、UI仍可读、内部位置保存 |
| 换同名同大小文件/换卡 | 外部copy、USB退出 | 内容id重新算，不能误用旧进度 |
| 缓存损坏 | 封面、layout、目录index | 重建cache，保留原书与位置 |
| 日志损坏/满空间 | A/B记录、索引commit | 选择有效代、失败明确，不能清空全库 |
| 显示欠载 | 软件故障/带宽压力 | 降档恢复目标页，连续失败可保护退出 |
| 升级断电/首启失败 | OTA每阶段 | 至少一个可启动槽，设置兼容或回退 |
| USB异常退出 | copy中拔线、主机未弹出 | 不并发挂载，提示检查，不自动格式化 |
| 电源请求遇写入 | lock/off/upload/update | 保存与停止屏障优先，deadline失败取消切电 |

文件事务故障点主机穷举；真实硬件每关键phase至少10次断电/拔卡，专项测试卡进行，不对唯一用户原书做实验。

## 7. 长时与耗电

至少两块同型号板、三张不同TF卡。8小时自动阅读（正常节奏）、8小时PDF/图文混合、24小时锁屏/浅睡、连续1000次翻页；环境冷热边界以硬件可支持范围先确认，温度试验记录不能自行设超规格。

电流分别测阅读翻页、空闲轨关闭、浅睡、PMU软睡、AP/STA传书。电池续航按实测usable capacity与场景占比估算，公开测试条件，不提前承诺“数周”。电量低于15%提示，低于5%停止新OTA/大导入并保存，门槛按电压/PMU SOC实测校准，USB充电中另判断。

## 8. 发布门

1. 主机真实源测试、网页真实脚本测试、CI/defaults两个配置编译通过；产品默认仍是已验证板型时序，CI不能代替产品配置。
2. 用户明确PDF目标通过；已公布格式各有样本，未支持特性明确可诊断。
3. 性能、内存、显示残影、取消、断点、保存与升级门通过；没有P0崩溃/数据丢失。
4. LICENSES、引擎/字体来源、公开源码/对象文件等适用发行材料齐备，PDF许可决策完成。
5. 首次使用、TF部署、扫码传书、转换范围、刷机恢复与升级指南可由新人执行。
6. 发布manifest包含板型、版本、IDF、SHA-256、分区与签名；完整flash镜像与app更新包区别明确。

不足两板、多卡、温度或回滚证据时保留Beta标记。未烧写/仅编译/真机验证三种状态分别陈述，不把静态文档或UI示意当作产品验收。
