# PicoNano 1.0 产品与验收计划

2026-10-12界面方向补充：默认阅读首页与独立书库分工，四栏统一导航为首页/书库/传书/设置；书库保留3列、4列和列表，展示EPUB作品名、作者和真实封面。缺失元数据有明确回退，统计只来自实际记录。行为、资源边界和实施出口见[阅读首页与独立书库](READING_HOME.md)。

更新：2026-10-12。源码分析基线：`cf99c18`，0.0.57及其后未发布改动。本文件规定尚待完成的1.0目标，不是功能已交付声明。实施顺序、工作包和原任务映射见 [1.0开发执行计划](V1_DEVELOPMENT_PLAN.md)；当前实现状态仍见 [PROJECT_STATUS](PROJECT_STATUS.md)。

## 1. 产品目标与范围

1.0交付一台安静、清晰、响应可预期的离线阅读器：导入方便，文字利用原生像素清晰呈现，阅读位置可靠，锁屏有个人风格。中文名“PicoNano”，英文/日文名“Read Pico”；`pico_nano`仅为工程代号。

硬件基线：RDP-G01-W、ESP32-S3、16MiB flash、8MiB PSRAM、684×1216逻辑竖屏、16级灰阶。按4.7英寸推算约297ppi，本文“约300ppi”指这一分辨率级别，不是面板有效尺寸的实测结论。高像素密度必须体现在字体细节、基线、标点和图像采样质量上。

| 范围 | 1.0决定 | 完成条件 |
| --- | --- | --- |
| TXT、重排EPUB | 必须 | 编码、目录、图片、排版、续读与兼容语料通过 |
| 原生PDF | 必须，保留既定要求 | 先过许可/引擎/资源技术门，再过视口、导航和恢复门 |

| 热点、局域网网页传输 | 必须 | Android/iOS真实传书、字体、封面、壁纸全流程 |
| LocalSend接收 | 必须，保留已提出要求 | 官方桌面/Android/iOS与设备发现、HTTPS、确认、取消闭环 |

| 睡眠、关机、恢复、升级回滚 | 必须 | 保存屏障、PMU电源路径、签名升级与失败回滚 |

| 游戏、动画桌面、AI常驻、完整浏览器 | 不纳入 | 保持离线阅读与资源预算优先 |

原生PDF技术门若未通过，继续提供文本开发版，但不能静默删掉PDF后称本计划的1.0已完成。格式限制沿 [FORMATS](FORMATS.md) 明示，固定布局EPUB、DRM、复杂塑形等不能被扩展名“支持”掩盖。

## 3. 传书与资源管理

### 3.1 用户旅程

- 一级“传书”提供附近传书、热点传书、局域网传书；USB仅在能力通过时显示为可用。
- 热点提供“连接设备”和“打开传书网页”两码，口令仅本次会话有效；局域网显示真实连接状态与网页入口。
- 首次无书引导一次导入；手机网页显示设备、剩余空间、支持格式和资源类别，所有提示使用产品语言。
- 网页书籍、字体、封面、锁屏图片明确分区。图片用途必须由用户选择，不能根据文件名猜用途。
- 单个活动传输模式；进入时保存并关闭阅读源/正文预绘制，退出时等请求、写入与安装恢复收口，再返回原书位置或原书架页。
- 队列每项显示“准备摘要/等待确认/接收/校验/安装/已保存/失败/已取消”。持久ACK表示块保存，安装提交后才能表示资源已保存。
- 同名支持明确确认覆盖或另存名称；覆盖核对旧内容身份。批量处理逐项报告结果，不因一项失败清空成功项。

### 3.2 可靠性与网络

- 网页续传覆盖断网、标签刷新、服务重启、手机熄屏与新建成功回复丢失；通过类别、名称、长度、完整摘要找回会话，重新配对后恢复。
- LocalSend整文件中断重发，与网页持久分块续传分别说明；默认等待设备确认，图片逐项确认用途，同名初期拒绝覆盖。
- 增加未完成上传列表、继续/取消与安全回收；未确认安装恢复结束前不得删除part、backup或journal。清理只针对确认无活动owner的事务。
- 家庭网络扫描、保存/忘记与切换形成完整流程；保存网络数使用有界小表，具体上限在接口实现前固定并显示。口令不回显、不进入日志。
- 设备HTTPS证书、随机令牌、发现与握手预算实测；不为实现第三方通道关闭既有证书校验。
- 所有上传复用`pn_upload_directory`、`pn_sd_layout.h`和共享安装事务，遵守 [SD_CARD_LAYOUT](SD_CARD_LAYOUT.md)。客户端不能指定目标目录。
- 保留当前资源上限基线：字体32MiB、壁纸/封面图片8MiB、网络块64KiB。书籍上传上限与各解析器实际可读上限对齐并按格式公布，不以现有统一512MiB上传额度保证所有书都可读。

### 3.3 字体、壁纸、封面网页管理

字体网页完成列表、真实信息、中文/拉丁样例、上传/删除/覆盖确认和刷新结果。壁纸网页完成分页列表、尺寸/大小/缩略图、上传/删除/覆盖与当前缓存状态。封面网页可选目标书再上传或恢复内嵌封面；关联必须绑定书目身份，保留旧同名侧车兼容，不让同名不同格式书误换封面。

上传不会自动应用字体或锁屏。网页预览不是面板照片；设备负责最终验证和应用。删除已应用壁纸原图时明确“当前锁屏缓存保留”；用户要移除显示内容时提供独立“恢复默认并移除自定义缓存”流程。

## 4. 字体与约300ppi清晰度

### 4.1 字体产品行为

- 固定常驻UI字体与默认阅读字体分别维护；正文默认使用内置Noto Sans SC阅读子集，外置完整TTF可替代，缺字有系统回退和一次性可理解提示。
- 全局默认与逐书覆盖清楚分开：设默认不覆盖已明确选择字体的书；恢复本书默认是显式操作。
- 列表采用实际字体的中文短句和“Aa”样例，缓存样例，避免每次绘制反复打开全部字体。详情显示家族、样式、字重、支持范围与样例缺字结果。
- 主流静态TTF必须通过；变化轴只按实际`fvar`范围显示，受测wght可选。OTF/CFF、TTC、WOFF等不支持类型在上传时明确拒绝或说明。
- 覆盖/删除使用中字体先暂停并关闭源，核对摘要并确认影响；失败保留旧文件/选择。缺失回退不修改进度与原选择记录。

### 4.2 清晰度工程

| 项目 | 要求 | 真机比较 |
| --- | --- | --- |
| 原生栅格 | 正文、UI文字和图标按684×1216目标像素生成，不缩放低清整页 | 细横竖笔画、标点、英文、数字 |
| 基线/间距 | 使用真实字体度量与受控小数累计，避免逐字取整漂移 | 同行混排、长行、字间距、段首 |
| 灰阶覆盖率 | 保留4bpp抗锯齿；覆盖曲线按字体/字号/刷新模式验证 | 候选0.6/0.8/1.0、黑白与16级灰阶 |
| 字重 | 优先真实静态字重/可变轴；另设受限“笔画增强”并明确含义 | 小字内部白腔、横竖均匀、黑度与粘连 |
| 刷新 | 清晰/均衡/省电策略以清晰度和残影测量选择；DU通过后才可用 | 100次翻页、反色、菜单边缘、封面转正文 |
| 图像 | 高质量有界缩小，4bpp灰阶；照片抖动与文字抗锯齿分离 | PNG线稿、照片渐变、封面小字 |
| 温度 | 使用受测温度来源与已有厂商波形，固定25°C工程值不能作为最终温补 | 标准室温及硬件允许的冷热边界 |

字号覆盖28/36/44/56/72px；中英及中文复杂笔画、稀有字、成对省略号/破折号、引号与数字单位单独比较。不靠统一加粗掩盖渲染问题，不手改厂商波形或vendor字体引擎。

默认正文采用清晰均衡灰阶。快速二值模式只是通过真机门后的可选项，不牺牲默认笔画完整性；不可用时不展示假开关。反色需完整转换与残影验证，不能提前宣称更护眼。

## 5. PNG壁纸、书封锁屏与电源

### 5.1 必须交付的模式

1. 系统默认：有许可的原生黑白现代图案，首次开机使用。
2. 简洁：产品名与可隐藏的唤醒提示。
3. 自定义：PNG/JPEG原图、真实预览、应用/取消/恢复默认。
4. 当前/最近在读书封：采用有效在读书身份和封面，退出阅读/重启后仍能使用最近有效缓存。

锁屏不显示时间，不为了统计、日期或壁纸定期唤醒。封面/书名/进度与用户摘句属于主动启用的隐私选项，提示文字有白底安全带，可隐藏；关机画面与待机画面区分，关机提示“长按开机”。

### 5.2 PNG兼容与图像处理

- PNG是1.0正式壁纸格式，不是将PNG扩展名加入文件选择器即可完成。验收贯穿上传、列表、预览、保存、锁屏、重启/缺卡与恢复。
- 支持灰阶、RGB、索引色、alpha/tRNS、合法位深与Adam7交错；透明区域默认合成白底，半透明边缘不发黑。不支持动画播放，APNG须识别后明确提示使用静态PNG。
- 必过样本包含原生684×1216、二倍1368×2432、横图、透明线稿、调色板、渐变、16bit和交错PNG。各组合遵守字节、chunk、像素及内存边界；先建立样本矩阵，不无条件承诺任意高分辨率PNG。
- 保留8MiB文件上限、单边8192和总16Mi源像素的解码保护上界；上界不是保证可完成的尺寸，保证集合以真机样本与实际预算发布。若PNG二倍目标无法达标，记录瓶颈并优化条带/采样，不能静默改成仅接受JPEG。
- JPEG完成有界EXIF方向归一化；大渐进式JPEG不得为小缩略图申请无上限整图系数。超预算可操作提示并保留旧设置。
- 顺序：方向归一化、透明合成、等比缩放/裁切、独立对比度/轻抖动、4bpp量化。提供完整显示、铺满、90°旋转和有界裁切步进。
- 图片使用默认/增强对比度和可选照片抖动；线稿与文字图默认避免抖动。正文gamma不改变壁纸。

### 5.3 书封锁屏闭环

- 打开/换书确认成功后记录候选书身份和封面来源；保存并关闭正文前取得锁屏快照，不能因`reader_active`变假而回退空白默认图。
- 在空闲且预算允许时预生成整屏书封位图，默认等比完整显示；设置页预览显示真实目标书封、来源与适配效果。
- 更新按书身份、封面摘要/来源、处理版本和适配参数失效；换书提交成功才接受新候选，过期任务不能写成当前封面。
- 无封面用该书的原生书名排版封面；坏封面/超预算/缺卡时使用同身份有效缓存，否则用系统默认并在设置中解释。不能无提示显示另一书的旧封面。
- 默认锁屏读取内部位图，不在每次按电源键时解压EPUB或解码大图；不每翻一页写封面缓存。最近在读书封已有有效缓存时，拔卡和重启仍可显示。
- 返回书架保留最近在读书封；用户移除/清除阅读关联时按隐私选择恢复默认。正常删除原图与移除锁屏显示内容分别确认。

### 5.4 存储与睡眠

独立1MiB wallpaper分区只保留当前及上一有效A/B结果，每张415872字节加版本、源身份、参数、序号与CRC；实测文件系统开销、迁移与可用空间。它不是所有壁纸/所有模式的永久图像仓库；切换模式覆盖历史缓存后，重新应用旧原图可能需要TF。

应用顺序为写非活动槽、同步、读回校验、接受选择。失败重新读有效代；双坏回默认。预处理与临时帧走共享预算，结束释放；锁屏按行读到显示目标帧，不新增常驻全屏缓存。

电源键/自动锁屏先完成保存与传输停止屏障，再显示GC16锁页、关轨、睡眠。锁页图像失败可回默认，但位置保存失败必须阻止切电。实现可配置自动锁屏/软睡/关机、重启自动续读和低电量保存；拿起唤醒默认关闭，仅在实际功耗与误唤醒门通过后可选。

## 6. 书架展示与板级性能

书架继续分页，保留三键语义，不引入惯性长滚动。布局共用书库/焦点/分页模型，切换不改书籍身份、筛选或阅读位置。

| 方案 | 定位与页容量 | 原生封面候选尺寸与像素成本 | 1.0决定 |
| --- | --- | --- | --- |
| 简洁列表 | 长书名/快速找书，默认5本/页，封面可关闭 | 80×112/4bpp，4480字节/张；5张约22KiB | 必须；性能降级路径 |
| 标准三列网格 | 浏览封面，6本/页；保持当前主布局 | 176×244/4bpp，21472字节/张；6张约126KiB | 必须；优化真实缩略图尺寸 |
| 紧凑四列网格 | 浏览更多，8本/页；设置可选 | 134×186/4bpp，12462字节/张；8张约97KiB | 用户新增要求，已实现同源软件；当前仍共用184×256缓存槽，板级性能待验收 |
| 双列大封面 | 视觉浏览，原型4本/页 | 候选260×360/4bpp，46800字节/张；4张约183KiB | 验证后决定；尺寸须经真实版面检查 |

上述仅为缩略图像素净成本，不包含槽结构、解码临时内存、帧、字体、epdiy或碎片，不能据此认定大封面已可运行。继续阅读卡尽量复用来源/缩略图，另有尺寸时计入总额。现有184×256共用槽及历史72×100小缓存须按目标视框验证采样，不能把低清放大当作约300ppi优化；缓存键必须含尺寸、算法和来源版本。

所有方案要求：

- 文字、分页和命中区域先可用，封面未完成用稳定占位；封面更新不移动书籍或焦点。
- 持久分页索引支持千本书、作者/书名/添加时间/最近打开排序、在读/未读/已读、收藏和有界书单。只保留当前与邻页模型。
- 导入/覆盖/删除后增量失效；外部变更、换卡和USB退出后重扫识别，摘要未确认时不能关联旧进度。
- 可见封面优先，最多一个解码任务；输入/阅读优先，后台任务有取消点。缓存命中首帧显示，未命中封面合并一次局部呈现，不逐本闪屏。
- 图书详情、删除确认、收藏、清进度、从书架移除与批量管理逐项说明影响；清进度不清书签，移除记录不删原书。
- 三种布局分别测空库、6本、100本、1000本、长书名、大字、坏封面、冷/热缓存、低预算。大封面需通过首帧、取消、连续切页、峰值/连续块和残影门。

默认布局先保留标准网格，最终以真机易读性/性能结果固定；用户选择持久化。内存不足时停止封面任务并使用占位，允许切换简洁列表，不能静默跳页或隐藏书目。W00源码核对补充：当前共用封面槽已为184×256，七槽净像素约161KiB；72×100是旧文档基线。第6节候选尺寸不等于当前缓存尺寸，仍需分别验证原生采样与整机峰值。

## 7. 操作响应与沉浸阅读

### 7.1 操作

触摸和屏下三键共用用户意图，KEY2阅读中打开/关闭工具栏，长按回书架；列表KEY1/KEY3移动焦点、KEY2确认。最小命中88px、滑出取消、长按600ms一次触发，阈值经真机核对。返回保留来源、书架页/筛选和阅读锚点。

刷新中仅保留一条待执行导航意图，反向输入可替换尚未执行的意图；已经扫描的帧安全完成。跳转、设置、锁屏优先取消过期预备任务，不能积累无限翻页。等待反馈与取消入口明确，不能靠多次全刷表示忙。

默认以正常翻页成功后提交进度；候选页、后台预排、失败呈现和过期完成不改变可见位置。字号/字体/边距应用保留语义锚点；取消设置恢复原页。

### 7.2 沉浸

- 正文保持纯净背景与原生文本，不叠卡片、纹理、常驻品牌或网络状态。默认无顶部系统栏；正文阅读不自动开启WiFi。
- 页脚提供标准/极简/隐藏三档。隐藏档回收页脚空间并纳入layout_key，调整时保留源锚点；菜单入口与三键可发现且始终可用。
- 阅读预设提供舒适/紧凑/大字，映射字号、行段距、边距、缩进；允许个别修改，显示“自定义”，逐书保存。
- 中文禁则、成对标点、英文词换行、标题孤行和段落连续性必须正确；诗歌保留换行。不要为满页密度丢字或强行压缩间距。
- EPUB脚注弹出/返回、内嵌图片开关、出版物样式开关；全文搜索可取消，命中跳转可返回原处。
- 阅读中提示仅在必要时出现；字体回退/低电量等合并一次提示，详细原因在菜单，不每页覆盖正文。
- 自动翻页为可关闭的可选阅读控制，定时下一页须服从busy、停止与睡眠状态；默认关闭。反色仅在清晰度/残影门通过后提供。
- 阅读时长只统计有效阅读会话，排除锁屏、传输、设置和长时间无操作；页数只统计成功显示的用户翻页，预绘制不计。定期/离书合并保存，统计失败不阻塞进度保存。
- 用户可选自写摘句/书名作为静态锁屏个性化，默认隐藏；手机网页编辑有界文字，设备独立验证并确认应用，无云服务依赖。

## 8. 性能、质量与发布门

以下继承 [VALIDATION](VALIDATION.md) 的待测目标，每组至少30次，记录p50/p95/最大/失败数；冷/热、缓存、字体、卡、温度和供电分组。软件准备与面板光学稳定分开测量。

| 指标 | 1.0初始目标 |
| --- | --- |
| 输入采集/软件取消 | p95≤30ms / 通常≤100ms，显示相位安全结束另计 |
| 控件可见反馈 | p95≤180ms，扫描排队单独记录 |
| 热文本准备/GL16完成 | p95≤80ms / ≤650ms |
| 快速二值翻页 | p95≤350ms，仅通过DU技术与清晰度门后启用 |
| 热恢复/冷TXT/常规冷EPUB首屏 | p95≤1.5s / ≤2s / ≤3s，语料条件沿VALIDATION |
| PDF首屏/单页 | p95≤4s / ≤2s，复杂边界组另列 |
| 千本已索引书架文字首帧 | p95≤1.5s，不等待所有封面 |
| 设置预览 | 输入合并250ms后，总p95≤900ms |
| AP/STA有效上传 | 5×32MiB，持久ACK口径中位≥0.5/0.8MiB/s；校验/安装另计 |
| 锁屏关键路径 | 保存、候选等待、读缓存、显示、关轨、睡眠分段统计；G1基线后冻结p95目标，不掩盖保存失败 |

整机PSRAM按 [ARCHITECTURE](ARCHITECTURE.md) 同时峰值预算，目标保留1MiB余量；内部SRAM空闲≥64KiB、最大连续块≥32KiB、各任务栈水位余量≥25%。池峰值不等于整机峰值；显示驱动、WiFi/TLS、文件系统和隐藏分配纳入测量。单个6MiB应用槽保留至少10%余量，不为PDF/字体破坏双槽。

验收必须同时包含：

- 共享源主机/ASan/UBSan、实际HTTP及独立摘要/QR核对、SDL自动回归与可见窗口人工旅程；源码重建后重启窗口加载新代码。
- 两套ESP-IDF v6.1配置编译及尺寸检查，板级配置与CI配置隔离。
- 真机PNG/书封/字体、手机传输、300ppi细节照片、刷新残影、响应与耗电；没有照片/测量时仍标未验收。
- 打开/关闭500次、字体切换100次、传输启停100次、连续1000翻页，以及24小时待机/浅睡和8小时阅读等原有长时矩阵。
- 保存/上传/壁纸/升级各提交阶段断电、拔卡与异常恢复，旧书/最后有效位置/有效锁屏/可启动槽至少有一份可恢复。
- 至少两块板、三张卡的原计划发布条件；不足时保留Beta，不以单板或主机全绿代替正式质量。

任何指标调整先提交实测原因、替代方案与产品影响；不通过缩小样本、删除慢样本或静默缩减功能完成验收。无开放P0数据丢失/崩溃，必做范围未完成不能发布本计划的1.0。

## 9. 后续演进

微信读书在1.0稳定后单独立项：优先评估官方书架/笔记/统计授权同步，再单独研究正文阅读与进度写回的开放条件、版权、账户安全、平台变更和硬件预算。1.0不添加凭据字段、后台请求或未验证入口。

双列大封面未过门时、横屏重排、日文界面、更多字体格式及复杂排版可进入后续版本；原生PDF既定固定页视口能力不因“横屏重排后续”被取消。新增需求不能打断1.0可靠性与发布验收。
