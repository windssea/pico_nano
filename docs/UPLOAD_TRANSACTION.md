# 上传持久事务内核

pn_transfer/pn_upload提供单owner的同源上传状态机，用于后续书籍、TTF、封面和壁纸接收。事务内核、故障模拟port与[真实文件安装port](UPLOAD_FILES.md)已建立，包含格式检查、空间预检和8会话配额；HTTP/配对/AP/STA、网页、设备回调与传输入口尚未接入。不能称为已有可用传书或字体上传功能，完整路径仍按[传输方案](TRANSFER.md)开发。

## 数据与确认

创建请求包含owner生成的16字节非零随机ID、资源kind、UTF8单文件名、精确总长度及可选完整SHA。ID不代表授权，不由文件名生成。拒绝路径、点前缀、控制字符、非法UTF8、Windows保留名和不可移植字符；各kind限制扩展名，book512MiB、TTF32MiB、封面/壁纸8MiB。扩展名通过不能代替真实格式校验。未知完整摘要时该字段必须全零，完成请求必须给出完整摘要。

begin/resume取得TF的独占WRITE租约，已有阅读/TF字体READ或USB访问时返回BUSY。关闭只释放内存/租约，不取消可续传会话；恢复使用新租约并核对持久media_id，不能复用旧epoch/句柄。网络与配对owner负责稳定可信媒体身份和恢复授权。

固定64KiB块，只有最后块可以不足。客户端偏移必须等于已确认offset；上一块完全相同的偏移/长度/摘要可幂等重发，并检查实际暂存内容。块SHA通过后截去未确认尾部，精确写入并同步，再写A/B日志并同步读回，两者都成功才更新ACK。失败保持调用方ACK输出。

日志同步错误即使能读回新内容也不能回成功。会话标记不确定，阻止新的块/状态推断/提交，调用方关闭并恢复。恢复从最新合法日志核对暂存长度和上一块摘要，截去未确认尾部，再成功同步新的日志代，才对外提供可续传offset。未知版本、字段或I/O不擦旧记录；较短暂存返回损坏，完整摘要在完成时覆盖早期块损坏检测。

## 完成与取消

RECEIVING：完整长度/SHA核验，再调用实际格式检查。通过后同步VERIFIED，然后调用可恢复幂等install_sync；该port必须核对新主文件完整摘要后才成功。最后同步COMMITTED。已提交完成请求幂等，不重复安装。

VERIFIED重开允许暂存已被移到目标路径；由install_sync判定新主/旧备份并恢复。安装失败或已安装但COMMITTED日志失败都保留已验证事务，不能用取消删除可能已安装的资源。覆盖备份和各rename恢复阶段由文件port实现；内核不声称FAT rename原子。

RECEIVING取消先同步CANCELLED标记再清本ID暂存。清理失败可重试，不能删已安装资源。begin遇已有日志或无日志的暂存拒绝覆盖；孤立暂存需要后续明确清理入口，不能偷删。

## port维护契约

bind只绑定ID所属日志，不擦已有数据；admit可预检配额及保存覆盖意图，unbind只解除绑定，recover_initial只允许恢复已有持久意图的空暂存；ctx和日志上下文在会话期间稳定不可移动。size的EMPTY仅表示暂存不存在。truncate_sync/write_sync/remove_sync必须真实同步；不支持同步不能假报成功。read每次返回1..capacity字节，所有文件操作需检测介质错误并排除其他进程改动。install_sync需可重复调用和掉电恢复。validate是强制回调，不能仅根据扩展名放行。不允许回调重入状态机。

所有应用内存走pn_pool；数据块借用调用方只读缓冲，调用期间不得修改，内核不保存整本。SHA流每次4KiB读取。hash/格式检查当前同步，异步取消/响应时间预算尚未实现。

## 日志格式

PNUP schema1封装在既有PNBL双槽，最大399字节。头144字节：magic[0..3]、version16[4]、kind8[6]、phase8[7]、media_id64[8]、size64[16]、offset64[24]、last_offset64[32]、last_length32[40]、known_digest32[44]（0/1）、id16[48]、完整SHA32[64]、上一块SHA32[96]、name_length16[128]、reserved14[130]全零。144之后文件名原UTF8字节，不带NUL。整数小端。offset/最后块/phase和名字均重新验证，不接受仅CRC正确的非法语义。

## 可复跑验证

python tools/dev.py host的upload测试覆盖64KiB与尾块、摘要/位置冲突、精确重发、未确认尾截断、每个日志字节中断（包括完整写入却返回IO仍不ACK）、恢复重新同步、格式拒绝、完整摘要检测早期损坏、安装失败、已安装但提交标记失败的恢复、未知日志保持、取消、媒体身份与独占、恢复分配失败回收。固定abc SHA向量验证新增内存摘要入口。当前port是内存故障模拟，不是TF同步、断电、无线吞吐或HTTP端到端证据。
