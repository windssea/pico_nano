# PicoNano

基于 ESP32-S3 的独立墨水屏阅读器固件。核心、解析、字体、排版与界面在设备和 PC 模拟器中共用源码，固定目标为 RDP-G01-W/E0470A01、684×1216、16 灰阶、8MiB PSRAM、16MiB Flash。对外品牌在所有语言中统一为 **PicoNano**。

当前是 **0.6.5 开发预览**，不是完整 1.0 验收版本。已发布应用来源为 `766a137`：面板扫描期间准备下一页、页脚变化合并为单次扫描、输入健康日志；0.6.4 字形缓存扩到约两页、封面预算计入可回收缓存；0.6.3 修复 0.6.1/0.6.2 调频与自动浅睡实际未生效、睡眠引脚上下拉、按真机日志加速字形预热；此前 0.6.2 增加自动浅睡与触摸中断唤醒，0.6.1（动态调频、去除已显示帧副本、透明遮罩锁屏缓存、EPUB 打开减少随机读、阅读线深浅与左右半屏点按）基础上增加自动浅睡与触摸中断唤醒；真机功耗、翻页、触摸与 TF 时延尚待实测。实现、软件验证、烧录和真机验收分别记录。

TXT、受限重排 EPUB、字体与排版、阅读线、书签/续读、锁屏图片、AP/STA 网页传书已有源码实现。LocalSend 已有协议和 HTTP/发现基础，设备与官方客户端互通仍未验收；PDF、FB2、CBZ、USB 大容量传书和设备 OTA 回滚尚未交付。用户反馈的插线无线不稳定、网页刷后自动复位及慢开书仍需设备验证，详见开发指南。
