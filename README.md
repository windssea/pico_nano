# PicoNano

基于 ESP32-S3 的独立墨水屏阅读器固件。核心、解析、字体、排版与界面在设备和 PC 模拟器中共用源码，固定目标为 RDP-G01-W/E0470A01、684×1216、16 灰阶、8MiB PSRAM、16MiB Flash。对外品牌在所有语言中统一为 **PicoNano**。

当前开发树为 **0.9.17 OTA 测试预览**，不是完整1.0验收版本；应用与完整恢复包的源码以发布清单的`source_commit`为准。本批加入Gitee签名更新、非活动槽写入与读回校验、显式重启切槽和启动确认/失败回滚逻辑；0.9.1修正首启确认不再依赖TF卡、等待确认时允许自动锁屏、下载超时/断点续传，以及用过OTA后的USB保留升级；0.9.2可在设置的“WiFi 网络”中用屏幕键盘直接配置家庭WiFi，保存前先测试连接；0.9.3修正翻页“描边感”，新增水波纹翻页、排版字重、OTF字体与系统字体选择，书库封面一次成画，并改善局域网传书与LocalSend发现；0.9.4加快TXT冷开（首屏前不再读完整本书，完整核对改在后台），水波纹改为只替换变化文字的柔和波纹，书库翻页只局部刷新列表；0.9.5修正局域网传书接收服务启动失败（片内内存），EPUB同样快开，菜单与设置切换只局部刷新，默认水波纹翻页；0.9.6清残影水波纹只清理变过的像素，菜单切换不再先黑一下，解锁立即显示加载，字体管理分当前字体与TF卡备选并可一键重置，楷体/宋体更清晰，排版换字体有提示且只读一遍字体文件；0.9.7修正切换OTF（CFF）字体时溢栈重启，LocalSend兼容新版客户端的v3路径；0.9.8暂时隐藏LocalSend入口，网页上传封面/锁屏图片前在浏览器内缩小并转为设备易解码的格式；0.9.9清残影改为无黑闪的“白推”（四次里第四次才GC16），菜单维护同样白推，大渐进JPEG封面可显示，书库空闲预计算未读书身份加快首开，排版档位项改用左右切换；0.9.10排版新增“清晰度”（标准/清晰/锐利/黑白），全部选项一页六行完成，并修正TXT应用字重后不生效；0.9.11 EPUB快开不再在首屏前整读外置阅读字体；0.9.12修正EPUB常卡在加载页、加载页按键误开别的书，排版档位项首尾循环；0.9.13加快网页/LocalSend传书后首次开书（安装提交身份缓存）、首页/书库整页复用、EPUB跨章预排不丢当前章，并优化板级帧转换与显示风险扫描。首次启用须通过完整USB包迁移兼容引导程序；真实设备的TLS、双槽互换、断电与回滚仍待验收，不将源码或主机测试当作设备OTA已交付。此前0.8的阅读与菜单修复保留，产品镜像不含测试控制台。0.9.14将PDF移出书架格式，EPUB外置正文字体/回退字体完整SHA移到首屏后台，书库身份预计算按最近阅读/当前选择优先并支持点击同书异步接管，整书身份读取优先48KiB内部DMA块，并复用EPUB目录尺寸；临时身份首屏只有默认关闭的设计，尚未启用。0.9.15修正身份接管后EPUB打不开、取消残留开书门及锁屏唤醒后锁图不恢复，字体复核失败保留会话并原位降级重画；阅读优先让出菜单帧，同代完整校验备忘减少重复字体读取，接管去掉重复加载和首屏前缓存落盘。0.9.16补齐真实分步开书诊断，提前身份预计算、分步完成ZIP/XML与加载期间首屏准备，并均衡后台工作；保持完整校验和首屏画质。0.9.17将邻章预排、已验证模型的跨会话加载分步推进，并优化字体供数；诊断同条件首次NEXT中位数2.44→1.05秒，首屏画质与完整校验保持。后续源码已加入本地书签锁屏与公历月历，作为独立诊断开发批次，尚未纳入0.9.17发行。

TXT、受限重排 EPUB、字体与排版、阅读线、书签/续读、锁屏图片、AP/STA 网页传书已有源码实现。LocalSend 已有协议和 HTTP/发现基础，设备与官方客户端互通仍未验收；USB MSC已有源码和软件验证，电脑枚举/读写/弹出/串口恢复待真机；PDF已从书架格式移除（需在电脑转换），FB2、CBZ与设备OTA回滚尚未交付，MOBI后期再评估。用户反馈的插线无线不稳定、网页刷后自动复位及慢开书仍需设备验证，详见开发指南。
